# and the set of `{placeholders}` in every key must match the base exactly;
# `scripts/check-messages.py` fails with a list otherwise.

se-064.duration-unrepresentable = {what}: the duration is not representable
se-064.duration-too-large = {what}: the duration exceeds {max} ms — it does not fit the {bits}-bit value representation (about 49.7 days)
se-073.tick-rate-not-multiple = a computed delay needs a rate that is a multiple of 1000 Hz: at {hertz} Hz a millisecond is not a whole number of ticks, and the comparison would round silently. Either use a multiple rate or keep the delay constant (the compiler converts that one exactly)

# ─── Semantics: address cell access (`semantic/anon_port.rs`) ────────────────
se-098.address-too-wide = the address '{addr}' of an anonymous access does not fit a 64-bit signed integer: the cell address is wider than representable
se-098.bit-given-twice = the bit position is given twice: by an address literal (':{literal}') and by bit access ('.'). Keep one form: '#0x{addr}.N' — a single bit, '#0x{addr}:N as TYPE' — a field starting at bit N
se-098.bit-position-is-a-name = the bit position of an anonymous access is given by the name '{name}': a number was expected
se-098.type-without-width = type '{ty}' does not set the access width for a cell: the width of an address access is not guessed. Allowed are 'bit', 'bool', integer types and 'q(m, n)'
se-098.bit-out-of-range = bit position {bit} is out of the range [0, {max}]: the access word is no wider than 64 bits
se-098.field-out-of-word = a field of width {width} starting at bit {bit} runs past the access word: {bit} + {width} > {max}
se-097.access-without-width = the access '{written}' does not set the cell access width: add a cast ('{written} as u32') or take a single bit ('#0x{addr}.N')
