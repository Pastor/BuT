# Реестр ветвей-заглушек - отказов "пока не поддерживается".
#
# Заглушка - разобранный узел, отвечающий отказом до какой-то будущей работы.
# Гейт исчерпаемости её не видит по устройству: узел разобран,
# ветви `_` нет, отказ законен по типу. Класс дал дефект дважды (фиксы 0134-01
# и 0134-02: ветвь отвечала "значение времени вводит подзадача 0134-03" и
# пережила эту подзадачу на пять месяцев).
#
# Формат: <код диагностики> <файл от корня репозитория> <держатель> # пояснение
#
#   держатель = номер фичи, которая заглушку снимет,
#             | постоянный - отказ не временный, а принятое решение.
#
# Ключ - код + файл, а не номер строки: строка уедет при первой правке
# (запрет ссылок `файл.rs:NNN` - правило живого контекста, гейт 0149).
#
# Три условия отказа гейта scripts/check-stub-branches.py:
#   1. заглушка в коде без записи здесь - новая незарегистрированная;
#   2. держатель в статусе готово/отмена - заглушка пережила свою задачу;
#   3. запись, которой в коде ничего не соответствует, - реестр окаменел.
