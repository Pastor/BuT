# Реестр нижних границ входа - узаконенный долг и названные исключения.
#
# Правило: проверка, чей вердикт строится на выборке из файла, отказывает, когда
# разбор не достиг границы (scripts/gatelib.py). Пустая выборка - не
# благополучие, а слепота: разбор ничего не нашёл, находкам взяться неоткуда, и
# проверка отвечает успехом, не прочитав ни строки.
#
# Реестр не даёт послабления - он замораживает долг. Проверка
# scripts/check-gate-inputs.py запрещает его рост: потолок записан в ней
# константой, и дописать строку, не тронув потолок, нельзя.
#
# Единственная допустимая правка записи вида "долг" - её удаление вместе с
# заведением границы. Записи вида "исключение" описывают проверки без выборки:
# они судят по коду возврата чужого инструмента или по одной названной точке.
#
# Долга сейчас нет, и это его нормальное состояние: границу заводят вместе с
# проверкой, а не пополняют реестр. Потолок в check-gate-inputs.py равен нулю,
# поэтому первая же запись долга валит проверку - поднять потолок можно только
# правкой её кода, видимой в диффе.
#
# Формат: <долг | исключение> <имя проверки> - <причина>

# Исключения: выборки нет, судить нечего.
исключение check-language-version.sh - сверяет три названных источника версии языка, выборки из файла нет
исключение check-stale-candidates.sh - печатает подсказку к ревизии кандидатов, вердикта не выносит
исключение check-version-tag.sh - сверяет одну точку: метку версии, достижимую из HEAD
исключение check-wasm.sh - собирает модуль и гоняет два названных инструмента
исключение check-web-server.sh - запускает набор сервера проектов, судит по коду возврата
исключение check-zed-extension.sh - собирает расширение редактора под две названные цели

# Долг: записей нет. Граница заводится вместе с проверкой, а не пополняет
# реестр; потолок в check-gate-inputs.py равен нулю.
