# Реестр непокрытых конструкций языка - узаконенный долг.
#
# Правило: каждая конструкция языка обязана быть показана примером - и в
# `examples/` (исполняемая документация, её гоняют гейты предкоммита), и в
# `book/src/**` (справочник языка). Перечисленные ниже правило
# нарушают. Реестр не даёт им разрешения - он их замораживает: сторож
# `takt-lang/tests/syntax/language_coverage_tests.rs` запрещает появление новых
# непокрытых конструкций, а запись о конструкции, для которой пример появился,
# объявляет протухшей и роняет прогон.
#
# Единственная допустимая правка записи - удаление: покрытие может только
# расти. Формат: <область> <вид конструкции> # <причина>
#
# Области: `examples` и `book` - долг соответствующего корпуса; `never` -
# конструкция в каноничном примере появиться не может, и это доказано, а не
# заявлено (причина у каждой записи своя).

# ── Не может быть показана примером ───────────────────────────────────────
never FormulaStatement::Error # узел восстановления после ошибки в блоке `formula`: тот же случай, что `Statement::Error`
never ModelElement::StraySemicolon # лишнюю `;` стирает `taktc fmt` (проба 2026-08-23), а канон примеров сторожит `fmt --check`
never StateElement::StraySemicolon # лишнюю `;` в теле состояния стирает `taktc fmt` — та же причина
never Statement::Error # узел восстановления после ошибки: живёт только на НЕВЕРНОМ входе, каноничный пример его не даст

# ── Долг документа `book/` ────────────────────────────────────────────────
#
# Осталось четыре записи, и все - не про документ, а про цели: гейт примеров
# книги требует, чтобы каждый пример компилировался целью `c`,
# а перечисленные конструкции она не переводит. Показать их примером станет
# возможно, когда цели научатся их переводить, - это работа над целями, а не
# над разделами.
book Condition::AnonAddress # цель `c` обращение к ячейке не переводит (`CC-021`), а гейт 0133 требует от примера документа компиляции ею — замер 2026-08-23
book Expression::AnonAddress # та же причина: `CC-021` у цели `c`; конструкцию переводят `c-hal`, `st-at`, `sv-mmio`
book Statement::Formula # блок формул В ТЕЛЕ даёт `CC-023` у цели `c` (уровня модели — компилируется и в документе показан)
