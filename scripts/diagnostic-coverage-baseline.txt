# Реестр кодов, не достигаемых корпусом, - узаконенный долг.
#
# Правило: у каждого кода диагностики есть вход в корпусе (`takt-lang/tests/data`,
# `examples/`, `book/src`), который его порождает. Корпус - то, что гоняют проверки
# целей и потактовые сверки; код, которого корпус не даёт, ими не проверяется
# вовсе, и узнать, работает ли он, можно только чтением исходника.
#
# Перечисленные коды правило нарушают. Реестр их замораживает: проверка
# `scripts/check-diagnostic-quality.py` запрещает появление новых недостижимых
# кодов, а запись о коде, для которого вход появился, объявляет протухшей и
# роняет прогон. Единственная допустимая правка - удаление.
#
# Многие из этих кодов проверяются юнит-тестами на исходнике-строке - то есть
# "не проверяется" и "недостижим корпусом" не одно и то же. Реестр честно
# называет второе: он про то, видят ли код проверки, гоняющие чужие инструменты.
#
# Область проверки - `taktc compile`. Коды эталона (`SIM`), стиля (`CS`) и
# форматтера (`FM`) сюда не входят: их печатают другие инструменты.
#
# Формат: <код> # <причина>
