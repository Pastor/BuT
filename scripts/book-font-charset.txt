# Снимок покрытия шрифта документа book/.
#
# назначение. Символ, которого нет в шрифте, PDF не роняет: xelatex печатает
# предупреждение Missing character, а глиф молча выпадает из вывода. Сборка
# документа в предкоммит не входит - нужны mdbook, mdbook-pandoc, pandoc,
# xelatex и сам шрифт. Снимок позволяет проверять покрытие текстом, без них:
# scripts/check-book-glyphs.py сверяет с ним каждый символ документа.
#
# что это. Кодовые точки таблицы cmap, сжатые в диапазоны. Это замер, а не
# редполитика: файл говорит, что шрифт умеет нарисовать, а не что уместно в
# тексте. Уместность - дело автора и ревью.
#
# шрифт: Fira Code
# версия: Version 6.002
# начертаний: 7 (FiraCode-Bold.ttf, FiraCode-Light.ttf, FiraCode-Medium.ttf, FiraCode-Regular.ttf, FiraCode-Retina.ttf, FiraCode-SemiBold.ttf, FiraCode-VF.ttf)
# CMAP начертаний идентичны: да
# кодовых точек: 1586   диапазонов: 152
#
# пересъёмка (при смене шрифта или его версии):
#
#   pip install fonttools
#   python3 scripts/snapshot-book-font.py > scripts/book-font-charset.txt
#
# граница. Снимок фиксирует покрытие названной версии. Если на машине сборки
# стоит другая версия с меньшим покрытием, гейт промолчит, а xelatex
# предупредит: конечный арбитр - `make -C book build`. Это та же граница
# "согласованность, а не правильность", что у гейта адреса репозитория.
#
# Формат строки: <начало>-<конец> шестнадцатерично, границы включительно.
