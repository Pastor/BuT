# Слова, выделяемые в документе book/.
#
# зачем файл. Шаблон документа (book/src/template.typ) выделяет инлайн-код,
# равный ключевому слову языка, - так же, как это делал lua-фильтр pandoc
# `keywords.lua` до перевода документа в Typst. Список нужен и подсветке блоков
# кода (book/takt.sublime-syntax, отдельный формат - регулярные выражения).
#
# это один из трёх списков одного набора: здесь, в `takt.sublime-syntax` и в
# таблице `KEYWORDS` лексера (`takt-lang/src/parser/lexer.rs`). Расходятся они
# молча - так предшественник этого файла (`takt.kate.xml`) отстал от лексера на
# пять слов и никем не проверялся. Контроль - `scripts/check-book-keywords.py`:
# сверяет оба списка документа с лексером в обе стороны.
#
# Формат: секции `[имя]`, далее по слову в строке; `#` - комментарий.
