# Исправление: проверка имени файла кричала на идиому корпуса

> Фича: [../features/0301-probe-checklist.md](../features/0301-probe-checklist.md) · ADR: [../features/0301-probe-checklist.md#архитектура-adr](../features/0301-probe-checklist.md#архитектура-adr) · отчёт: [../features/0301-probe-checklist.md#отчёт-о-тестировании](../features/0301-probe-checklist.md#отчёт-о-тестировании)

- **Статус:** **ИСПРАВЛЕН** (2026-08-18). Найден **сразу после закрытия** —
  первым же прогоном инструмента на настоящем примере корпуса.
- **Tier 4 — ложная тревога контроля.** Отказа нет; вред в том, что контроль,
  кричащий на верном входе, перестают читать.
- **Класс:** «проверка шире предмета».

## Что было

`scripts/probe.sh` объявлял пробу негодной, если имя файла совпадало с именем
**любого** объявления — включая `model`. Но `model Regulator` в
`regulator.takt` — **идиома корпуса**: так написан почти каждый пример, и цель
`c` такой вход принимает (проверено `cc -std=c11 -pedantic`).

```
$ scripts/probe.sh -n 2 examples/regulator.takt
ПРОВЕРКА ПРОБЫ
  ✗ имя файла 'regulator' совпадает с объявленным именем: Regulator
  ⚠️ проба негодна: замер ниже измеряет не предмет.
```

То есть инструмент, заведённый ради доверия к замеру, на половине входов
корпуса выдавал бы тревогу, которой цена — ноль. **Контроль, кричащий всегда,
замолкает навсегда.**

## Почему проскочило

Проверка писалась по замеру [структура без полей](../features/0284-empty-struct-semantics.md),
где столкновение было `pair.takt` ↔ **`struct Pair`**. В список объявлений
`model` попал «заодно», по форме, а не по замеру: тот же греп, то же имя — а
последствия разные. Контроль (`scripts/test-probe.sh`) проверял, что коллизия
**ловится**, и не проверял, что законная форма **не ловится**: контрольного
входа у этой проверки не было.

Это ровно тот пункт, который сама фича записала в **свод** как
обязанность человека — «контрольный вход». Первым же его нарушила она сама.

## Что сделано

1. Список сужен до **типов**: `struct`, `enum`, `type`. `model` изъят, причина
   названа в самом скрипте.
2. В контроль добавлен **контрольный вход**: `model Gate` в `gate.takt` не должен
   давать тревоги. Мутация «вернуть `model` в список» валит именно его.

## Проверки

```sh
scripts/test-probe.sh                       # 9 проверок, все пройдены
scripts/probe.sh -n 1 examples/regulator.takt   # тревоги нет
./scripts/precheck.sh
```
