# Исправление: тернарный оператор в `bit`-порт даёт некомпилируемый Rust

> Фича: [../features/0148-rust-printers-coverage.md](../features/0148-rust-printers-coverage.md) · вскрыт при задаче [тип `duration` в целях генерации и вычисляемая выдержка](../features/0183-duration-type-in-targets.md#разработка) (цель `rust` для типа `duration`), 2026-07-29

## Симптом

```takt
model T {
    var n: u32 := 7;
    out late: bit := 0;
    start Idle { always { late := (n > 5) ? 1 : 0; } ref Idle: false; }
}
start Main = T;
```

Порождённый Rust:

```rust
hal.write_bit(OutBitPort::Late, if (self.n > 5) { 1 } else { 0 });
```

`rustc -D warnings` даёт **три** ошибки:

```
error: unnecessary parentheses around `if` condition
error[E0308]: mismatched types — expected `bool`, found integer   (× 2: обе ветви)
```

То есть цель `rust` порождает код, который **не компилируется**, на простейшей
записи «условие → битовый выход».

## Причина (по чтению кода — не исправлено)

Два независимых промаха печатника, оба в одном выражении:

1. **Ветви тернарника не коэрцируются к `bool`.** Присваивание в `bit`-порт
   коэрцию делает (исправление свёл сравнение `bit`-операнда к самому операнду),
   а тернарник печатает `1`/`0` числами — при том что `write_bit` принимает
   `bool`. Тот же класс, что 0148-01: **два пути одной идеи разошлись**.
2. **Условие `if` печатается в скобках.** Инвариант ADR «каждый бинарный
   узел в скобках» защищает от расхождения приоритетов C и Rust, но в позиции
   условия `if` скобки не нужны и ловятся линтом `unused_parens` под
   `-D warnings`. Снимать их надо там, где узел стоит в позиции условия — как
   `unwrap_outer` снимает лишние внешние скобки в других позициях.

## Почему дожило

Проверка цели `rust` гоняет **только корпус**, а в корпусе нет присваивания
тернарника в битовый порт. Ровно та же причина, что у 0148-01 и 0148-02: три
дефекта одного класса, и все три невидимы для проверки, который проверяет
компилируемость **имеющихся** примеров.

Тесты печатников фичи (27 случаев по тексту) эту форму тоже не покрывают.

## Состояние

**Заведён, не исправлен.** В объём задачи не взят сознательно: там
предмет — тип `duration` в цели `rust`, и смешивать с ним правку коэрции битовых
портов значит вести две работы под одним номером. Фикстура сверки 0183 обходит
дефект формой `if … { late := 1; } else { late := 0; }` — с явным комментарием,
чтобы обход не выглядел стилем.

Исправление ожидается в объёме: коэрция ветвей тернарника к `bool` при записи в
`bit`-порт + снятие скобок в позиции условия `if`. Контроль — тест печатника **по
тексту** (как 0148), а не факт сборки корпуса.

## Tier

**Tier 2.** Молчаливо неверного поведения нет — отказ громкий (код не
компилируется), — но законная конструкция языка не транслируется, и класс уже
дал три дефекта подряд.
