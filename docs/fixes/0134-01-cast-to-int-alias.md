# Исправление: приведение `x as u8` давало `Unsupported` — два списка встроенных типов

> Фича: [../features/0134-language-time-model.md](../features/0134-language-time-model.md) · вскрыт при задаче [модель времени в языке: литерал длительности и частота такта](../features/0134-language-time-model.md#разработка) (требования заказчика к `duration`)

## Симптом

Любое приведение к целочисленному типу **не работало вовсе**:

```takt
var n: u8 := 0;
always { n := 5 as u8; }   // ОШИБКА вычисления: SIM-007
```

Симулятор останавливался с `SIM-007` («тип не поддерживается симулятором») на
совершенно законном коде. Дефект **существовал до фичи** и обнаружился
только потому, что требование заказчика («`duration as` даёт миллисекунды»)
впервые заставило проверить приведение к `u32`.

## Причина

Знание «какое имя обозначает какой встроенный тип» жило в **двух** местах и
разъехалось:

| Место | Что знало |
|---|---|
| `type_node::construct_type` (объявления) | `bit`, `bool`, `float`, `unit` **и** `u8`…`i64` |
| `type_inference::ast_type_to_node` (приведения `as`) | только `bit`, `bool`, `float`, `unit` |

Приведение идёт через **второй** список (контекст модели там недоступен),
поэтому `u8` в нём оказывался «пользовательским псевдонимом без контекста» →
`TypeNode::Unsupported`. Дальше молчания не было — симулятор честно отказывал, —
но отказ был на верном коде.

Это ровно тот класс, который проект уже ловил: два матчера адреса фичи
обязаны были давать один ответ, и их расхождение стоило отдельной проработки.

## Исправление

Заведён **единый** разбор `type_node::builtin_type_by_name(name) -> Option<TypeNode>`;
оба места зовут его:

- `construct_type` — после поиска в таблице типов модели (приоритет
  пользовательского псевдонима над встроенным именем **сохранён**), иначе `SE-034`;
- `ast_type_to_node` — вместо своего списка из четырёх имён.

Заодно в единый список попал `duration`, поэтому `250 as duration`
работает по той же дороге, а не по третьей.

## Проверка

- `takt-lang/tests/syntax/time_literal_tests.rs::cast_to_integer_alias_works_at_all` —
  контроль на `builtin_type_by_name` (включая `duration` и отказ на
  пользовательском имени);
- `takt-sim/tests/sim/duration_tests.rs::duration_casts_to_milliseconds_and_back` —
  значенческая проверка обоих направлений через `as`;
- проба, с которой всё началось: `5 as u8` в симуляторе даёт `5`, а не `SIM-007`.

## Tier

**Tier 2.** Молчаливого расхождения не было (симулятор отказывал явно), но
законная конструкция языка не работала, и причина — дубль знания, который сам по
себе источник будущих расхождений.
