# Исправление: пример сортировочного конвейера — связная модель

> Фича: [../features/0121-book-example-walkthrough.md](../features/0121-book-example-walkthrough.md) · соседний [примеры разделов — функциональные, из практики](0121-02-functional-examples.md) · запрос заказчика (перепроверка примера)

- **Статус:** Исправлено
- **Приоритет:** Tier 3 — корректность примера документа (компилировался, но модель бессвязна)

## Проблема

Первая редакция примера конвейера  **компилировалась**, но была
**семантически бессвязной** — набор конструкций без работающей логики:

- `kind` нигде не присваивался (оставался `Small`), поэтому `match kind` всегда
  выбирал один лоток — **сортировки фактически не было**;
- `counter := settle(sensor)` **перезатирал** счётчик каждый такт, а следом `for`
  добавлял 3 — «счёт обработанных деталей» не считал детали;
- функция `settle` крутила пустой цикл и возвращала `min(target, 50)` — результат
  бессмысленный;
- переход `ref Running: class_off = 0` вёл в то же состояние — бессмысленная
  самопетля.

Это противоречит цели 0121-02 (пример должен быть **функциональным и связным**).

## Исправление

Конвейер перепроектирован в **работающую** модель сортировщика (проверено
**симуляцией**):

- два состояния — `Waiting` (лента крутится, ждём деталь) и `Sorting` (обработка);
- деталь обрабатывается **один раз** в блоке `enter` состояния `Sorting`:
  ветвление `if … else` (1) определяет класс `kind` по коду датчика, `match` (2)
  направляет деталь в лоток, счётчик `count` (3) растёт **по одной детали**;
- функция `pallets` считает число полных паллет **делением повторным вычитанием**
  — циклом `while` (4), `break` (5), `return` (6) — результат используется
  (`pallet_count`);
- нумерация маркеров — по порядку кода (`pallets` перенесена после состояний).

Разбор в `book/src/06-control-flow/index.typ` переписан под связную модель.

## Проверка (симуляцией)

Сценарий `class_code = 1/0/7` при `part_ready`:

| Класс | `kind` | `gate` | `count` |
|-------|--------|--------|---------|
| `1` Large | 1 | 2 | 1 |
| `0` Small | 0 | 1 | 2 |
| `7` Reject | 2 | 0 | 3 |

Классы направляются в разные лотки, счётчик растёт по детали. Компиляция — 0
предупреждений; `make build` собирает PDF, `??` = 0.
