# Исправление 0564-05: к модели применялся сценарий другой модели

> Фича: [Управление файлами в структуре проекта](../features/0564-project-file-actions.md)

## Проблема

В проекте с двумя моделями прогон второй модели кончался отказом эталона
`SIM-030: порт go не найден`: к ней применялся сценарий первой модели, со
своими портами. Найдено прогоном страницы 2026-09-10.

## Причина

Сценарий выбирался при открытии проекта из **всех** сценариев проекта:
названный проектом либо первый по имени. При открытии другой модели того же
проекта сценарий заново не выбирался, хотя сценарий модели — это файл `.json`,
чьё имя начинается с имени модели, и так его показывает окно выбора.

## Решение

При открытии модели сценарий подбирается среди её собственных: текущий, если он
свой; иначе названный проектом, если он свой; иначе первый свой; своих нет —
прогон идёт без сценария. Правило — чистая функция `pickScenario`.

## Проверки

Тест: свой текущий остаётся, чужой уступает, своих нет — без сценария. Прогон
страницы: модель без своих сценариев прогоняется без отказа.
