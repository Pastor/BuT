## Проблема

После [пример сортировочного конвейера — связная модель](0121-03-conveyor-coherence.md) (связный конвейер) стало ясно: одной
компиляции мало — пример может компилироваться, но быть семантически бессвязным.
Нужно (а) закрепить проверку **симуляцией** в правиле, (б) прогнать регресс по
остальным примерам.

## Исправление

- **свод** (`docs/RULE.md`) дополнено пунктом **(д)**: пример проверяется
  **компиляцией И симуляцией** на осмысленное поведение; семантически бессвязный
  пример — дефект. Зафиксирован практический факт: симулятор **не вычисляет
  `extern`-функции с возвратом** (`SIM-019`) — значения датчиков берут **входным
  портом**, `extern fn` оставляют для команд (`void`).

- **Регресс симуляцией всех примеров 02–07** (`takt-sim` со сценариями):

  | Раздел | Устройство | Проверено |
  |--------|-----------|-----------|
  | 02 | термореле | гистерезис: выкл при 80, вкл при ≤75 |
  | 03 | лифт | едет вверх, `current` по датчику, при `current=target` → Waiting |
  | 04 | светофор | Red≈30 / Green≈30 / Yellow≈5 тактов, цикл |
  | 05 | бойлер | нагрев по холоду+давлению, стоп по перегреву/потере давления |
  | 06 | конвейер | Large→2, Small→1, брак→0; счёт по детали (0121-03) |
  | 07 | насосная | **был не симулируем** (см. ниже) → исправлен |

- **07 Насосная станция — исправлена.** Использовала `extern fn read_pressure()
  -> u8` (extern с возвратом) → симуляция падала `SIM-019`. Заменено: давление
  приходит **входным портом** `in pressure: u8`; `extern fn drive_pump(on: bit)`
  (`void`) оставлен для команды насосу. Композиция `headroom → clamp` проверена
  симуляцией: `pressure = 30 → margin = 70`; `pressure = 120 → clamp срезает до 100
  → margin = 0`. Разбор переписан. 0 предупреждений.
