# Исправление 0564-04: в окне выбора сценария не видно выбранного файла

> Фича: [Управление файлами в структуре проекта](../features/0564-project-file-actions.md)

## Проблема

В окне «Сценарий прогона» щелчок по файлу его выбирает, но строка никак не
меняется: не видно ни текущего сценария при открытии окна, ни только что
выбранного. Замечено заказчиком 2026-09-10.

## Причина

Строка выбора отмечалась признаком `aria-pressed` — и при открытии окна, и по
щелчку, — но у строки `.row-pick` не было оформления для нажатого состояния:
признак был, а виден не был.

## Решение

Нажатая строка `.row-pick` получает пару «выбранное» — ту же, что файл в дереве
и проект в списке. Книга оформления называет это состояние у строки выбора.

## Проверки

Прогон страницы: при открытии окна текущий сценарий подсвечен, щелчок по другому
файлу переносит подсветку.
