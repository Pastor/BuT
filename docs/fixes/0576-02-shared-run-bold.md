# Исправление 0576-02: рёбра в одной точке сливаются в жирную линию

> Фича: [схема — шестнадцать точек привязки, вид пересечения и место метки входа](../features/0576-scheme-ports-and-crossings.md)

## Проблема

Рёбра могут сходиться в одну точку окружности состояния и выходить из неё —
например, когда автор закрепил два конца в одной точке. Тогда их общий участок
читается жирной линией, а совпадающие наконечники — одним жирным. Заказчик
потребовал, чтобы эффекта жирной линии не было, 2026-09-10.

## Причина

Каждое ребро рисуется своим штрихом целиком. Два непрозрачных штриха в одном
месте складываются по краям сглаживанием: край темнеет, и линия выглядит толще
соседних. Наконечники в одной точке одним ходом ложатся друг на друга так же.

## Решение

Ребро, нарисованное позже, находит участки, совпадающие с уже нарисованными
(`overlapWith`: параллельный отрезок ближе полупикселя), и пропускает их штрихом
(`stroke-dasharray` по длине ломаной, `pathLength`). Совпадающий конец тем же
ходом не несёт второго наконечника. Выбранное ребро рисуется целиком: пропуск
и спрятанный наконечник у него снимает оформление (`.edge.selected`), потому что
выбор переключает класс без перестроения листа — решение, принятое при
отрисовке, застряло бы на ребре, которое уже не выбрано (найдено прогоном
страницы). У кривых Безье совпадения не ищутся.

## Проверки

Тест геометрии: общий участок двух рёбер, штрих с пропуском, совпадающий конец,
перпендикулярный конец и участок на одной прямой не встык — не совпадение.
Прогон страницы: два конца закреплены в одной точке — общий участок той же
толщины, что прочие линии.
