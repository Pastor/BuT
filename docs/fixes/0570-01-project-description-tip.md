# Исправление 0570-01: у проекта в списке не видно описания

> Фича: [список проектов живёт в панели структуры](../features/0570-projects-in-panel.md)

## Проблема

В списке проектов структуры строка называет только имя и уровень доступа:
описание проекта не видно нигде, и выбирать проект приходится по одному имени.
Заказчик потребовал подсказку с описанием при наведении, 2026-09-10.

## Причина

Строка списка строилась из имени и уровня; поле `description`, которое сервер
отдаёт вместе с проектом, страница не использовала.

## Решение

У строки проекта — подсказка с его описанием (атрибут `data-tip`, который
показывает общий носитель подсказок страницы). Пустое описание подсказки не
даёт: пустая всплывашка читалась бы как поломка.

## Проверки

Тест страницы: строка получает подсказку из описания, пустое — нет. Прогон
страницы: у проекта с описанием подсказка есть, у проекта без описания — нет.
