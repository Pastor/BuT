# Исправление: ловушка разброса не переживала замедления

> Фича: [../features/0272-build-measurement-harness.md](../features/0272-build-measurement-harness.md) · отчёт: [../features/0272-build-measurement-harness.md#отчёт-о-тестировании](../features/0272-build-measurement-harness.md#отчёт-о-тестировании)

## Проблема

`scripts/test-measure-precheck.sh` провалил **второе** условие («разброс сверх
порога ловится») в прогоне предкоммита 2026-08-23 при закрытии [комментарий перед блочным оператором уезжает внутрь блока](../features/0406-format-comment-before-block.md):

```
ПРОВАЛ: разброс НЕ пойман: Замер времени прогона (фича 0272): …/uneven.sh
  замер 1…
    3 с
  замер 2…
    3 с
  меньший прогон: 3 с, больший: 3 с, разброс: 0 %
  ЗАМЕР ГОДЕН: берите меньшее — 3 с (разброс 0 % ≤ 20 %).
```

Повторный прогон тем же скриптом сразу после — зелёный. К предмету фичи
отношения не имеет: контроль проверяет обвязку замера, а правка касалась печати
комментариев форматтером.

## Причина

Ловушка строилась на паре `sleep 1` / `sleep 3`. Обвязка меряет время **целыми
секундами** (`date +%s`), и под нагрузкой первый прогон растягивается: `sleep 1`
измеряется как 3 с, второй — те же 3 с, разброс 0 %, и «негодный замер»
объявляется годным. Ловушка ловила не дефект, а незанятость машины.

Тот же класс, что у [контроль обвязки замера падал под нагрузкой](0272-01-measure-guard-flaky.md), — там под нагрузкой падало **первое**
условие, и порог ему ослабили. Соседнее условие тогда не тронули: разница
казалась трёхкратной и «гранулярностью не объяснимой». Замер показал, что
объяснима — при округлении вверх обеих величин.

## Исправление

Контраст пары увеличен: `sleep 1` / `sleep 6`. Даже при замедлении обоих
прогонов на пару секунд отношение остаётся кратным (3 с против 8 с — 166 %),
то есть заведомо выше порога 20 %.

## Проверка

`bash scripts/test-measure-precheck.sh` — все четыре условия проходят; полный
`./scripts/precheck.sh` — код 0.

Класс остаётся: любая ловушка, построенная на **времени**, обязана иметь
запас на замедление. Секундная гранулярность `date +%s` — свойство обвязки, а
не случайность прогона.
