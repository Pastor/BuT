# Исправление: стиль графов верификации (равный радиус, шрифт ГОСТ тип А) + поля документа

> Фича: [../features/0124-verify-graph-export.md](../features/0124-verify-graph-export.md) · потребитель диаграмм — раздел «Практический пример» ([исправление](0118-01-practical-example.md))

## Проблема

По требованию заказчика к диаграммам графов (Крипке/Бюхи/произведение, экспорт
`taktc verify --emit-graph`), встроенным в раздел «Практический
пример»:

1. **Разный радиус вершин.** Круги подгонялись под длину подписи (`GoingDown`
   давал больший круг, чем `GoingUp`) — граф выглядел неаккуратно.
2. **Подписи не тем шрифтом.** Требовался чертёжный шрифт **ГОСТ тип А
   (наклонный)** — стандарт инженерной графики (ГОСТ 2.304-81).
3. **Слишком широкие поля PDF** — умолчание `geometry` (~2.5 см) давал избыточные
   поля.

## Причина

Эмиттер DOT (`verification/dot.rs`) задавал узлам `shape=circle` без
`fixedsize` — Graphviz растил круг под подпись; шрифт был `monospace`. Поля PDF
брались по умолчанию пакета `geometry`. Шрифт ГОСТ тип А в системе отсутствовал.

## Решение

- **Равный радиус вершин** (`verification/dot.rs`, общий помощник `graph_header`):
  `node [shape=circle, fixedsize=true, width=0.5, height=0.5, …]` — все круги
  одного (компактного) размера; стрелки рёбер уменьшены (`edge [arrowsize=0.7]`). Служебные точки-источники (`shape=point`) переопределяют `width`
  у себя и на равенство радиусов состояний не влияют.
- **Компактные подписи вершин + легенда** (`node_label`/`legend_label`,
  `subscript`): в кругах — `S` с **подстрочным** номером (`S₁`, `S₂`, … — Unicode
  ₀–₉, глифы есть в шрифте ГОСТ, флаттерятся в контуры без потерь), а расшифровка
  (`S₁ — Waiting`, `S₂ — GoingDown`, …) — **легендой** снизу рисунка (`label`
  графа, `labelloc=b`, `labeljust=l`, `\l`-строки). Для произведения запись пары —
  `Sᵢ — состояние, qN`; для Бюхи — `Sᵢ — {литералы}`.
- **Шрифт подписей — ГОСТ тип А наклонный** (`GRAPH_FONT = "GOST 2.304-81"`):
  имя семейства свободного шрифта `GOST2.304-81TypeA-Slanted.ttf` (проект
  Metrolog/Font.GOST2.304-81). Дефис в имени экранировать не нужно —
  Graphviz задаёт семейство напрямую (в отличие от `fc-match`, чей парсер принял
  бы `-81` за размер). Установлен **только наклонный** вариант → семейство
  резолвится именно в него.
- **Самодостаточный SVG (подписи → контуры)** — `book/scripts/svg_flatten_text.py`
  (`fontTools`): переводит `<text>` вывода Graphviz в векторные `<path>` глифами
  наклонного ГОСТ. Итоговый SVG показывает наклонный ГОСТ **в любом просмотрщике
  и в PDF без установленного шрифта**. Причина: `rsvg-convert` игнорирует
  встроенный `@font-face` (проверено), а голая ссылка `font-family` в системе без
  шрифта (или с обоими вариантами) наклон теряет — контуры снимают зависимость
  начисто. Конвейер регенерации — `book/scripts/render_verify_graphs.sh`
  (`taktc verify --emit-graph → dot -Tsvg → svg_flatten_text.py`).
- **Авто-регенерация графов перед сборкой** (`book/Makefile`, цель `graphs` —
  зависимость `build`/`check`): устраняет ручной шаг. Собирает `taktc` и гоняет
  `render_verify_graphs.sh` (`taktc → dot -Tsvg → svg_flatten_text.py`). Best-effort
  — при отсутствии `cargo`/`dot`/`python3`+`fontTools`/шрифта регенерация
  пропускается, берутся закоммиченные (самодостаточные) SVG, сборка не валится.
  Воспроизводимо: перегенерация даёт байт-в-байт те же SVG.
- **Авто-установка шрифта** (`book/Makefile`, цель `fonts`, best-effort): при
  отсутствии семейства `GOST 2.304` качает наклонный TTF из релиза Metrolog в
  каталог пользовательских шрифтов (по ос) + `fc-cache`. Идемпотентно; сбой
  загрузки не валит сборку.
- **Поля документа 1.5 см** (`book/book.toml`): `geometry = ["margin=1.5cm"]`.

## Проверки

- `cargo test -p takt-lang --lib verification::dot` — 6/6 (структура DOT цела).
- Флаттеринг: в SVG раздела `<text>` = 0, подписи — `<path>`; рендер `rsvg-convert`
  **без установленного шрифта** даёт наклонный ГОСТ (проверено осмотром PNG всех
  трёх графов, вкл. спецсимволы `{ } ! ,` и двухстрочную подпись Бюхи).
- Рендер `dot -Tpng`: все круги одного радиуса.
- `make -C book fonts` — идемпотентно; `make -C book build` — PDF собирается,
  страница графа показывает наклонный ГОСТ и равные вершины, поля 1.5 см
  (проверено рендером страницы). 89 страниц.
- `./scripts/precheck.sh` — зелёный.
