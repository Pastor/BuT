# Исправление 0539-05: несохранённая расстановка схемы теряется при перезагрузке

> Фича: [графическое представление модели — раскладка состояний и рёбер в отдельном файле](../features/0539-model-layout-ui.md)

## Проблема

Автор двигает узлы схемы, не сохраняет и перезагружает страницу (либо заново
открывает модель) — узлы стоят там, где стояли в сохранённом файле раскладки, а
расстановка пропала. Заказчик попросил перепроверить, когда координаты
схемы сохраняются и загружаются, 2026-09-10.

## Причина

Координаты живут в двух местах: в файле `.takt-ui` проекта (запись по
«Сохранить» и при закрытии проекта) и в черновике браузера (через 0,4 с после
каждой правки схемы, вместе с текстом модели). При открытии модели черновик
читался только в одном случае — когда **текст модели** в нём отличался от
сохранённого. Правка одной схемы текст модели не меняет, и черновик с
расстановкой пропускался: схема получала раскладку из файла проекта.

## Решение

При открытии модели с неизменным текстом раскладка черновика берётся, если она
по смыслу отличается от сохранённой: сравниваются канонические формы, пустая
раскладка черновика ничего не перекрывает. Страница говорит «Схема взята из
черновика» — работа не сохранена, и автор должен это видеть. Правило живёт одной
функцией `layout.preferDraft`.

## Проверки

Тест раскладки: подвинутый узел берётся из черновика; та же раскладка в другой
записи, пустой черновик и его отсутствие — нет; при отсутствующем файле
раскладки расстановка черновика берётся. Прогон страницы: узел подвинут без
сохранения, страница перезагружена — узел на новом месте, сообщение показано.
