# Исправление 0564-02: полоса действий молчит при открытии сценария

> Фича: [управление файлами в структуре проекта](../features/0564-project-file-actions.md)

## Проблема

Проект, чей активный файл — сценарий, открывался наполовину: состав файлов
показан, а полоса действий осталась полосой закрытого проекта — ни закрыть, ни
завести файл, ни выгрузить. Нашлось проверкой закрытия проекта 2026-09-10.

## Причина

У открытия файла три ветви: сценарий назначается активным и показывается своим
полем, раскладка открывает парную модель со схемой, прочее читается с сервера.
Обновление полосы стояло только в третьей — две первые уходили `return` молча.

Пока активным файлом проекта была модель, класс не проявлялся: третья ветвь
срабатывала первой и всё чинила. Стоило назначить активным сценарий — и полоса
переставала отвечать вовсе.

## Решение

Полосу обновляют все три ветви: открытие сценария и открытие раскладки — такое
же открытие файла, как и всякое другое.

## Проверки

Набор веб-части: тест считает ветви раннего выхода в открытии файла и требует,
чтобы обновлений полосы было не меньше (падает числами). Прогон страницы:
проект с активным сценарием открывается с полным набором кнопок.
