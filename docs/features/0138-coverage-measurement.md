### Context

Покрытие тестами **не измеряется**. При этом в корне лежит `codecov.yml`,
создающий видимость обратного:

```yaml
comment: false

ignore:
  - derive/src/lib.rs
  - pest/examples/parens.rs
  - pest/src/unicode/*
```

Ни одного из этих путей в репозитории нет — это остаток конфигурации проекта
`pest`. В `.github/workflows/ci.yml` нет ни `cargo-llvm-cov`, ни `tarpaulin`, ни
выгрузки отчёта; `cargo-llvm-cov` не установлен и локально.

Знать непокрытые ветви проекту полезно предметно: дефекты не раз находились
именно на путях, которых не касался ни один тест — цель `c-hal` не компилировалась
ни одним проверкой (0098), `SE-003` печаталась без позиции (0130), приёмка `rust`
нашла отсутствие сверки при зелёном проверке (0050).

#### Обстоятельство, определяющее объём

**GitHub Actions заблокированы по биллингу**: прогоны не стартуют. Всё
написанное в `ci.yml` сегодня **непроверяемо** — а фича уже разбирала
ровно этот класс риска (CI нёс собственную реализацию проверок, разошедшуюся с
`precheck.sh`, и это жило в «зелёном» CI).

### Decision Drivers

1. **Не создавать видимость проверки.** Чужой конфиг хуже отсутствующего: он
   сообщает, что покрытие настроено.
2. **Не писать вслепую.** Шаг CI, который нельзя запустить, — не гарантия, а
   декларация.
3. **Покрытие — инструмент поиска, а не цель.** Процент сам по себе ничего не
   гарантирует; ценность — в списке мест, которых не касается ни один тест.
4. **Предкоммит не должен дорожать.** Инструментация стоит минут; `precheck.sh`
   гоняется на каждое изменение.

### Considered Options

#### Развилка A: объём

| Вариант | Существо | Итог |
|---|---|---|
| **A1. Локальный замер + удалить чужой конфиг** | `codecov.yml` удаляется; заводится `scripts/coverage.sh` для запуска по требованию; разовый замер идёт в отчёт фичи | **принят** |
| A2. Только удалить конфиг | Минимум; цифр не получаем | отвергнут: вопрос «где слепые зоны» остаётся без ответа |
| A3. Полный вариант с CI | Плюс шаг в `ci.yml` с выгрузкой | отвергнут: CI не запускается, шаг остался бы непроверенным (драйвер 2) |

#### Развилка B: порог

| Вариант | Существо | Итог |
|---|---|---|
| **B1. Без порога** | Скрипт запускается по требованию; проверки нет | **принят** |
| B2. Порог-храповик | Заморозить процент, запретить снижение | отвергнут: требует прогона покрытия на каждом предкоммите (драйвер 4) и подталкивает к тестам ради процентов |

### Decision

1. **`codecov.yml` удаляется.** Он описывает чужой проект и вводит в
   заблуждение.
2. **Заводится `scripts/coverage.sh`** — обёртка над `cargo llvm-cov`, запуск по
   требованию. В `precheck.sh` **не подключается**.
3. **Разовый замер** выполняется в рамках фичи, и его результат — проценты по
   крейтам плюс список наименее покрытых модулей — идёт в **отчёт**. Ценность
   фичи в этом списке, а не в самом факте настройки инструмента.
4. **В CI ничего не добавляется**, пока Actions заблокированы. Когда блокировка
   снимется, вопрос вернётся вместе с кандидатом «дожать CI-верификацию 0090».
5. **Порога нет.** Покрытие — справочная величина.

**Что именно считать результатом фичи.** Не «покрытие измеряется», а
«названы места, которых не касается ни один тест». Первое — про инструмент,
второе — про проект; проверяться будет второе.

| Подзадача | Содержание |
|---|---|
| `0138-01` | удаление `codecov.yml`; `scripts/coverage.sh`; README |
| `0138-02` | разовый замер, разбор слепых зон, кандидаты по итогам |

### Consequences

#### Положительные

- Видимость настроенного покрытия исчезает — остаётся честное «не измеряется
  автоматически, измеряется по требованию».
- Появляется список слепых зон — материал для будущих фич.
- Предкоммит не дорожает.

#### Отрицательные / Action items

- Покрытие **не отслеживается непрерывно**: снижение никто не заметит. Это цена
  отказа от порога, принятая осознанно.
- `scripts/coverage.sh` требует `cargo-llvm-cov` и компонента `llvm-tools`;
  их отсутствие — **мягкий пропуск** с подсказкой, как поставить (образец —
  `ensure-iec2c.sh`, который никогда не валит предкоммит).
- Замер разовый: цифры в отчёте устареют. Поэтому в отчёт идут не только
  проценты, но и **выводы** — какие именно места слепы и почему.

#### Acceptance criteria

1. `codecov.yml` удалён; в репозитории нет конфигурации покрытия, описывающей
   чужие пути.
2. `scripts/coverage.sh` запускает измерение и печатает сводку; без
   установленного инструмента — понятное сообщение и код возврата 0.
3. Скрипт **не** вызывается из `precheck.sh`; время предкоммита не изменилось.
4. Отчёт фичи содержит проценты по крейтам и **поимённый** список наименее
   покрытых модулей с разбором, почему они слепы.
5. Находки замера, требующие работы, вынесены кандидатами.
6. `./scripts/precheck.sh` зелёный.

## Разработка

### Задача

#### Что было

Покрытие не измерялось нигде: ни в `ci.yml`, ни локально. При этом в корне лежал
`codecov.yml` — шесть строк, исключающих из покрытия `derive/src/lib.rs`,
`pest/examples/parens.rs`, `pest/src/unicode/*`. Ни одного из этих путей в
репозитории нет: конфигурация чужого проекта (`pest`), создающая видимость
настроенного измерения.

#### Что сделано

1. **`codecov.yml` удалён.** Ссылок на него в README и `.github/` не было —
   проверено грепом, чинить нечего.
2. **`scripts/coverage.sh`** — обёртка над `cargo llvm-cov`: сводка по крейтам
   (по умолчанию), `--html` (отчёт в `target/llvm-cov/html`), `--files`
   (построчная таблица). Мягкий пропуск без инструмента: печатает команды
   установки и завершается кодом 0 — образец `ensure-iec2c.sh`.
3. **README, раздел «Тестирование»** — как померить и почему это **не проверка**.

**`--features lsp` в скрипте обязателен.** Без него модули языкового сервера
не собираются и выпадают из измерения **целиком** — та же ловушка, что с их
тестами: обычная `cargo test` их не видит.

**Скрипт намеренно не подключён к `precheck.sh`**, и это записано в его шапке.
Инструментированная сборка не переиспользует обычные артефакты и стоит минут, а
порога нет (решение заказчика): покрытая строка не значит проверенное поведение —
проект не раз ловил дефекты именно в **покрытом** коде.

#### Проверки

```sh
sh -n scripts/coverage.sh                 # синтаксис
PATH=/usr/bin:/bin sh scripts/coverage.sh # мягкий пропуск: подсказка, код 0
grep -rn "coverage" scripts/precheck.sh   # пусто — не гейт
./scripts/precheck.sh                     # EXIT=0
```

### Задача

#### Что было

Цифр не было вовсе: покрытие не измерялось ни разу, и вопрос «какие места кода
не трогает ни один тест» оставался без ответа.

#### Что сделано

Проведён замер `cargo llvm-cov --workspace --features lsp` (`cargo-llvm-cov
0.8.7`, толчейн `1.97.1`, 2400+ тестов, однопоточно).

##### Итог

| Крейт | Покрытие строк |
|---|---|
| `takt-lang` | **79.22 %** (26 958 из 34 030) |
| `takt-sim` | **77.93 %** (4 674 из 5 998) |
| Всего | 79.02 % строк, 86.62 % функций, 76.66 % регионов |

##### Главная находка: `documentSymbol` не проверяется ничем

`takt-lang/src/lsp/symbols.rs` — **0 %** при 183 строках. Проверено отдельно:
`document_symbols` не упоминается **ни в одном** тесте, юнит-тестов в самом
файле нет. При этом возможность **объявлена** клиенту в `ServerCapabilities`,
то есть редактор её вызывает, а сервер отвечает вслепую.

Это ровно тот класс, ради которого замер и делался: возможность есть, проверка
зелёный, тестов нет.

| `generator/rust/rust_cond.rs` | 25 % | у цели `rust` **один** тестовый файл, зовущий `compile_to_rust`; печатники проверяются в основном проверкой сборки корпуса, а корпус мал |

##### Что замер не означает
