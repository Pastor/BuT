## Итог (что сделано)

Наполнен раздел `book/src/05-expressions/index.typ` (язык не меняется,
Tier 3; ADR/анализ не требовались):

- **Условия** (`ref`, `if`/`while`) — логическое значение; `&`/`|`/`!` —
  логические И/или/не (одиночные знаки), сравнения, `+`/`-`, обращение к
  члену, `S(Модель)`.
- **Выражения** (тела блоков/функций) — вычисление и присваивание; таблица
  операторов (арифметика/побитовые/логические `&&`/`||`/сравнения/`:=`/тернарный
  `?:`/`as`).
- **Ключевое различие** (сверено с грамматикой `grammar.lalrpop`): `&`/`|` —
  **логические** в условиях, но **побитовые** в выражениях (логические в
  выражениях — `&&`/`||`).
- **`:=` vs `=`** (присваивание vs сравнение; `==` в языке нет).
- **Приоритет операторов** — полная лестница (обращение/унарные/`**`/`*`÷/`+-`/
  сдвиги/`&`+`as`/`^`/`|`/сравнения/`=`/`&&`/`||`/`:=`+`?:`), сверена с цепочкой
  `Chain14…Atom`.
- **Доступ к члену**: `.поле`, `.бит`, `[i]`, срез `[l:r]`.
- Пример `book/src/05-expressions/examples/expr.takt` — **компилируется** `taktc`
  (цель `c`, EXIT 0): условия с `&`/`|`, выражения с `+`/`*`/`:=`/`=`/тернарным.
