## Краткое описание

Кандидат 0027 ссылался на «лимит ~1000 (`CLAUDE.md`, `docs/CODE.md`)», но в
`docs/CODE.md` такого правила **нет** — единственный источник `CLAUDE.md:128`, то
есть файл **живого контекста** (правило 9), а не **свод правил кода** (правило 23).

Лечение: перенести правило в `docs/CODE.md`.

Выявлено при [разделение переросших модулей (validate.rs, lsp.rs, c_expr.rs)](0027-module-size-split.md).

## Архитектура (ADR)

- **Status:** Accepted
- **Date:** 2026-07-22
- **Authors:** Архитектор + Аналитик
- **Related issues:** [Фича](0091-module-size-rule-in-code-md.md); истоки — [ADR](0027-module-size-split.md#архитектура-adr); выявлено при 0027

### Context

Правило «размер модуля — не больше ~1000 строк (вместе с тестами); дели по логике»
живёт **только** в `CLAUDE.md:741` — файле **живого контекста** (правило 9). Но это
**правило написания кода**, а свод таких правил — `docs/CODE.md` (правило 23).
Кандидат 0027 уже ссылался на «лимит ~1000 (`CLAUDE.md`, `docs/CODE.md`)», но в
`docs/CODE.md` его нет — ссылка вводит в заблуждение.

Запись в `CLAUDE.md` **смешивает** два слоя: собственно **правило** (место —
`docs/CODE.md`) и **живой контекст** (реестр долга `module-size-baseline.txt`,
статус уже выполненных разделений, поведение храповика — место в `CLAUDE.md`,
правило 9).

### Decision Drivers

1. **Правило кода — в своде кода** (правило 23): `docs/CODE.md` — канонический и
   первый читаемый источник правил Rust-кода.
2. **Разделение слоёв** (правило 9): живой контекст (реестр, статус) остаётся в
   `CLAUDE.md`; дублирования правила быть не должно.
3. **Минимальность.** Правка документационная; код, проверка и реестр не трогаются
   (правило уже машинно проверяется).

### Considered Options

#### Option A. Правило — в docs/CODE.md; в CLAUDE.md — указатель + живой контекст

Формулировка правила (лимит, «дели по логике», машинная проверка `check-module-size.sh`,
семантика реестра-долга) добавляется секцией в `docs/CODE.md`. В `CLAUDE.md`
формулировка правила заменяется **указателем** на `docs/CODE.md`, а живой контекст
(реестр — узаконенный долг, ратчет, выполненные разделения) остаётся.

**Pros:**
- Правило там, где его ищут (драйвер 1); слои разделены, дубля нет (2);
  минимально (3).

**Cons:**
- Нужно аккуратно вырезать из `CLAUDE.md` только формулировку, не потеряв контекст.

#### Option B. Продублировать правило в docs/CODE.md, CLAUDE.md не трогать

**Pros:**
- Меньше правок.

**Cons:**
- Дублирование правила в двух местах → дрейф формулировок (прецедент: правило
  версии языка жило только в README и разошлось). Нарушает драйвер 2.

### Decision

Принимается **Option A**. Правило — в `docs/CODE.md` (новая секция «Размер
модулей»); в `CLAUDE.md` формулировка заменяется указателем на свод, живой контекст
(реестр-долг, ратчет, разделения) сохраняется. Заодно исправляется устаревшее число
файлов реестра в `CLAUDE.md` (было «22», фактически **18** — долг снижался фичами).

Код, проверка `check-module-size.sh` и реестр `module-size-baseline.txt` **не
трогаются** — правило уже машинно проверяется (0027); 0091 лишь ставит его
формулировку на место.

### Consequences

#### Положительные

- Правило кода находится в каноническом своде (правило 23); ссылка «см.
  `docs/CODE.md`» кандидата 0027 перестаёт вводить в заблуждение.
- Слои `CLAUDE.md` (контекст) и `docs/CODE.md` (правила) разделены; дубля нет.

#### Отрицательные / Action items

- Формулировка правила теперь в двух документах не дублируется, но `CLAUDE.md`
  ссылается на `docs/CODE.md` — при изменении лимита править **свод** (одно место).

#### Acceptance criteria

1. `docs/CODE.md` содержит правило о размере модуля (лимит ~1000, «дели по логике»,
   машинная проверка, семантика реестра-долга).
2. `CLAUDE.md` не дублирует **формулировку** правила — ссылается на `docs/CODE.md`;
   живой контекст (реестр, ратчет, разделения) сохранён; число файлов актуально (18).
3. Ссылки целы (`check-links`), `precheck.sh` зелёный. Код/вывод/поведение не
   затронуты; версии не поднимаются.

## Анализ

### Цель и контекст

Правило о размере модуля (правило **кода**) живёт только в `CLAUDE.md` (живой
контекст, правило 9), а не в своде `docs/CODE.md` (правило 23). Перенести
формулировку в свод; в `CLAUDE.md` оставить указатель + живой контекст. Решение —
Option A ADR.

### Зависимости фичи (правило 17/19)

- **Зависит от:** **нет.** Затрагивает только `docs/CODE.md` и `CLAUDE.md`. Код,
  проверка `check-module-size.sh`, реестр `module-size-baseline.txt` — **не** трогаются
  (правило уже машинно проверяется, 0027).
- **Влияние на порядок разработки:** не блокирует других.

### Требования и проверяемые условия

- **R1. Правило в своде.** `docs/CODE.md` содержит правило: размер модуля ≤ ~1000
  строк (вместе с тестами), «дели по логике», машинная проверка
  `scripts/check-module-size.sh` (precheck+CI) против реестра-долга
  `module-size-baseline.txt` (файл оттуда не имеет права расти; уложившийся в лимит
  обязан быть удалён).
- **R2. CLAUDE.md — указатель + контекст.** Формулировка правила в `CLAUDE.md`
  заменена ссылкой на `docs/CODE.md`; **дубля нет**. Живой контекст (реестр —

  актуализировано (22 → **18**).
- **R3. Целостность.** Ссылки целы (`check-links`), `precheck.sh` зелёный.
- **R4. Аддитивность.** Код/вывод/поведение не затронуты; версии не поднимаются.

## Разработка

### Задача

#### Что было

Правило «размер модуля ≤ ~1000 строк; дели по логике» жило только в `CLAUDE.md`
(живой контекст, правило 9), смешанное с живым контекстом (реестр-долг, статус
разделений). Свод кода `docs/CODE.md` (правило 23) правила не содержал — ссылка
кандидата 0027 «см. `docs/CODE.md`» вводила в заблуждение.

#### Что сделано

Реализована **Option A** [ADR](0091-module-size-rule-in-code-md.md#архитектура-adr).

- **`docs/CODE.md`:** новая секция **«Размер модулей»** — лимит ~1000 строк (вместе
  с тестами), «дели по логике» (границы модулей = границы ответственности; образцы
  разделения), машинная проверка `scripts/check-module-size.sh` в `precheck.sh`/CI,
  семантика реестра-долга `module-size-baseline.txt` (замораживает; правка записи —
  только уменьшение; уложившийся в лимит удаляется), история (`validate.rs` дорос до
  3654 до фичи).
- **`CLAUDE.md`:** формулировка правила заменена **указателем** на
  `docs/CODE.md`; живой контекст сохранён (реестр-долг, ратчет «готовься к отказу
  «вырос»», выполненные разделения `validate/`/`lsp/`/`c_expr/`/`index/`). Число
  файлов реестра актуализировано **22 → 18** (долг снижался фичами); добавлена
  ссылка на остаток-фичу.

| Функциональность | Статус |
|---|---|
| правило в `docs/CODE.md` | ✅ секция «Размер модулей» |
| `CLAUDE.md` — указатель + контекст, 18 файлов | ✅ дубля нет |
| код/проверка/реестр | н/п — не тронуты |

#### Проверки

- `scripts/check-links.py` → ссылок нет битых.
- `grep` подтверждает: формулировка правила в `CLAUDE.md` заменена ссылкой; живой
  контекст (реестр, ратчет, разделения) на месте; число «18».
- Код крейтов, проверка `check-module-size.sh`, реестр не тронуты.
- Полный `./scripts/precheck.sh` → зелёный (см.
  [отчёт](0091-module-size-rule-in-code-md.md#отчёт-о-тестировании)).
