## Краткое описание

Из полосы управления убраны кнопки «Мои проекты» и «Открытые проекты»: проекты
открываются из структуры проекта, витрина открытых проектов на странице больше
не нужна. Панель учётной записи — способы входа и пароль — открывает логин в
шапке.

### Context

Список проектов переехал в структуру проекта, и кнопка «Мои проекты» открывала
уже только панель учётной записи: выход (он есть и у кнопки входа), установку
пароля и привязанные площадки. Замер: к паролю и площадкам другого пути на
странице не было — убери кнопку без замены, и они стали бы недоступны.

### Decision

- **Кнопки убраны**, витрина открытых проектов снята со страницы целиком: её
  разметка, обработчики и модуль ленты `showcase.js`. Ручка сервера витрины и
  страница открытого проекта `/p/<id>` остаются.
- **Панель учётной записи открывает логин в шапке**: по виду подпись, по сути
  кнопка; виден он только вошедшему — ровно тогда, когда панели есть что
  показать.

### Consequences

Поиска по открытым проектам на странице нет; проект открывается ссылкой, которой
делится автор.

1. Разметка: кнопок и витрины нет; логин открывает панель учётной записи.
2. Прогон страницы: страница загружается без отказов, щелчок по логину
   показывает способы входа.
