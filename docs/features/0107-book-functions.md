## Итог (что сделано)

Наполнен раздел `book/src/07-functions/index.typ` (язык не меняется,
Tier 3; ADR/анализ не требовались):

- **Определение** `fn имя(параметры) -> Тип { … return …; }` (стрелка/тип
  необязательны, если нет возврата).
- **Вызов** как выражение; **композиция** (функция вызывает функцию, порядок —
  за компилятором); **рекурсия запрещена**.
- **Внешние функции** `extern fn` (объявление без тела, реализация — с
  платформы; вызов как обычной).
- **Параметры/типы**: любой тип языка, включая составные (`[bit; N]`, структуры,
  перечисления).
- Пример `book/src/07-functions/examples/functions.takt` — **компилируется**
  `taktc` (цель `c`, EXIT 0): `extern fn`, `double`, композиция `quad→double`,
  вызовы из тела. Сниппет с `[bit;8]`-параметром проверен отдельно.
