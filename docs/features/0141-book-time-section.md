## Итог (что сделано)

Раздел написан по образцу существующих (своду–27): изложение по
конструкциям, **функциональный пример из практики** — вытяжной вентилятор с
выбегом (свет погас → вентилятор работает ещё три минуты; включили свет снова →
выдержка отменяется), разбор с числовыми выносками `(1)…(4)`, трасса реального
прогона и блок «Частые ошибки» со ссылкой на приложение.

Пример проверен **симуляцией** со сценарием: выбег срабатывает ровно через
180 000 мс после входа в состояние, а не от начала прогона.

**Временная ветка в проверке примеров.** Проверка (`precheck.sh`)
компилирует примеры документа целью `c`, а она конструкции времени пока
отвергает (эмиссию вводит задача `0134-04`). Поэтому пример с временем
компилируется целью `plantuml`, и проверка **прямо это печатает**:
`fan.takt → компилируется целью plantuml (цель c ещё не поддерживает время) и
симулируется`. Молчаливого пропуска нет. **Ветка снимается задачей** —
записано в карточке [модель времени в языке: литерал длительности и частота такта](0134-language-time-model.md).

**Ограничение языка, вскрытое при написании примера:** `after` принимает
только **литерал**, а не именованную константу (`const OVERRUN := 3m;
ref Idle: after OVERRUN;` не разбирается). В примере пришлось написать литерал.
Вынесено кандидатом в [`FEATURES.md`](../../FEATURES.md).
