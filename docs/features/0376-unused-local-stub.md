## Краткое описание

Замер-21 на `var spare: u8 := n + 5;` без единого обращения:

| Потребитель | Ответ |
|---|---|
| эталон | исполняет |
| `c`, `c-hal` | **`cc -Wall -Wextra -Werror`: unused variable 'spare' [-Wunused-variable]** |
| `rust` | **`rustc -D warnings`: unused variable: `spare`** |
| `st`, `st-at` | `iec2c` принял · `cc` собрал |
| `sv`, `sv-mmio` | verilator принял · yosys синтезировал |

Вывод двух целей **не собирается** под флагами их же проверок при **нулевом**
коде возврата `taktc`.

Смежно: `SE-036` («переменная не используется») локальные объявления тел
**не видит** — проба это показала; предупреждения автор не получает.

## Документирование

**Не требуется** — язык не меняется: запись законна и исполняется эталоном.

### Context

Локальная переменная, объявленная и ни разу не использованная, ломает проверки
целей `c` (`-Wunused-variable`) и `rust` (`unused variable`) при нулевом коде
возврата `taktc`. Цели `st` и `sv` тот же вход принимают, эталон исполняет.

Класс — продолжение 0260/0337: там гасились **параметры**, здесь — **локальные
объявления тел**.

### Decision Drivers

1. **Вывод обязан собираться флагами проверки своей цели.**
2. **Отказывать нельзя:** запись законна и исполняется эталоном; у неё есть
   смысл (заготовка, отладка).
3. **Признак — один на цели, идиома — своя у каждой** (образец 0337).
4. **Ошибка признака не должна быть тихой.**

### Considered Options

#### Option A. Заглушка по нужде, признак по семантическому дереву (принято)

`(void)x;` у `c`, `let _ = x;` у `rust` — печатаются в конце блока, где
переменная ещё в области видимости. Признак —
`generator::local_stub::unused_locals(block)`: имена объявлений верхнего уровня
блока, которых нет в `usage_from_stmt` этого блока.

**Pros:**
- Отвечает ровно на вопрос компилятора («имя нигде не используется»).
- Сборщик имён уже есть и открыт генератору (его зовёт цель `st`).
- Область видимости учитывается сама: вопрос задаётся блоку объявления.

**Cons:**
- Признак по дереву, а не по напечатанному тексту (0260/0337 делали иначе) —
  но там речь шла о параметре, чьё тело уже напечатано.

#### Option B. Не печатать само объявление

**Cons:** инициализатор бывает с эффектом (вызов функции), и его потеря —
молчаливое изменение поведения. Ровно этот класс правила и 0306.

#### Option C. Диагностика семантики (`SE-036` на локальные)

**Cons:** предупреждение автору полезно, но вывод целей оно не чинит — они
по-прежнему не собирались бы. Вынесено кандидатом отдельно.

#### Option D. Отключить предупреждение флагом проверки

**Cons:** проверка перестал бы ловить настоящие находки (класс: `lint_off`
гасит контроля, а не причину).

### Decision

Принимается **Option A**. Заглушка печатается **в конце блока**: там переменная
ещё видима, а порядок операторов не меняется.

### Consequences

#### Положительные

- Вывод `c` и `rust` собирается под флагами проверок на записи, которую эталон
  исполняет.
- Признак общий, идиома — своя у каждой цели: то же устройство, что у 0337.

#### Отрицательные / Action items

- Класс «локальная записана, но не прочитана» (`-Wunused-but-set-variable`)
  этой фичей не измерялся: признак считает запись использованием.
- `SE-036` локальные объявления по-прежнему не видит — вынесено кандидатом.

#### Acceptance criteria

1. Вывод целей `c` и `rust` на входе с неиспользуемой локальной собирается
   флагами их проверок.
2. Заглушка печатается только там, где переменная не используется
   (контрпример).
3. Вывод корпуса не изменился; предкоммит зелёный.

## Анализ

### Цель и контекст

Кандидат заведён закрытием 0375: там замер по локальным переменным дал три
строки, и фича закрыла столбец `sv`. Эта закрывает оставшиеся два.

#### Замер (`scripts/probe.sh -n 2`, 2026-08-21)

Вход: `var spare: u8 := n + 5;` — объявлена, ни разу не упомянута.

| Потребитель | Ответ |
|---|---|
| эталон | исполняет |
| `c`, `c-hal` | **`cc` ОТВЕРГ:** unused variable 'spare' [-Wunused-variable] |
| `st`, `st-at` | `iec2c` принял · `cc` собрал |
| `rust` | **`rustc` ОТВЕРГ:** unused variable: `spare` |
| `sv`, `sv-mmio` | verilator принял · yosys синтезировал |

`taktc` во всех восьми случаях возвращает **ноль**: класс невидим по кодам
возврата, его показывает только раздел «инструменты целей» пробы (0362).

Проверка пробы прошла: `SE-036` не сработала — то есть
предупреждение «переменная не используется» локальных объявлений **не
касается**, и автор о неиспользуемой локальной не узнаёт ниоткуда.

### Зависимости фичи

- **Зависит от:** нет. 0260 и 0337 (идиомы заглушек), 0375 (столбец `sv`) —
  закрыты.
- **Влияние на порядок разработки:** снимает кандидат «Локальная переменная, не
  используемая вовсе, валит проверки целей `c` и `rust`»; заводит кандидата
  «`SE-036` не видит локальных объявлений».

### Требования и проверяемые условия

- **R1. Проверка `c`.** `cc -std=c11 -Wall -Wextra -Werror -c` собирает вывод.
- **R2. Проверка `rust`.** `clippy-driver -D warnings` принимает вывод.
- **R3. По нужде.** Используемая локальная заглушки не получает.
- **R4. Область видимости.** Заглушка стоит в том блоке, где переменная
  объявлена.
- **R5. Один признак.** Вопрос «используется ли имя» задаётся общим носителем,
  а не двумя копиями у целей.
- **R6. Неизменность.** Вывод корпуса не меняется.

### Критерии приёмки и способ проверки

| # | Критерий | Способ проверки |
|---|---|---|
| A1 | R1, R2 | `generated_output_passes_target_gates` (прогон `cc` и `clippy-driver`) |
| A2 | R3 | `used_local_gets_no_stub` |
| A3 | R4 | `unused_local_gets_a_stub` (текст: заглушка в теле блока) |
| A4 | R5 | юнит-тесты `generator::local_stub` + отсутствие второго обхода в коде |
| A5 | R6 | `git diff examples/generated/` пуст |

### Особенности по обратной функциональности

Обратная совместимость сохраняется: добавляется строка вывода там, где раньше
вывод не собирался вовсе. Значения не меняются — заглушка эффекта не имеет.

### Риски и зависимости

- **Ошибка в сторону «заглушка не нужна»** даёт отказ проверки — громко.
  **Ошибка в сторону «нужна»** даёт мусорную строку — тихо, поэтому есть
  контрпример.
- **Запись без чтения** (`x := 5;` и больше ничего) признак считает
  использованием: `usage_from_stmt` берёт имя из левой части присваивания.
  Класс `-Wunused-but-set-variable` этой фичей не измерялся — граница названа.

## Разработка

### Задача

#### Что было

Локальная переменная, объявленная и не использованная, печаталась как есть, и
вывод целей `c` и `rust` не собирался под флагами их проверок.

#### Что сделано

- Новый носитель `generator/local_stub.rs`: `unused_locals(block)` — имена
  объявлений **верхнего уровня** блока, которых нет среди использованных имён
  блока (`semantic::unused::usage_from_stmt`, тот же сборщик, что зовёт цель
  `st`).
- **`c`** (`c_expr/stmt.rs`, ветвь `Block`): после операторов блока печатает
  `(void)<имя>;` для каждого такого объявления.
- **`rust`** (`rust_stmt.rs`, `print_block`): то же с `let _ = <имя>;`.
- Имена нормализуются тем же преобразованием, что и объявления
  (`normalize_lowercase_snakecase`), иначе заглушка сослалась бы на несуществующее
  имя.

**Статус по функциональности.** Затронуты `c`/`c-hal` и `rust`;
`st`/`st-at`, `sv`/`sv-mmio` (там своя форма, 0375), `plantuml` и эталон —
**н/п**.

#### Проверки

```sh

./scripts/probe.sh -n 2 <проба>.takt     # все восемь целей: инструменты приняли
```

## Итог (что сделано)

- Неиспользуемая локальная получает заглушку: `(void)x;` у `c`, `let _ = x;` у
  `rust`. Идиома принадлежит целевому языку, а **признак общий** —
  `generator::local_stub::unused_locals`.
- **Признак спрашивает семантическое дерево, а не текст** (в отличие от
  0260/0337): там вопрос был о параметре, чьё тело уже напечатано, здесь — о
  переменной, объявление которой печатается **до** блока. Сборщик имён общий с
  целью `st` (`usage_from_stmt`), второго обхода не заводится.
- **Вопрос задаётся блоку, а не всему телу:** область видимости локальной —
  её блок, и это ровно тот ответ, который даёт компилятор.
- Контрпример обязателен: используемая локальная заглушки не получает —
  иначе правило читалось бы как «гасим любое объявление».
- Вывод корпуса не изменился: неиспользуемых локальных в `examples/` нет.
