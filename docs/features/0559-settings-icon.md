## Краткое описание

Значок кнопки настроек читается как штурвал: обод с восемью спицами наружу.
Шестерёнку узнают по зубцам, сидящим на ободе, а не по лучам от центра. Форма
выбирается заказчиком по показу нескольких начертаний.
