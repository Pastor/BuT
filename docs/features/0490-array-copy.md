# Фича: Копирование массива целиком: переменная и константа справа

- **Номер:** 0490
- **Статус:** ГОТОВО
- **Зависит от:** нет
- **Tier:** 2
- **Класс:** генерация
- **Связанные issue (анализ):** перебор «тип константы × цель» 2026-09-02

## Стадии жизненного цикла

Все стадии — **разделы этой карточки**. Отдельным артефактом
остаются только исправления — [`docs/fixes/`](../fixes/README.md).

## Краткое описание

`seen := src;` над массивами печаталось как присваивание целиком: `c` отвечал
«array type is not assignable», `iec2c` — «Incompatible data types for ':='»,
и оба при **нулевом** коде возврата `taktc`. Тот же вход `rust` и `sv`
переводили — потребители расходились молча. У константы к этому добавлялся
макрос `#define X {1, 2}`, дававший `{1, 2}[0]`.

## Документирование

**Не требуется.** Язык не меняется: запись `a := b;` над массивами была законна
и прежде, менялась **форма вывода** двух целей. Диагностик фича не заводит.

## Архитектура (ADR)

- **Status:** Accepted
- **Date:** 2026-09-02
- **Authors:** архитектор, аналитик

### Context

Матрица 2026-09-02 «агрегат × источник значения × восемь целей» с прогоном
инструментов (нулевой код возврата `taktc` валидности не значит):

| Правая часть | массив | структура |
|---|---|---|
| литерал `{3, 4}` | принимают все | принимают все |
| **переменная** | `c`, `c-hal`: `cc` отверг; `st`, `st-at`: `iec2c` отверг | принимают все |
| **константа** | то же + `#define X {1,2}` → `{1,2}[0]`; у `sv` — `yosys` не синтезировал | принимают все |

Класс **не новый по механизму**: литерал уже разворачивался поэлементно
(0330 у `st`/`sv`, 0340 у `c`), а объявление с инициализатором-переменной — у
`c` (0364). Не покрыт остался **оператор присваивания**, где справа не литерал.

Структура в объём не входит — и это **замер**, а не догадка: её присваивают
целиком и C, и IEC, и все восемь потребителей вход принимают.

### Decision

1. **`c`:** присваивание массива, где справа переменная, печатается
   поэлементно (`c_expr::aggregate::emit_array_copy`).
2. **`c`:** константа-массив объявляется `static const T X[N] = {…};` — тем же
   решением, каким с 0080-02 объявляется константа-структура; макрос
   разворачивался бы в фигурный литерал внутри выражения.
3. **`st`:** то же поэлементное копирование в печатнике операторов.
4. Разворот берёт **только переменную** справа: результат вызова
   индексировать нельзя, его поднимает во временную свой проход (0431).

### Consequences

- Копирование массива переводят все восемь целей; значения совпадают с
  эталоном (тот же поэлементный смысл).
- Бит-вектор `[bit;N≤64]` не затронут: он упакованный **скаляр** (0078) и
  присваивается целиком.
- **Названная граница:** у цели `sv` константа-массив (и константа
  перечислимого типа) остаются несинтезируемыми — `yosys` не принимает
  `localparam` такого вида, хотя `verilator` принимает. Это предмет
  **объявления**, а не присваивания; вынесен кандидатом.

#### Acceptance criteria

1. Копирование массива из переменной и из константы принимают инструменты
   `c`, `c-hal`, `st`, `st-at`.
2. Константа-массив у `c` объявлена массивом, а не макросом.
3. Структура по-прежнему присваивается целиком.
4. Случай «справа вызов функции» не сломан (0431).
5. `./scripts/precheck.sh` зелёный.

## Разработка

### Задача — цель `c`

`c_expr/aggregate.rs`: `emit_array_copy` — поэлементное копирование, когда
справа переменная; `c_decl.rs`: константа-массив печатается `static const`.

### Задача — цель `st`

`st_stmt.rs`: ветвь поэлементного копирования рядом с существующей ветвью
агрегата-литерала.

Первая редакция обеих правок разворачивала **любую** правую часть и сломала
случай 0431 (`got := pair(k);`): `iec2c` отвечал «';' missing» на
`got[0] := pair(k)[0];`. Условие сужено до переменной; поймал полный прогон
тестов, а не проба.

- Копирование массива целиком (`a := b;`) переводят все восемь целей: у `c` и

- Названная граница: у `sv` константа-массив и константа перечислимого типа
  не синтезируются `yosys` (`localparam` такого вида он не принимает) — это
  предмет объявления, вынесен кандидатом.
