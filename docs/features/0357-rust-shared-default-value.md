# Фича: Умолчание общей переменной строит один носитель

- **Номер:** 0357
- **Статус:** ГОТОВО
- **Зависит от:** нет (0059, 0351 закрыты)
- **Связанные issue (анализ):** кандидат «Фолбэк `Default::default()` у общих
  переменных под-моделей» (заведён закрытием 0351)

## Стадии жизненного цикла

Все стадии — **разделы этой карточки**: «Архитектура (ADR)»,
«Анализ», «Разработка», «Тест-план», «Отчёт о тестировании», «Итог».
Отдельным артефактом остаются только исправления —

## Краткое описание

`rust_shared.rs::emit_shared_new_block` печатал общей переменной без
посчитанного инициализатора строку `"Default::default()"` — **второй** носитель
знания «чему равно умолчание типа». Первый — `rust_decl::default_value`, и
фича показала цену расхождения: `Default` у структуры выводится **не
всегда**.

## Документирование

**Не требуется** — язык не меняется; правится внутреннее устройство одной цели,
причём ветвь защитная и достижимого входа не имеет.

## Архитектура (ADR)

- **Статус:** Accepted
- **Дата:** 2026-08-21
- **Фича:** [../features/0357-rust-shared-default-value.md](0357-rust-shared-default-value.md)

### Контекст

Конструктор цели `rust` печатает блок `shared: <Root>Shared { … }`. Значения берутся из `inits` — карты, посчитанной обходом полей
корня; переменной, которой там нет, печаталась строка `"Default::default()"`.

Это **второй** носитель знания «чему равно умолчание типа»: первый —
`rust_decl::default_value`. Фича измерила цену такого дубля на соседнем
месте: `#[derive(Default)]` у структуры выводится не всегда (поле-перечисление,
массив длиннее 32), и опора на `Default` там порождала невалидный вывод.

Зонд 2026-08-21 (`panic!` вместо фолбэка) показал, что достижимого входа у
ветви нет: прошли весь корпус и 13 наборов тестов, включая вход с общей
переменной корня и вход через `from_calls`.

### Решение

**Фолбэк зовёт `default_value(ty, root)`.** Тип есть в `union`, корень — у
карты (`map.root_model_node()`).

**Ветвь сохраняется.** Удаление (по образцу, снявшей мёртвый
`compact_implement`) здесь неуместно: там мёртвой была реализация целиком, с
док-комментарием, обещавшим вызов; здесь — одна строка внутри живого пути, и
её отсутствие означало бы либо панику, либо молчаливый пропуск поля. Замер
доказывает «недостижимо сегодня», а не «недостижимо по построению».

### Отвергнутые варианты

**А. Удалить ветвь, сделав `inits.get(vname)` обязательным (`expect`).**
Превращает недостижимое сегодня в панику завтра — у инструмента, который
обязан отвечать диагностикой (правило R4 эталона, тот же принцип у целей).

**Б. Оставить строку как есть.** Работает, пока `Default` у типа выводится.
Ровно это допущение фича и опровергла на соседнем месте.

### Последствия

- Знание об умолчании типа у цели `rust` живёт в одном месте.
- Вывод не меняется ни на одном входе (ветвь недостижима) — снапшоты корпуса
  прежние.
- Язык не меняется.

### Замер

Расхождения потребителей здесь **нет** — предмет внутренний, поэтому замер
снимался не `probe.sh`, а **зондом**: строка фолбэка заменена на `panic!`,
после чего прогнаны весь корпус (`examples/*.takt`, цель `rust`) и все 13
наборов тестов. Ни одного срабатывания.

Проверены два входа, специально подобранные под ветвь:

1. общая переменная объявлена в корне и меняется под-моделью;
2. переменная корня читается **только** функцией, которую зовёт под-модель
   (ветвь `from_calls` в `shared_variables`).

Оба дали значение из `inits`.

**Вывод замера — «недостижимо сегодня», а не «недостижимо по построению»**:
доказательства второго нет, поэтому ветвь сохраняется, а не удаляется.

### Объём правки

Одна ветвь в `takt-lang/src/generator/rust/rust_shared.rs`. Тип берётся из
`union` (он там уже есть), корень — `map.root_model_node()`.

### Зависимости

**Нет.** 0059 (структура `Shared`) и 0351 (умолчание типа у цели `rust`)
закрыты.

### Обратная совместимость и версия языка

**Язык не меняется, версия не поднимается.** Вывод не меняется ни на одном
входе — ветвь недостижима.

### Редакторский слой

**Правок не требуется, ответ зафиксирован:** правится печать одной цели.

### Риски

- **Ветвь останется непроверяемой.** Принято: её задача — не молчать, если
  вход когда-нибудь появится. Замер и его дата записаны в код, чтобы следующая
  фича не приняла ветвь за живую.

#### Что сделано

`emit_shared_new_block`: вместо строки `"Default::default()"` вызывается
`rust_decl::default_value(ty, &root.borrow())`. Тип берётся из `union`, корень —
у карты.

Замер зондом и его дата записаны в док-комментарий функции: следующая фича не
должна принять защитную ветвь за живую.

#### Ловушки

**Соблазн удалить ветвь.** Замер говорит «недостижимо сегодня» — этого мало
для удаления: `expect` превратил бы недостижимое в панику инструмента, который
обязан отвечать диагностикой.

**Корня может не быть** (`root_model_node()` возвращает `Option`) — там
сохранена прежняя строка: умолчание строить не из чего.

### Особенность: контроля нового не заводится

Правится **защитная** ветвь, у которой нет достижимого входа (замер зондом).
Тест на неё был бы тестом на недостижимое: он либо не компилируется в модель,
либо проверяет не то.

Проверка состоит в другом:

| № | Условие | Как проверено |
|---|---|---|
| П1 | вывод цели `rust` не изменился ни на одном входе | весь корпус + 13 наборов тестов зелёные, снапшоты не тронуты |
| П2 | ветвь недостижима | зонд `panic!` на корпусе и тестах — ни одного срабатывания |
| П3 | вход через `from_calls` тоже не достигает ветви | отдельный вход с функцией корня, вызываемой под-моделью |

### Почему нового контроля не заведено

Ветвь защитная: достижимого входа у неё нет, и тест на неё проверял бы не то,
что называет. Вместо теста в код записан **замер с датой** — чтобы следующая
фича не приняла ветвь за живую и не «дочинила» её обратно в строковую
константу.

Это осознанное исключение из привычки «фича заводит контроля»: контроль без
достижимого входа — декорация (тот же довод, что у ветви `DomainNotEnumerable`
в 0258).

## Итог (что сделано)

- Фолбэк зовёт `default_value(ty, root)` — тип у `union` есть, корень берётся
  у карты. Знание об умолчании осталось **одно**.
- **Ветвь защитная, и это замер, а не догадка.** Зонд 2026-08-21 (`panic!`
  вместо фолбэка) прошёл **весь корпус** и все 13 наборов тестов — включая
  вход с общей переменной корня и вход, где переменная читается только
  функцией, которую зовёт под-модель (ветвь `from_calls`). Переменная попадает
  в `union` из объявлений корня, а `model_fields` корня их и обходит.
- Ветвь **не удалена**: молчаливая подмена умолчания хуже лишнего пути, а
  доказательства недостижимости «по построению» у нас нет — только замер.
