## Стадии жизненного цикла (правило 17)

Все стадии — разделы этой карточки (правило 32).

## Краткое описание

`enum Level { Low = -5, … }` цель `sv` печатала как `LEVEL_LOW = 4'd-5` —
синтаксически неверная форма, которую `verilator` не разбирает. Знак в
**объявлении** перечисления учитывался с фичи, а в **значении** — нет.

## Документирование (правило 24)

Не требуется: язык не меняется.

### Context

**Замер-23** (`scripts/probe.sh`): эталон исполняет (трасса −1, 2, 12,
22), `c`, `c-hal`, `st`, `st-at`, `rust` и `plantuml` переводят и их
инструменты принимают, а `sv`/`sv-mmio` дают

```
%Error: Number is missing value digits: 4'd
    9 |     LEVEL_LOW = 4'd-5,
```

при **нулевом** коде возврата `taktc`.

**Два места одного правила разошлись:** объявление печаталось
`typedef enum logic signed [3:0]` (знак учтён, 0060), а значение — прежней
беззнаковой формой. Класс в миниатюре.

Корпус класс не покрывает: отрицательных вариантов в `examples/` нет.

### Decision Drivers

- Форма литерала обязана соответствовать знаковости объявления.
- Положительные значения менять нельзя — иначе поедет вывод всего корпуса.

### Considered Options

1. **Печатать все значения знаковой формой** (`W'sdN`). Отвергнут: изменил бы
   вывод корпуса без нужды.
2. **Знаковая форма только для отрицательных** (принято): `-W'sdN`.

### Decision

Принят вариант 2: при `value < 0` печатается `-{width}'sd{abs}`.

### Consequences

- Все восемь целей переводят запись; verilator и yosys вывод принимают.
- Вывод корпуса не изменился.

#### Acceptance criteria

Трасса RTL совпадает с эталоном; формы `W'd-N` в выводе нет; положительные
значения печатаются прежней формой.

правила разошлись.

проверка: иначе поехал бы вывод всего корпуса.
