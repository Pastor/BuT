# Фича: Отложенное объявление массива у rust не инициализируется (E0381)

- **Номер:** 0411
- **Статус:** ГОТОВО
- **Зависит от:** нет
- **Tier:** 2 — невалидный вывод при рапорте об успехе
- **Класс:** генерация
- **Связанные issue (анализ):** находка [отложенная инициализация локальной переменной: rust печатает лишний mut](0410-rust-deferred-let-mut.md); разблокирует [срез в аргументе вызова не переводит ни одна цель](0400-slice-in-call-argument.md)

## Краткое описание

`var part: [u8; 2]; part := src[1:3];` — Rust требует инициализировать массив
**целиком** до записи по индексу, и `rustc` отвечал `E0381` («used binding
`part` isn't initialized») при **нулевом** коде возврата `taktc`.

## Архитектура (ADR)

- **Status:** Accepted — исполнителю (решения заказчика не требует)

### Context

[отложенная инициализация локальной переменной: rust печатает лишний mut](0410-rust-deferred-let-mut.md) сняла лишний `mut` и отложенную
форму у **скаляра**; агрегат остался: у него присваивание печатается
поэлементно (массив — по индексам, 0355/0340), а Rust считает переменную
неинициализированной, пока ей не присвоено значение целиком.

### Decision

Отложенное объявление **агрегата** получает умолчание своего типа —
`rust_decl::default_value`, тот же носитель, которым живут поля конструктора
(0351). Предикат `needs_deferred_default`: массив (кроме упакованного
бит-вектора `N ≤ 64` — он **скаляр** по 0078) и структура.

**Скаляру умолчание не печатается, и это не экономия**: там отложенная
форма законна, а лишнее значение дало бы `unused_assignments` — отказ проверки
под `-D warnings` (тот самый класс, ради которого заведена 0216).

`mut` у агрегата печатается **всегда**: запись по индексу — изменение, а не
инициализация.

### Consequences

- Вывод цели `rust` принимается `rustc` и `clippy` на входе, который исполняют
  остальные потребители.
- Разблокирована [срез в аргументе вызова не переводит ни одна цель](0400-slice-in-call-argument.md): разворот среза во
  временную переменную упирался ровно в этот класс.
- Вывод корпуса **не изменился**.

## Итог (что сделано)

Отложенное объявление агрегата у цели `rust` получает умолчание своего типа
(носитель `default_value`, 0351); скаляр — не получает, иначе линт отвечает
`unused_assignments`.

Это третий слой одного разбора: 0410 сняла лишний `mut`, затем
`needless_late_init`, теперь — `E0381`. Каждый слой измерялся прогоном
инструментов цели, и ни один не следовал из чтения кода.

Фича **разблокировала** [срез в аргументе вызова не переводит ни одна цель](0400-slice-in-call-argument.md): форма
разворота (объявление → присваивание среза → вызов) теперь переводится всеми
восемью целями, и все их инструменты вывод принимают.
