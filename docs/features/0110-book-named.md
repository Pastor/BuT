## Краткое описание

Описывает **именованные условия** `cond` и **именованные блоки** (`enter`/`exit`/`always`): их объявление и использование в переходах и телах.

## Итог (что сделано)

Наполнен раздел `book/src/10-named/index.typ` описанием языка (правило 24 — язык не
меняется, Tier 3; ADR/анализ не требовались):

- **Именованные условия** `cond Name = expr;` — объявление, использование в
  переходах вместо формулы, комбинирование через `&`/`|`/`!` (`ref Done: Cooled &
  CyclesDone;`).
- **Именованные блоки** состояния: `enter` (один раз при входе), `always` (каждый
  такт), `exit` (один раз при выходе); имён ровно три.
- **Частые ошибки** (правило 26): `SE-025` (cond ссылается на неизвестное имя),
  `SE-045` (неизвестное имя блока — допустимы только enter/exit/always).
- Пример `tank.takt` — регулятор уровня в баке (`cond Full`/`Empty` в переходах;
  `enter` открывает клапан/насос, `always` меняет уровень, `exit` считает циклы
  откачки). **Компилируется** (0 предупреждений) и **проверен симуляцией**
  (правило 27д): уровень колеблется между `LOW`/`HIGH`, `cycles` растёт на каждом
  завершённом цикле откачки.

зелёный; сборка PDF (`make -C book build`) чистая. Язык не менялся → версия языка
