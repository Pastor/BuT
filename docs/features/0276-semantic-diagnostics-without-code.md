## Краткое описание

**Восемь безликих диагностик остались в семантике.** Замер при закрытии
[диагностика цели c без кода](0212-c-diagnostic-without-code.md) (2026-08-17): в цели
`c` таких мест было девятнадцать и все закрыты воронками `CC-022`/`CC-023`, а
вне генераторов их **восемь** — `semantic/function.rs` (×3), `tree.rs` (×2),
`named_block.rs`, `condition/mod.rs`, `extend.rs`. Все строят диагностику
конверсией `From<&str>`: код `None` (печатается `[?]`) и позиция
`Source(0, 0, 0)`, то есть «начало первого файла». Кандидат: дать им коды
`SE-…` с описанием в приложении (правило 25), после чего **удалить**
`impl From<&str> for Diagnostic` — тогда класс запретит тип, а не греп-контроль.
Часть мест — внутренние инварианты семантики; для них надо решить, один
общий код или свой каждому.

> Фича заведена **из бэклога кандидатов пакетным переводом** (решение заказчика
> 2026-08-18: «перевести всех кандидатов в фичи без проработки, решить, делать
> или нет, позже»). Стадии 2 и 3 **не пройдены**: приоритет, зависимости и
> объём не оценивались. Далее — жизненный цикл по правилу 17.

### Context

Фича закрыла девятнадцать безликих диагностик в цели `c` двумя воронками
(`CC-022`/`CC-023`). Вне генераторов такие места остались.

**Замер-19** — восемь мест в семантике (`function.rs` ×3, `tree.rs` ×2,
`named_block.rs`, `condition/mod.rs`, `extend.rs`) и **два пропущенных** в самой
цели `c` (`c_expr/condition.rs`, `c_expr/call.rs`). Все строили диагностику
конверсией `From<&str> for Diagnostic`: код `None` (печатается `[?]`), позиция
`Location::Source(0, 0, 0)` — то есть «начало первого файла».

Прогон по каждому месту разделил их надвое:

| Место | Достижимо | Ответ до фичи |
|---|---|---|
| `condition/mod.rs` — «Массив не найден» | **да** | `[?]`, координата `1:1` |
| `function.rs` — «Локальная функция должна иметь тело» | **да** | `[?]`, координата `1:1` |
| `function.rs` — параметр без типа | нет: перехватывает `SE-034` | — |
| `function.rs` — «Функция не определена» | нет: перехватывает `SE-004` | — |
| `extend.rs` — реализация не композиция | нет: перехватывает `SE-081` | — |
| `named_block.rs`, `tree.rs` ×2 | нет: запасные ходы | — |

**Координата была ложной, а не отсутствующей.** `Source(0, 0, 0)` печатается
как `файл:1:1` — сообщение указывает на первую строку любого входа. Это тот же
класс, что 0264: правдоподобная ложь хуже пустоты.

### Decision Drivers

1. **Достижимая диагностика — ответ автору**: ей нужен свой код и своя позиция.
2. **Недостижимая — сообщение о дефекте инструмента**: ей нужен общий код и
   честный текст, а не вид ответа автору.
3. **Класс должен запрещаться типом.** Пока конверсия существует,
   `Err("текст".into())` компилируется, и девятнадцатое место заводится
   незаметно — это уже случилось дважды (0212, и два пропущенных места там же).

### Considered Options

#### Option A. Дать всем восьми свои коды

**Cons:** шесть кодов для мест, недостижимых из корректной программы; реестр и
приложение документа наполняются записями, которых пользователь не увидит
никогда.

#### Option B. Один общий код всем восьми

**Cons:** два достижимых места — настоящие ответы автору (`mem[1]` при
отсутствии `mem`), и общий «внутренний инвариант» на них — неправда.

#### Option C. Разделить по достижимости + удалить конверсию

**Pros:**
- достижимые получают свои коды и позиции;
- недостижимые — одну воронку `SE-119`, называющую вид нарушения словом;
- удаление `From<&str>` делает класс невозможным **по типу**, а не по контролю.

**Cons:** удаление конверсии вскрывает все её употребления сразу — но это и есть
польза: два места с кодами (`SE-004`, `SE-022`) теряли позицию так же молча.

### Decision

Принимается **Option C**.

1. `SE-117` — индексируется не массив (позиция имени).
2. `SE-118` — локальная функция без тела (позиция объявления).
3. `SE-119` — общая воронка `semantic::internal::internal(вид)` для инвариантов.
4. Два пропущенных места цели `c` переведены на существующую `CC-023`.
5. `impl From<&str> for Diagnostic` **удалён**; на его месте — комментарий,
   объясняющий, почему возвращать конверсию нельзя.

### Consequences

#### Положительные

- Две достижимые диагностики стали ответом с кодом и координатой.
- Безликую диагностику больше нельзя построить случайно: тип не позволит.
- Попутно исправлены `SE-004` и `SE-022`, терявшие позицию тем же способом.

#### Отрицательные / Action items

- `SE-119` печатается с `Location::Codegen`: у внутреннего инварианта позиции
  нет по существу, и подставлять «начало файла» — та же ложь, от которой фича
  уходит.
- **Недостижимость держат другие проверки** (`SE-034`, `SE-004`, `SE-081`),
  а не этот модуль: их ослабление сделает `SE-119` видимой.

#### Acceptance criteria

1. `ref Done: mem[1] = 0;` даёт `SE-117` с позицией имени (A1).
2. `fn f(a: u8) -> u8;` даёт `SE-118` с позицией объявления (A2).
3. Конверсии `From<&str>` в исходнике нет (A3).
4. В `semantic/` не осталось `Err("…".into())` (A4).
5. Реестр диагностик и приложение документа пополнены (A5).
6. `./scripts/precheck.sh` зелён (A6).

## Анализ

### Выводы и дальнейшие шаги

- **Кандидатов, называющих 0276, не осталось** (правило 28).

## Итог (что сделано)

**Безликая диагностика запрещена типом.** Конверсия `From<&str> for Diagnostic`
строила отказ без кода (`[?]` на печати) и с позицией `Source(0, 0, 0)` — то
есть «начало первого файла»: координата **ложная**, а не отсутствующая.

**Замер нашёл больше, чем называл кандидат** — двенадцать мест вместо восьми:
восемь в семантике, **два пропущенных в самой цели `c`** (фича правила там
девятнадцать) и **два с кодами**, где та же конверсия молча съедала позицию
(`SE-004`, `SE-022`).

**Сделано:** достижимые места получили свои коды и позиции (`SE-117` —
индексируется не массив, `SE-118` — локальная функция без тела); недостижимые
(их держат `SE-034`, `SE-004`, `SE-081` и запасные ходы) — общую воронку
`SE-119`, называющую вид нарушения **словом**, по образцу `CC-023`. Два места
цели `c` переведены на существующую `CC-023`. Конверсия **удалена**, на её месте
— комментарий, почему возвращать нельзя.

**Контроль двухслойный** (`takt-lang/tests/semantic/diagnostic_code_presence_tests.rs`):
поведение (код и позиция у обеих достижимых диагностик) и устройство (нет
конверсии; в `src/semantic` не осталось `Err("…".into())` — падает списком мест).

**Урок:** удаление удобной конверсии — способ **измерить** класс. Пока она
существовала, безликое место заводилось незаметно, и именно так 0212 пропустила
два места в цели, которую правила.

**Документ:** приложение «Ошибки и предупреждения» — таблица и записи `SE-117`,
`SE-118`. **Версия языка не поднята** (цикл `0.10.0`); крейт `takt-lang`:
`0.48.0` → `0.49.0`.
