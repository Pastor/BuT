## Краткое описание

Панель структуры показывает **одно из двух**: пока проект не открыт — список
проектов, открыли — его состав. Полоса действий отвечает показанному. Закрытие
проекта — выход из него **с сохранением**, а не отказ от работы.

## Архитектура (ADR)

- **Status:** Accepted
- **Date:** 2026-09-10
- **Authors:** заказчик (требование), разработка

### Context

Список проектов и состав открытого стояли в панели одновременно, разделённые
ручкой. Заказчик, увидев это на стенде, поправил замысел: в проект
**проваливаются** — отдельного места под список файлов не нужно, панель отвечает
на один вопрос за раз.

### Decision

Панель показывает список проектов, пока проект не открыт, и его состав — когда
открыт. Полоса действий следует за показанным: список — завести, открыть,
переименовать, удалить, загрузить архив; состав — закрыть, выгрузить архивом и
всё о файлах.

Закрытие проекта сохраняет работу: автор уходит из проекта, а не выбрасывает
набранное. Отказ записи не запирает в проекте — он назван словами, а проект
всё равно закрывается.

### Consequences

Ручка между списком и составом снята вместе со своим ключом памяти: делить
больше нечего. Удалённый проект закрывается без записи — писать в него уже
некуда.

## Разработка

### Задача — одно из двух

`refresh` переключает показ (`projects` против `tree`) и набор кнопок по одному
признаку «проект открыт». Правило скрытия у обоих узлов своё (`[hidden]`):
раскладка сильнее атрибута, и это правило проекта.

### Задача — выход с сохранением

`closeProject` стал асинхронным и перед закрытием зовёт сохранение, если есть
что писать и есть право. Отказ проглатывается намеренно: о нём уже сказало само
сохранение, а держать автора в проекте отказом сервера нельзя.

### Проверки

`check-web.sh` (106 тестов; набор о полосе переписан под «одно из двух» и
дополнен требованием сохранения при закрытии), `check-design.py` (446 правил),
прогон страницы на сервере с базой.

## Отчёт о тестировании

### Резюме

Требование выполнено, проверки зелёные.

### Фактические результаты по проверкам

1. До выбора: список, кнопки «завести» и «загрузить архив».
2. После выбора: добавились «открыть», «переименовать», «удалить».
3. Внутри проекта: состав файлов, кнопки закрытия, выгрузки и все файловые;
   действий над проектами нет.
4. Правка модели, закрытие проекта, повторное открытие — правка на месте
   (388 → 416 знаков, текст сохранился).
