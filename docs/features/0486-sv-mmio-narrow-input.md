# Фича: Цель sv-mmio: биты reg_wdata, не занятые входными портами

- **Номер:** 0486
- **Статус:** ГОТОВО
- **Зависит от:** нет
- **Tier:** 2
- **Класс:** генерация
- **Связанные issue (анализ):** кандидат `FEATURES.md` (заведён при закрытии 0485)

## Стадии жизненного цикла

## Краткое описание

Ширину слова данных регистрового файла цель считает по **всем** адресованным
портам, а `reg_wdata` читают только **входные** (`out`-биты запись игнорируют).
Модель, где входной порт уже выходного, оставляла старшие биты входа висящими,
и `verilator -Wall` отвечал `UNUSEDSIGNAL: Bits of signal are not used:
'reg_wdata'[7:1]` при **нулевом** коде возврата `taktc`. Фича гасит непокрытые
биты редукцией — той же идиомой, что обёртка APB и неиспользуемый параметр
функции.

> Фича зарегистрирована из бэклога кандидатов; далее проходит жизненный цикл
> по своду.

## Архитектура (ADR)

- **Status:** Accepted
- **Date:** 2026-09-02
- **Authors:** архитектор, аналитик

### Context

Замер-02 (`taktc -t sv-mmio` → `verilator --lint-only -Wall`, флаги
проверки цели):

| Вход | Ответ `verilator` |
|---|---|
| `in cmd: u8` + `out level: u8` (вход во всю ширину слова) | принял |
| `in cmd: bit` + `out level: u8` | **`UNUSEDSIGNAL` `'reg_wdata'[7:1]`** |
| `in cmd: Mode` (перечисление, 2 бита) + `out level: u8` | **`UNUSEDSIGNAL` `'reg_wdata'[7:2]`** |

Причина в устройстве: ширина слова — максимум `bit + width` по **всем** портам
(так задумано, исправление: шире нужного шину не эмитим), а `reg_wdata`
используют лишь входные. Выходной порт шире входного — и разница висит.

Класс — родня фичи («интерфейс отражает состав портов»), но про
**биты**, а не про сигнал целиком. Корпус его не покрывает: у `sv-mmio` в
`examples/` входные порты занимают всё слово.

**Контрольный вход** в замере есть: та же модель с входом во всю ширину
принимается — значит меряется соотношение ширин, а не проба.

### Decision

1. Считать покрытие `reg_wdata` объединением срезов **входных** портов
   (`Mmio::unused_wdata_ranges`) и печатать поглотитель на непокрытые
   диапазоны: `wire _unused_wdata = &{1'b0, reg_wdata[7:1]};`.
2. Идиома — редукция с константой (`lint_off` запрещён правилом): биты
   честно используются, а синтезатор эту логику выбрасывает сам.
3. Гасить **только непокрытое**, а не сигнал целиком: покрытие считается по
   объявленным портам, поэтому сломайся печать среза — бит останется
   неиспользованным в тексте, и `verilator` об этом скажет.
4. При отсутствии входных портов поглотителя нет вовсе — там нет и `reg_wdata`.

### Consequences

- Модель с узким входным портом проходит линт и синтез; вывод моделей, где
  вход занимает всё слово, не меняется (контроль — контроль в наборе).
- Предупреждение `UNUSEDSIGNAL` остаётся рабочим контролем для настоящих
  дефектов печати срезов.

#### Acceptance criteria

1. Узкий входной порт (бит, перечисление) даёт вывод, который `verilator -Wall`
   принимает, а `yosys` синтезирует.
2. При входе во всю ширину поглотителя нет.
3. Адаптер APB по-прежнему собирается вместе с ядром.
4. `./scripts/precheck.sh` зелёный.

## Разработка

### Задача — покрытие и поглотитель

`Mmio::unused_wdata_ranges` строит маску занятых битов по входным портам и
сворачивает её в диапазоны `(hi, lo)`; `emit_wdata_guard` печатает
`wire _unused_wdata = &{1'b0, …};` перед регистровым файлом — и только при
наличии записываемого регистра.

Диапазонов может быть несколько: входы разных слов занимают разные биты
одного `reg_wdata`, и середина между ними гасится одним срезом.

- Биты `reg_wdata`, не занятые ни одним входным портом, поглощаются редукцией;
