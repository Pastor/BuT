## Краткое описание

Поле поиска справки стояло вплотную к заголовку «Справка — язык Takt», отдельно
от стрелок перехода по найденному. Теперь поле, число совпадений и стрелки —
одна группа у правого края шапки справки; на узкой странице группа переносится
на вторую строку целиком.

> жизненный цикл по своду.

### Context

Шапка справки шла подряд: заголовок, поле, число совпадений, стрелки, распорка,
крестик. Поле с основой 22rem забирало всё свободное место, распорке ширины не
оставалось, и поле прижималось к заголовку; на телефоне стрелки уходили за край.

### Decision

- Число совпадений, поле и стрелки — группа `.help-find` с
  `margin-inline-start: auto`: она прижата к правому краю, распорка не нужна.
  Число стоит перед полем и выровнено к нему.
- Поле не растягивается шире 16rem — свободное место остаётся между заголовком
  и группой.
- Шапка переносится (`flex-wrap`): не помещается группа рядом с заголовком —
  она уходит на вторую строку целиком, а не частями.

### Consequences

Порядок фокуса по Tab прежний по смыслу: заголовок, число, поле, стрелки,
крестик.
