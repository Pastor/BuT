- **Номер:** 0404
- **Статус:** ГОТОВО
- **Зависит от:** 0403
- **Tier:** proc
- **Класс:** прочее
- **Связанные issue (анализ):** запрос заказчика 2026-08-23

## Стадии жизненного цикла (правило 17)

Все стадии — **разделы этой карточки** (правило 32). Отдельным артефактом
остаются только исправления — [`docs/fixes/`](../fixes/README.md).

## Краткое описание

[примеры покрывают все конструкции языка — проверка покрытия](0403-language-coverage-gate.md) завела счёт покрытия конструкций
языка примерами и заморозила остаток реестром. Эта фича остаток снимает: в
`examples/` и в `book/` показана **каждая конструкция, которую можно
показать**.

| Область | До 0403 | После 0403 | После 0404 |
|---|---|---|---|
| `examples/` | 83 из 157 (53 %) | 141 (90 %) | **153 (97 %)** |
| `book/src/**` | 84 из 157 (53 %) | 84 (53 %) | **149 (95 %)** |

Оставшиеся 4 и 8 записей — не пробел документации: это конструкции, которые
**не может показать ни один пример** (узлы восстановления после ошибки, лишняя
`;`, которую стирает `fmt`) либо которые **не переводит цель `c`**, а проверка
примеров книги (0133) требует от примера компиляции ею.

## Документирование (правило 24)

Правит `book/` напрямую — но **не заводит новых разделов**: примеры добавлены
в существующие («Выражения», «Управление», «Импорты», «Модели и состояния»,
«Время», «Верификация», «Типы», «Порты и адреса»), каждый с разбором-выносками
по правилу 27. Раздел «Стиль кода» не затронут.

## Архитектура (ADR)

- **Status:** Accepted
- **Date:** 2026-08-23
- **Authors:** архитектор, аналитик, разработчик, тестировщик

### Context

Замер-23 показал, что долг делится на три разных класса, и лечатся они
по-разному:

1. **Просто не написан пример** — 66 записей книги. Лечится примерами.
2. **Форма без семантики** — `Expression::List`: `(a, b)` разбирается, но
   эталон её не исполняет (`SIM-014`), ни одна цель не переводит (`CC-022`), а
   имена внутри списка не считаются использованием и дают ложное `SE-036`.
3. **Цель не переводит** — `assembly`, `formula` в теле, `#АДРЕС`. Пример в
   `book/` невозможен: проверка требует компиляции целью `c`.

### Decision

- Класс 1 — покрыть примерами (решение заказчика: «покрыть 66, четыре — в
  долг»).
- Класс 2 — **изъять из языка** (решение заказчика), по образцу фичи:
  правило снято из грамматики, запись отвергается обычным `SY-002`. Версия
  языка **0.13.0**.
- Класс 3 — оставить в реестре с причиной, называющей **цель**, а не документ.

**Решение по `Expression::String` пересмотрено на замере.** Вопрос заказчику
был задан о двух формах сразу, и по строковому литералу формулировка оказалась
**неверной**: у него есть потребитель — `debug("сообщение")`, встроенная
функция отладки; эталон её исполняет, `c`, `c-hal` и `plantuml` принимают.
Изъятие сломало бы `debug`. Форма покрыта примером (правило 30: замер
опровергает предпосылку, а не подтверждает её).

### Consequences

- `(a, b)` перестала разбираться. Полный прогон тестов после изъятия — **код
  0**: ни корпус, ни фикстуры этой формы не использовали.
- Правило скобок стало прямым: `"(" Expression ")"`, без разбора через
  `ParameterList`. LR-конфликта нет (проверено сборкой).

#### Acceptance criteria

1. В `examples/` и `book/` покрыто всё покрываемое.
2. Остаток реестра называет причину, проверяемую прогоном.
3. Изъятие формы не ломает ни одного теста.

## Анализ

### Замер (правило 30, 2026-08-23)

Снят `scripts/probe.sh` и прямыми прогонами:

| Вход | Эталон | Цели |
|---|---|---|
| `r := (a, b);` | `SIM-014` | `CC-022` у `c`; имена внутри списка не считаются использованием (ложное `SE-036`) |
| `debug("текст");` | исполняет | `c`, `c-hal`, `plantuml` — OK; `st`, `rust`, `sv` — отказ с причиной |
| `assembly "c" { … }` | исполняет | **все семь** отказывают; у `c` код `CC-023` — «дефект инструмента» вместо границы цели |
| `formula { … }` в теле | исполняет | `CC-023` у `c` |
| `formula { … }` уровня модели | исполняет | `c` компилирует (блок не эмитится) |
| `#0x200 as u8` | исполняет | `CC-021` у `c` — штатный отказ с причиной |
| `const SPAN: u16 := 2 ** 8;` | **`0` молча** | `CC-023` у `c`, OK у `st`/`rust`, `SV-002` у `sv` |

Последняя строка — **отдельный дефект Tier 1**, вынесен фичей
[степень в инициализаторе константы не сворачивается](0407-const-power-fold.md).

переводила ни одна цель, то есть работающей программы с ней быть не могло.

## Разработка

### Задача — изъятие формы без семантики

Правило `Precedence0` разбирало `ParameterList` и при двух и более элементах
строило `Expression::List`. Теперь правило прямое: `"(" Expression ")"` →
`Parenthesis`. Вариант АСД остался мёртвым (как `Expression::CodeBlock`), и
проверка покрытия перестал его требовать сам — по признаку достижимости.

### Задача — примеры корпуса

`examples/language/control.takt` дополнен `debug("отчёт готов")`.

### Задача — признак достижимости

Признак смотрел на текст грамматики **вместе с комментариями**, и пояснение
о снятом правиле вернуло требование покрытия для изъятой конструкции.
Комментарии вырезаются: узел строит **код**, а не пояснение к нему.

### Найденные дефекты

1. **Степень в инициализаторе константы** — `const SPAN: u16 := 2 ** 8;` даёт
   у эталона **0 молча**, у `c` — `CC-023`, у `st`/`rust` — верное значение.
   Tier 1, вынесено фичей [степень в инициализаторе константы не сворачивается](0407-const-power-fold.md). Найдено при
   попытке написать естественный пример («ёмкость окна»).
2. **Цель `c` отвечает `CC-023` на `assembly` и `formula` в теле** — кодом
   «дефект инструмента» вместо кода границы цели (`CC-022`);
   соседи отвечают своими кодами с причиной. Записано причиной в реестре
   долга.
3. **Признак достижимости учитывал комментарии** — см. задачу.

### Выводы и дальнейшие шаги

Дальнейший рост покрытия — не работа над документом: он упирается в цели.
Показать `assembly`, `formula` в теле и `#АДРЕС` примером книги станет
возможно, когда цель `c` научится их переводить либо когда проверка научится
принимать пример с названной целью.

## Итог (что сделано)

- Покрытие конструкций примерами: `examples/` 90 % → **97 %**, `book/` 53 % →
  **95 %**; покрыто **всё покрываемое**.
- Форма `(a, b)` изъята из языка (версия **0.13.0**): её не исполнял эталон и
  не переводила ни одна цель.
- Решение по `Expression::String` пересмотрено на замере — у формы есть
  потребитель (`debug`), и она покрыта примером, а не изъята.
- Найдены и вынесены два дефекта: степень в инициализаторе константы
  ([степень в инициализаторе константы не сворачивается](0407-const-power-fold.md), Tier 1) и код отказа `CC-023` у цели `c`
  на `assembly`/`formula`.
