# Фича: Массив как поле структуры не переводят `st` и `sv`

- **Номер:** 0422
- **Статус:** ГОТОВО
- **Зависит от:** 0343, 0293
- **Tier:** 2
- **Класс:** генерация
- **Связанные issue (анализ):** новая фича (найдена пробой 2026-08-23)

## Стадии жизненного цикла

Все стадии — разделы этой карточки.

## Краткое описание

`struct Buf { data: [u8; 3], n: u8 }` исполняют эталон, `c`, `c-hal` и `rust`,
а `st` и `sv` рапортовали об успехе с выводом, который отвергают их
инструменты. Слоёв оказалось **три**, и каждый вскрывался после починки
предыдущего.

## Документирование

Не требуется: язык не меняется — массив в поле структуры был законен и прежде.

## Архитектура (ADR)

- **Status:** Accepted
- **Date:** 2026-08-23
- **Authors:** архитектор, разработчик

### Context

**Замер-23** (`scripts/probe.sh`):

| Слой | Цель | Ответ инструмента |
|---|---|---|
| 1 | `st`, `st-at` | `iec2c`: «Initialization element identifier (data) is not declared in referenced structure/FB scope» |
| 2 | `sv`, `sv-mmio` | `verilator`: «Unpacked data type 'logic[7:0]$[0:2]' in packed struct/union (IEEE 1800-2023 7.2.1)» |
| 3 | `sv` (после починки слоя 2) | `verilator`: «Assignment pattern member not underneath a supported construct: CONCAT» |

Код возврата `taktc` — **нулевой** во всех трёх случаях; эталон, `c`, `c-hal`,
`rust` и `plantuml` вход исполняют.

**Слои вскрывались по одному:** пока жил первый, второго не было видно.
Замер снимался трижды.

### Decision Drivers

- Форма выбирается **прогоном** инструмента, а не чтением стандарта.
- У цели `sv` нужны **оба** инструмента: verilator и yosys.

### Considered Options

1. **Отказ целей на поле-массив.** Отвергнут: запись исполняют эталон и три
   цели, а выразить её можно.
2. **Починка всех трёх слоёв** (принято).

### Decision

- `st`: поле-массив **исключается** из агрегата объявления, а значения кладут
  операторы первого скана — механизм 0343 (там он завёден для массива
  структур). Частичный инициализатор `(n := 0)` законен — проверено пробой
  `iec2c`.
- `sv`: поле-массив объявляется **упакованным** (`logic [N-1:0][W-1:0]`), а его
  значение в цепи сброса печатается **конкатенацией в обратном порядке** — у
  упакованного вектора старший разряд слева.
- Обычная переменная-массив остаётся распакованной (0365): там форма выбрана
  прогоном обоих инструментов, и менять её незачем.

### Consequences

- Все восемь целей переводят запись, все инструменты вывод принимают.
- Вывод корпуса не изменился: полей-массивов в `examples/` нет.

#### Acceptance criteria

Значения совпадают с эталоном потактово (включая порядок элементов); `iec2c` и
оба инструмента SV вывод принимают.

### Редакторский слой

Не затронут.

валидный RTL с зеркальными значениями; его контролирует сверка, а не линт.

## Разработка

### Задача

#### Что было

`st` печатал `(data := [1, 2, 3], n := 0)`; `sv` объявлял поле распакованным и
печатал его значение шаблоном `'{…}` внутри конкатенации.

#### Что сделано

- `st_decl.rs` — `field_is_deferred`, исключение поля-массива из агрегата.
- `st_model.rs` — ветвь `emit_deferred_inits` для полей-массивов структуры.
- `sv_type.rs` — `packed_array_field`: упакованное объявление поля.
- `sv_const.rs` — `packed_field_array`: конкатенация в обратном порядке с
  размерными литералами.

#### Проверки

Проба восьми целей (трижды), потактовая сверка с RTL, прогон `iec2c`, мутация
порядка, предкоммит.

### Найденные дефекты

**Класс трёхслойный, и слои вскрывались по одному:** починка `st` открыла
дефект объявления у `sv`, а та — дефект значения сброса. Замер пришлось
снимать трижды; ни один слой не был виден, пока жил предыдущий.

**Порядок размерностей поймал прогон, а не рассуждение:** первая редакция
печатала `logic [W-1:0][N-1:0]`, и `data[i]` давало ширину **числа
элементов** — verilator отвечал `WIDTHEXPAND`.

### Выводы и дальнейшие шаги

Класс найден пробой наугад: поля-массива нет ни в одном примере корпуса.

## Итог (что сделано)

`struct Buf { data: [u8; 3], n: u8 }` давал невалидный вывод у `st` и `sv` при
нулевом коде возврата `taktc`. Починены **три** слоя: инициализатор `st`
(поле-массив уходит в первый скан, механизм 0343), объявление поля у `sv`
(упакованная форма — распакованная в `struct packed` запрещена стандартом) и
значение сброса (конкатенация в **обратном** порядке вместо шаблона `'{…}`).

**Слои не видны по одному:** каждый вскрывался только после починки
предыдущего, и замер снимался трижды.

**Порядок размерностей и порядок элементов — места, где ошибка даёт
валидный вывод с другими значениями.** Первое поймал `verilator`
(`WIDTHEXPAND`), второе контролирует потактовая сверка, где `first` и `last`
намеренно разные.

Обычная переменная-массив осталась распакованной (0365): её форма выбрана
прогоном обоих инструментов, и менять её незачем.
