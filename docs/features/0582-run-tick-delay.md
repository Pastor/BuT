## Краткое описание

На панели прогона рядом с числом шагов — поле задержки между тактами в секундах,
дробное, по умолчанию 0 (без задержки). Задержка действует на прогон кнопкой
«Пуск» (шаги по одному её не ждут) и хранится в метаданных проекта — своя у
каждого сценария.

### Context

Прогон без задержки летит быстрее, чем глаз успевает за схемой: такты идут
порциями по 256. Показывать работу модели автор хочет в своём темпе, и темп
зависит от сценария — медленный разгон и быстрый стресс-тест смотрят по-разному.

### Decision

- **Хранение — метаданные проекта**, колонка `run_delays` (объект JSON «имя
  сценария — секунды», шаг схемы 7 → 8). Ключ — имя файла: переименование
  сценария переносит задержку, удаление — забывает. Ноль не хранится.
- **Проверка на записи**: число секунд от 0 до 60, до миллисекунды; ключ —
  сценарий проекта (`limits::check_run_delays` и проверка рода); записей не
  больше, чем файлов в проекте.
- **Пишет владелец** — как цель и ключи сборки; у прочих задержка живёт до
  перезагрузки страницы. Копия проекта и архив её переносят (формат архива —
  версия 4: прежний сервис потерял бы задержки молча).
- **Воркер**: при задержке больше нуля прогон идёт такт за тактом с паузой;
  команда «стоп» разбирается во время паузы.

### Consequences

Без выбранного сценария задержку записать не к чему — она действует на прогон,
но после перезагрузки пропадёт.

## Разработка

Сервер: `db.rs` (колонка, шаг 7 → 8), `limits.rs`, `projects.rs`, `files.rs`,
`grants.rs`, `archive.rs`, `archive_api.rs`. Страница: `index.html`, `app.js`,
`worker.js`, `account.js`, `project.js` (`runDelay`), `app.css`, словарь.

## Тест-план

1. Сервер: отказ на ключе-модели, несуществующем сценарии, отрицательной и
   слишком большой задержке; дробная принимается; переименование переносит,
   ноль не хранится, удаление забывает; схема, поднятая переходом, равна
   поднятой с нуля; архив несёт задержки.
2. Страница: `runDelay` — дробь, миллисекунды, пусто, отрицательное, предел.
3. Прогон страницы: задержка сценария записывается, читается при открытии,
   прогон идёт с паузой.
