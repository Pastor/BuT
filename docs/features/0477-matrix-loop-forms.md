## Краткое описание

Цикл в языке принимает шесть форм: `for` со статическими границами, `for` без
инициализатора, `while`, бесконечный `loop` с `break`, вложенные циклы и цикл
с `continue`. Перебор знал одну (`local_var_in_for` как фикстуру отказа `sv`).
Фича заводит шесть видов и — главное — **потактовую сверку**: у цикла
компиляция ничего не доказывает.

### Context

Замер-01 по формам и целям:

| Форма | `c` | `rust` | `st` | `sv` |
|---|---|---|---|---|
| `for` статический | | | | (разворот, 0321) |
| `for` без инициализатора | | | | `SV-002` |
| `while` | | | | `SV-002` |
| `loop` + `break` | | | | `SV-002` |
| вложенные | | | | |
| `continue` | | | **`ST-011`** | `SV-002` |

Отказы законны и разной природы: у `sv` цикл обязан разворачиваться в схему
(границы известны на этапе синтеза), у `st` в IEC есть `EXIT` (аналог `break`),
а продолжения итерации нет **вовсе**.

Эталон исполняет все шесть форм; расхождений с ним никто не проверял —
цикл контролировался только компиляцией.

### Decision

1. **Шесть видов по формам** — с записью границ целей в таблицу отказов
   перебора: цель, вдруг переведшая то, что не умеет, роняет контроль так же,
   как невалидный вывод.
2. **Потактовая сверка значений.** У цикла потерянная итерация, лишний проход
   или проигнорированный `continue` дают **валидный** код с другим числом
   шагов — компиляция слепа.
3. **Приращения форм разные** (3, 3, 3, 4, 3, 1): при одинаковых потеря целого
   цикла сошлась бы в сумме и осталась незамеченной.
4. **Цель `sv` в сверку не входит**: четыре формы из шести она отвергает
   законно, а её единственную пригодную контролирует сверка 0321.

### Considered Options

- **A. Сверка значений** — принята: единственный способ увидеть потерю
  итерации.
- **B. Осмотр порождённого текста** — отвергнут: форма цикла у каждой цели
  своя (разворот у `sv`, `WHILE` у `st`), и сравнивать было бы нечего.
- **C. Одинаковые приращения ради простоты** — отвергнуты: маскируют потерю.

### Consequences

Матрица растёт с 50 до 56 видов (460 → 520 случаев). Вывод корпуса не
меняется.

#### Acceptance criteria

- A1. Шесть форм проходят все восемь целей либо отказывают **названным** кодом.
- A2. Эталон и порождённый C дают одну сумму приращений.
- A3. Мутация «терять `continue`» роняет сверку по значению.

## Итог

Дефектов не нашлось, но у циклов появилось то, чего им недоставало: проверка
**значением**. Компиляция здесь не доказывает ничего — потерянная итерация
даёт валидный код, который считает другое. Заодно записаны границы двух целей:
почему `sv` берёт лишь одну форму из шести и почему у `st` нет `continue`.
