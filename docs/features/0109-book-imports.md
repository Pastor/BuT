## Итог (что сделано)

Наполнен раздел `book/src/09-imports/index.typ` описанием языка (правило 24 — язык
не меняется, Tier 3; ADR/анализ не требовались):

- **Импорт файла**: `import "f.takt";` (доступ под именем из имени файла) и
  `import "f.takt" as Name;` (явное имя).
- **Выборочный импорт**: `import { A, B as C } from "f.takt";` — конкретные
  модели/псевдонимы типов, с переименованием.
- **Поиск файлов**: рядом с импортёром + каталоги `-I`.
- **Композиция**: `model`, параллельная `|` (шаг делают обе), последовательная
  `+` (по очереди), реализация состояния `state S = Model;`.
- **Общие переменные корня** — видны под-моделям (одна пишет, другая читает).
- **Частые ошибки** (правило 26): `SE-013`, `SE-017`, `SE-001`.
- Примеры: `climate.takt` — климат-контроль (параллельная композиция
  `Thermostat | Fan`, общий флаг `heating`), **компилируется** (0 предупреждений)
  и **проверен симуляцией** (правило 27д): нагрев+вентилятор ниже порога 22°,
  выключение на пороге, повторное включение при остывании; `thermostat.takt` +
  `room.takt` — тот же термостат выборочным импортом из отдельного файла
  (компилируется `-I`, симулируется). `+`-композиция описана прозой без
  симулируемого примера — симулятор её с переходом `next` не исполняет.

зелёный; сборка PDF (`make -C book build`) чистая. Язык не менялся → версия языка
