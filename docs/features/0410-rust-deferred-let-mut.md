# Фича: Отложенная инициализация локальной переменной: rust печатает лишний mut

- **Номер:** 0410
- **Статус:** ГОТОВО
- **Зависит от:** нет
- **Tier:** 2 — невалидный вывод при рапорте об успехе
- **Класс:** генерация
- **Связанные issue (анализ):** находка [срез в аргументе вызова не переводит ни одна цель](0400-slice-in-call-argument.md)

## Краткое описание

`var t: u8; t := 5;` — отложенная инициализация локальной переменной. Цель
`rust` печатала `let mut t: u8;`, и `rustc -D warnings` отвечал «variable does
not need to be mutable» при **нулевом** коде возврата `taktc`.

Найдено при работе над [срез в аргументе вызова не переводит ни одна цель](0400-slice-in-call-argument.md).

## Замер (правило 30, 2026-08-23, `scripts/probe.sh`)

Вход: `var t: u8; t := 5; o := t;`

| Потребитель | `taktc` | Инструмент цели |
|---|---|---|
| эталон | исполняет | — |
| `c`, `c-hal` | OK | `cc` принял |
| `st`, `st-at` | OK | `iec2c` принял · `cc` собрал |
| **`rust`** | **OK** | **`rustc` ОТВЕРГ:** «variable does not need to be mutable» |
| `sv`, `sv-mmio` | OK | `verilator` принял · `yosys` синтезировал |

Снятие `mut` открыло **второй** слой: `clippy::needless_late_init` —
«unneeded late initialization». Оба слоя измерены прогоном, а не выведены из
кода.

**Не требуется.** Язык не меняется: правится форма печати у цели.

## Архитектура (ADR)

- **Status:** Accepted — исполнителю (решения заказчика не требует)
- **Date:** 2026-08-23

### Context

У цели `rust` есть носитель признака `deferred_needs_mut`: «первое
присваивание на каждом пути — инициализация, а не изменение». Он применялся в
ветви **мёртвого инициализатора** и не применялся в ветви **без
инициализатора**, где `mut` печатался безусловно. Там же не делалась свёртка
`fold_assignment`, снимающая `needless_late_init`.

### Decision

Ветвь «без инициализатора» зовёт **те же** два механизма, что соседняя:
признак `deferred_needs_mut` и свёртку `fold_assignment`. Второго знания о том,
«что считать изменением», не заводится.

**Срез из свёртки исключён**: он печатается поэлементно (0355), выражения у
него нет, и свёрнутый `let part = src[1:3];` дал бы `RS-011` там, где
присваивание переводится. Исключение живёт в самой `fold_assignment` — рядом с
исключением «значение читает само себя».

### Consequences

- Вывод цели `rust` проходит `rustc` и `clippy` под `-D warnings` на записи,
  которую исполняют все остальные потребители.
- Вывод корпуса **не изменился**: отложенных объявлений без инициализатора в
  `examples/` нет.

## Итог (что сделано)

Ветвь «объявление без инициализатора» у цели `rust` перестала печатать лишний
`mut` и отложенную форму: она зовёт **те же** механизмы, что соседняя ветвь
мёртвого инициализатора (признак `deferred_needs_mut` и свёртку
`fold_assignment`).

**Слоёв было два, и второй открылся после починки первого**: снятие `mut`
дало `clippy::needless_late_init`. Оба измерены прогоном инструментов, а не
выведены из кода.

**Соседний класс, вынесенный кандидатом:** отложенное объявление **массива**
с последующей поэлементной записью (`var part: [u8; 2]; part := src[1:3];`)
даёт `rustc` `E0381` — «used binding isn't initialized»: Rust требует
инициализации массива целиком до записи по индексу. Класс найден тем же
разбором и к предмету фичи не относится.

Детали — в разделах «Замер», «Архитектура (ADR)» и «Отчёт о тестировании».
