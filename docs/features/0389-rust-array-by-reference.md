## Краткое описание

Замер-22 на `fn total(a: [u8; 4]) -> u8`:

| Цель | Передача массива |
|---|---|
| `c`, `c-hal` | `uint8_t a[4]` — **указатель** |
| `st`, `st-at` | `VAR_IN_OUT` — по ссылке (0348) |
| `sv`, `sv-mmio` | плоский вектор + пролог (0369) |
| **`rust`** | **`a: [u8; 4]` — копия на каждый вызов** |

Наблюдаемого расхождения нет — это **цена**, а не дефект: все девять
потребителей вход исполняют одинаково. Но платить её незачем, и остальные цели
её не платят.

### Context

Массив в параметре функции цели передают по-разному: `c` — указателем
(`uint8_t a[4]`), `st` — через `VAR_IN_OUT` (0348), `sv` — плоским вектором с
прологом (0369), а `rust` — **по значению** (`a: [u8; 4]`), то есть копией на
каждый вызов.

Наблюдаемого расхождения нет: все девять потребителей исполняют вход
одинаково. Это цена, а не дефект — но цена, которой остальные цели не платят.

### Decision Drivers

1. **Цена без пользы.** Копия массива на вызов не даёт ничего: тело параметр
   только читает (запись в параметр языком не выражается — он не место записи).
2. **Признак обязан быть один.** Сигнатуру печатает `rust_func`, аргумент —
   `rust_expr`; разъедься они, вывод не соберётся (`E0308`).
3. **Бит-вектор — не массив**: `[bit;N ≤ 64]` печатается
   скаляром, и по ссылке его передавать нельзя.

### Considered Options

#### Option A. Оставить по значению

**Pros:** нулевой риск, borrow checker не задет.
**Cons:** цена на каждом вызове; форма расходится с тремя другими целями без
причины.

#### Option B. Передавать срез (`&[u8]`)

**Cons:** теряется длина в типе, а с ней — проверка компилятором; индексация
осталась бы, но `[u8; N]` в Rust точнее и дешевле.

#### Option C. Передавать ссылку на массив (`&[u8; N]`)

**Pros:** длина сохранена в типе; индексация и чтение работают через
авторазыменование, тело печатается прежним путём; форма согласуется с `c` и
`st`.

**Cons:** признак нужен в двух печатниках — снимается общим носителем.

### Decision

Принимается **Option C**. Признак живёт в `generator/rust/rust_byref.rs`
(`is_array_by_reference`) и спрашивается обоими печатниками.

**Упакованный бит-вектор исключён:** `[bit;N ≤ 64]` — скаляр (0078), его тип
печатается не массивом.

**Отдельный модуль, а не функция в `rust_expr`** — не только ради
связности: `rust_expr.rs` упирался в предел размера (1017 строк при лимите
1000 после правки), и вынос был обязателен.

### Consequences

#### Положительные

- Вызов не копирует массив; форма согласована с целями `c` и `st`.
- Признак невозможно продублировать — он в своём модуле.

#### Отрицательные / Action items

- Вывод цели `rust` на таких функциях меняется (`&[u8; N]`, `&self.data`).
  Корпус не затронут — функций с массивом в параметре в `examples/` нет.

#### Acceptance criteria

1. Порождённый Rust компилируется и проходит `clippy -D warnings`.
2. Все тесты зелены; вывод корпуса не изменился.
3. `./scripts/precheck.sh` зелёный.

## Разработка

### Задача

#### Что было

Цель `rust` печатала `fn total(a: [u8; 4])` и вызов `total(self.data)` — копия
массива на каждый вызов, тогда как `c` передаёт указатель, `st` — `VAR_IN_OUT`,
`sv` — плоский вектор.

#### Что сделано

**1. Признак в своём модуле.** `generator/rust/rust_byref.rs`:
`is_array_by_reference(ty)` — массив, кроме упакованного бит-вектора
(`[bit;N ≤ 64]` — скаляр по правилу).

**2. Оба печатника спрашивают его:** сигнатуру печатает `rust_func`, аргумент —
`rust_expr`. Разъедься они, порождённый код не собрался бы (`E0308`) — поэтому
признак вынесен, а не продублирован.

**Вынос был ещё и обязателен по размеру:** `rust_expr.rs` после правки
достиг 1017 строк при лимите 1000, и проверка отверг прогон.

Статус по функциональности (правило 11): правка только у цели `rust`; эталон,
прочие цели и семантика не трогались.

#### Проверки

## Итог (что сделано)

- Массив в параметре функции цель `rust` печатает теперь по ссылке
  (`a: &[u8; 4]`), а аргумент — `&self.data`.
- **Признак — один на два печатника** (`rust_byref::is_array_by_reference`):
  сигнатуру печатает `rust_func`, аргумент — `rust_expr`; разъедься они,
  порождённый код не собрался бы (`E0308`). Отдельный модуль делает копию
  невозможной по построению.
- **Упакованный бит-вектор (`[bit;N ≤ 64]`) исключён:** он **скаляр**, и печать типа у него не массивная — передача по ссылке
  развела бы форму аргумента и форму параметра.
- Вывод корпуса не изменился: функций с массивом в параметре в `examples/` нет
  ни одной (то же наблюдение, что у 0372).
