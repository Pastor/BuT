## Краткое описание

Переменная **без инициализатора** типа `Struct`, `duration` или `q(m, n)` даёт
у цели `rust` отказ **`RS-014`** «Значение по умолчанию для типа '…' не
строится», тогда как семь остальных потребителей ту же запись переводят и
исполняют. Отказ приходит из `generator/rust/rust_decl.rs::default_value` — она
знает `bit`/`bool`/`float`/целые/массив/перечисление, а три законных типа языка
проваливаются в ветвь `other =>`.

**Замер-21** (`scripts/probe.sh -n 3`), три входа:

| Вход | эталон | `c`, `c-hal`, `st`, `st-at`, `sv`, `sv-mmio`, `plantuml` | `rust` |
|---|---|---|---|
| `var v: Aa;` при `struct Aa { b: Bb, n: u8 }` | `v=Aa{b=Bb{m=0},n=0}` | переводят | **`RS-014`** |
| `var f: q(4, 4);` | `f=0.0000` | переводят | **`RS-014`** |
| `var d: duration;` | см. ниже | переводят | **`RS-014`** |

**Контрольный вход обязателен**: та же переменная **с**
инициализатором (`var f: q(4, 4) := 1.0 as q(4, 4);`) цель `rust` переводит —
значит отказывает именно умолчание, а не тип как таковой.

**Замер на `duration` неполон со стороны эталона:** переменная без
инициализатора получает у него значение **целого**, и `d > e` при
`e: duration := 1s` даёт `SIM-005` «операция '>' не определена для операндов
целое и длительность». Это **второй, отдельный** дефект (умолчание длительности
у эталона); поведение семи целей им не затронуто — они переводят вход, который
`rust` отвергает. Класс выносится кандидатом.

> Фича зарегистрирована из бэклога кандидатов (запись «Цикл структур не
> диагностируется» — проба при её проверке вскрыла соседний класс); далее
> проходит жизненный цикл по своду.

### Контекст

Переменная **без инициализатора** получает у цели `rust` значение из
`generator/rust/rust_decl.rs::default_value`. Функция разбирает `bit`/`bool`,
`float`, целые, массив (в том числе бит-вектор шире 64 бит) и перечисление, а
всё прочее отдаёт ветви `other =>` — отказ **`RS-014`** «Значение по умолчанию
для типа '…' не строится».

**Замер-21** (`scripts/probe.sh -n 3`, восемь целей и эталон):

| Вход | эталон | семь целей | `rust` |
|---|---|---|---|
| `var v: Aa;`, `struct Aa { b: Bb, n: u8 }` | `v=Aa{b=Bb{m=0},n=0}` | переводят | **`RS-014`** |
| `var f: q(4, 4);` | `f=0.0000` | переводят | **`RS-014`** |
| `var d: duration;` | (свой дефект, см. ниже) | переводят | **`RS-014`** |
| `var b: Buf;`, `struct Buf { data: [u8; 40], n: u8 }` | исполняет | переводят | **`RS-014`** |

**Контрольный вход**: та же переменная **с** инициализатором
(`var f: q(4, 4) := 1.0 as q(4, 4);`, `var v: Aa := {{7}, 3};`) целью `rust`
переводится — отказывает именно умолчание, а не тип.

#### Второй дефект того же места: `derive(Default)` порождает невалидный Rust

Объявление структуры печатается с `#[derive(Debug, Clone, Copy, PartialEq,
Default)]`, и комментарий в коде называет `Default` обязательным: общая
переменная под-модели без инициализатора печатается в конструкторе как
`Default::default()` (`rust_shared.rs::emit_shared_new_block`).

Но `derive(Default)` **выводится не всегда**, и прогон `rustc` это показывает
при **нулевом** коде возврата `taktc`:

```
error[E0277]: the trait bound `Mode: Default` is not satisfied   // поле-перечисление
error[E0277]: the trait bound `[u8; 40]: Default` is not satisfied // поле-массив N > 32
```

У перечисления `Default` не выводится вовсе (нужен атрибут `#[default]` на
варианте), а `impl Default for [T; N]` в стандартной библиотеке существует
только для `N ≤ 32`. То есть цель кладёт на диск файл, который не собирается,
и **вход с полем-перечислением есть в замере выше** — он же служит контролем к
первой половине.

**Замер на `duration` со стороны эталона неполон:** переменная без
инициализатора получает у него значение **целого**, и сравнение с `duration`
даёт `SIM-005`. Это **третий, отдельный** дефект (умолчание длительности у
эталона); поведения семи целей он не касается и выносится кандидатом.

### Решение

**Умолчание значения строит один носитель `default_value`; `impl Default`
структуры печатается по нужде — только там, где `derive(Default)` не
выводится.**

1. `default_value` дополняется тремя ветвями:
   - `TypeNode::Duration` → `0` (цель печатает длительность как `u32`
     миллисекунд — `rust_type.rs`);
   - `TypeNode::Fixed { m, n, .. }` → `0` (хранение — `i{W}`, нулевой код
     означает `0.0` в любом формате `q`);
   - `TypeNode::Struct(name)` → `<Имя>::default()`.
2. `emit_structs` печатает `Default` в `derive` **если он выводится**, иначе —
   ручной `impl Default`: литерал полей в **объявленном** порядке, значение
   каждого поля — `default_value` того же типа. Имена полей нормируются тем же
   правилом, что и объявление (`normalize_lowercase_snakecase`), имя типа —
   `rust_type_name`: форма совпадает с литералом инициализатора
   (`rust_struct::struct_literal`), и живёт тело в том же модуле.
3. Признак «`derive(Default)` выводится» (`rust_struct::derives_default`):
   перечисление — **нет** (нужен атрибут `#[default]` на варианте), массив —
   только при длине ≤ 32 **напечатанного** типа (бит-вектор шире 64 бит
   печатается массивом **слов**, 0078) и при выводимом элементе, структура —
   рекурсивно по полям, прочее — да.

**Печатать `impl Default` Всегда нельзя, и это замер, а не осторожность:**
`clippy::derivable_impls` под `-D warnings` — **отказ** сборки, а проверка цели
гоняет ровно эти флаги. Проба 2026-08-21: ручной `impl Default for Bb { … Bb {
m: 0 } }` даёт «error: this `impl` can be derived», а тот же импл для структуры
с полем-перечислением и с полем `[u8; 40]` линт проходит с кодом 0 — то есть
признак «derive не выводится» и признак «линт молчит» совпадают по построению.

### Отвергнутые варианты

**А. `#[derive(Default)]` перечислению плюс `#[default]` первому варианту.**
Чинит только поле-перечисление; поле-массив `N > 32` остаётся невалидным
выводом. Вдобавок заводит **второй** носитель правила «умолчание перечисления —
первый вариант»: то же правило уже записано в `default_value`, и два списка
одного набора расходятся.

**Б. `default_value` для структуры печатает литерал полей (без `impl`).**
Умолчание переменной чинится, а невалидный `derive(Default)` остаётся — то есть
худшая половина дефекта (файл не собирается при коде возврата 0) переживает
правку. Вдобавок литерал вложенной структуры разворачивался бы рекурсивно в
одну строку, тогда как `<Имя>::default()` короче и читаемее.

**В. Снять `Default` со структуры и заменить `Default::default()` в
`emit_shared_new_block` на `default_value`.** По существу верно и даже точнее
(там тоже нет знания о типе), но затрагивает общий путь под-моделей и его
сверки; предмет фичи — умолчание **типа**, а не устройство `shared`. Вынесено
кандидатом.

**Г. Печатать `impl Default` всегда, снять `Default` из `derive`.** Отвергнуто
пробой: `clippy::derivable_impls` роняет проверка на структуре со скалярными полями
(см. выше). Глушение линта атрибутом `#[allow(…)]` в порождённом коде проект не
практикует (политика 0169: вывод не должен просить инструмент молчать).

**Д. Снять `Default` у структуры вовсе, а фолбэк `Default::default()` в
`emit_shared_new_block` заменить на `default_value`.** По существу верно —
знание осталось бы одно, — но фолбэк касается общих переменных **под-моделей**, а `default_value` требует модели, в которой объявлена структура:
корень чужую не найдёт. Предмет фичи — умолчание **типа**, а не устройство
`shared`; вынесено кандидатом.

### Последствия

- Вход, законный сегодня и переводимый семью потребителями, перестаёт
  отвергаться восьмым: три типа получают умолчание.
- Порождённый Rust для структуры с полем-перечислением или массивом `N > 32`
  начинает **компилироваться**; прежде он клался на диск невалидным.
- Форма вывода корпуса **не меняется**: у структур корпуса `derive(Default)`
  выводится, поэтому печать остаётся прежней. Изменяется вывод только там, где
  сегодня он невалиден. Снапшоты `examples/generated/rust` и `book/`
  обновляются в рамках фичи (детерминированность генерации — 0048).
- Язык не меняется: версия языка не поднимается.

### Объём правки

| Место | Что делается |
|---|---|
| `generator/rust/rust_decl.rs::default_value` | три ветви: `Duration` → `0`, `Fixed` → `0`, `Struct` → `<Имя>::default()` |
| `generator/rust/rust_decl.rs::emit_structs` | `Default` уходит из `derive`; печатается ручной `impl Default` |
| `generator/rust/rust_struct.rs` | носитель тела `impl Default` и признака `derives_default` (модуль уже держит знание «как выглядит агрегат структуры», 49 строк) |

**Место печати `impl Default` — `rust_struct.rs`, а не `rust_decl.rs`.**
Модуль заведён фичей ровно под знание «как выглядит агрегат структуры у
цели `rust`», и литерал умолчания есть тот же агрегат: два носителя одной формы
разошлись бы. Размер `rust_decl.rs` — 493 строки, то
есть лимит (0027) правку не гонит; решает принадлежность знания.

## Разработка

### Задача

- **Фича:** [../features/0351-rust-default-value-types.md](0351-rust-default-value-types.md)
- **ADR:** [0351-rust-default-value-types.md#архитектура-adr](0351-rust-default-value-types.md#архитектура-adr)
- **Анализ:** [0351-rust-default-value-types.md#анализ](0351-rust-default-value-types.md#анализ)
- **Дата:** 2026-08-21

#### Что сделано

##### 1. `default_value` знает три типа (`generator/rust/rust_decl.rs`)

| Тип | Умолчание | Почему так |
|---|---|---|
| `Duration` | `0` | цель печатает длительность как `u32` **миллисекунд** (0183) |
| `Fixed { m, n, .. }` | `0` | хранение — `i{W}`; нулевой код есть `0.0` в любом `q`  |
| `Struct(name)` | `<Имя>::default()` | у структуры есть собственный `Default` (см. п. 2) |

Прежде все три проваливались в ветвь `other =>` — отказ `RS-014` «Значение по
умолчанию для типа '…' не строится» при том, что семь остальных потребителей
ту же запись переводят.

##### 2. `impl Default` печатается по нужде (`emit_structs` + `rust_struct.rs`)

`#[derive(Default)]` печатался у структуры **безусловно**, а выводится он не
всегда: у перечисления `Default` не выводится вовсе, а
`impl Default for [T; N]` в стандартной библиотеке существует только до
`N = 32`. Прогон `rustc` на порождённом файле давал `E0277` при **нулевом**
коде возврата `taktc`.

Теперь `emit_structs` спрашивает `rust_struct::derives_default`:

- **выводится** → печать прежняя (`#[derive(…, Default)]`), вывод корпуса
  байт-в-байт тот же;
- **не выводится** → `derive` без `Default`, следом ручной
  `impl Default for <Имя>` с телом от `rust_struct::default_literal`.

Тело — литерал полей в **объявленном** порядке, значение каждого поля даёт
`default_value`: знание «чему равно умолчание типа» остаётся у одного носителя,
а форма агрегата совпадает с литералом инициализатора (`struct_literal`, 0293) —
оба живут в одном модуле.

#### Ловушки (проверено прогоном)

**Печатать `impl Default` всегда нельзя.** `clippy::derivable_impls` под
`-D warnings` — **отказ** сборки, а проверка цели гоняет ровно эти флаги. Проба
2026-08-21: ручной импл для структуры со скалярными полями даёт «error: this
`impl` can be derived»; тот же импл для структуры с полем-перечислением и с
`[u8; 40]` линт проходит с кодом 0. Признак «derive не выводится» и признак
«линт молчит» совпадают по построению.

**Длина массива считается у напечатанного типа.** `[bit; N > 64]`
печатается массивом **слов** `[u64; ⌈N/64⌉]` (0078), поэтому `derives_default`
берёт число слов, а не разрядов; `[bit; N ≤ 64]` — упакованный скаляр, длины у
него нет вовсе. Наивный счёт по `TypeNode::Array(n, …)` объявил бы `[bit; 40]`
невыводимым, а `[bit; 4096]` (64 слова) — выводимым: обе ошибки тихие.

**Признак рекурсивен по полям структуры.** Структура, содержащая структуру с
полем-перечислением, `Default` тоже не выводит — иначе `E0277` возвращается на
уровень выше.

#### Границы

- Фолбэк `Default::default()` для общих переменных **под-моделей**
  (`rust_shared.rs::emit_shared_new_block`) не трогался: он требует модели, в
  которой объявлена структура, а корень чужую не найдёт. Вынесено кандидатом.
- Умолчание переменной типа `duration` у **эталона** — отдельный дефект
  (значение получает вид целого, сравнение с длительностью даёт `SIM-005`);
  поведения целей он не касается, вынесен кандидатом.

### Что именно контролируем

Класс двойной, и обе половины **невидимы корпусу**: в `examples/` нет ни
переменной без инициализатора типа `q`/`duration`/структуры, ни структуры с
полем-перечислением, ни массива длиннее 32. Проверка цели гоняет только корпус,
поэтому контроля — **фикстурные**, с прогоном настоящих `rustc`/`clippy`.

### Слои проверки

| Слой | Что доказывает | Почему нужен |
|---|---|---|
| 1. эмиссия | в выводе стоит ожидаемое умолчание и ожидаемая форма (`derive` либо `impl`) | ловит регресс дёшево и **точно называет** место |
| 2. `clippy -D warnings` | вывод принимается тем же проверкой, что в `precheck.sh` | доказывает, что ловим **настоящее** правило линта, а не своё представление |
| 3. потактовая сверка | значения умолчаний совпадают с **эталоном** | компиляция не отличает `0` от `1`: линт принимает вывод, который считает другое  |

### Условия проверок и ожидаемые результаты

#### Примеры (запись законна, вывод обязан быть верен)

| № | Вход | Ожидание |
|---|---|---|
| П1 | `var v: Aa;` при `struct Aa { b: Bb, n: u8 }` | поле печатается `Aa::default()`, вывод собирается |
| П2 | `var f: q(4, 4);` | поле печатается `0` |
| П3 | `var d: duration;` | поле печатается `0` |
| П4 | `struct Cfg { mode: Mode, n: u8 }` (поле-перечисление) | `derive` **без** `Default` + `impl Default` с первым вариантом (`Mode::Idle`) |
| П5 | `struct Buf { data: [u8; 40], n: u8 }` | `derive` без `Default` + `impl Default` с `[0; 40]` |
| П6 | `struct Wide { w: [bit; 4096], n: u8 }` | поле печатается `[u64; 64]`, форма — ручной `impl Default` |

#### Контрпримеры (без них «починка» читается неверно)

| № | Вход | Ожидание | Что ловит |
|---|---|---|---|
| К1 | `struct Point { x: u8, y: u8 }` (скаляры) | `derive(…, Default)` **сохранён**, ручного `impl` **нет** | «печатать импл всегда» — `clippy::derivable_impls` роняет проверка |
| К2 | `struct Narrow { b: [bit; 40], n: u8 }` | `derive` сохранён | `[bit; N ≤ 64]` — упакованный **скаляр** (0078), а не массив длины 40 |
| К3 | структура с инициализатором (`var v: Aa := {{7}, 3};`) | печатается литерал, не `::default()` | правка не должна подменять авторское значение умолчанием |

#### Потактовая сверка с эталоном

| № | Вход | Ожидание |
|---|---|---|
| С1 | модель, выводящая в порт поля структуры, `q` и `duration` **без инициализаторов**, по тактам | трасса цели `rust` совпадает с трассой `takt-sim` |

Сверка обязана брать **накапливающее** тело (значение меняется по тактам):
на постоянном нуле «умолчание ноль» и «значение не пишется вовсе» неразличимы.

### Найденные дефекты

Дефектов, требующих исправлений, не найдено. Одна правка **внутри** разработки:
первая редакция фикстуры `PLAIN` объявляла `f` и `d`, но их **не
использовала**, и штатный фильтр цели выбрасывал переменные из вывода — тест на
умолчание прошёл бы на выводе, где переменной нет вовсе. Это ловушка,
описанная сводом и проверяемая `probe.sh`; поймал её сам тест (упал на
`f: 0,`), фикстура дополнена использованием.

### Мутационная проверка контрольных тестов

Каждый контроль проверен внесением дефекта в код и прогоном:

| Мутация | Кто упал | Что доказано |
|---|---|---|
| `derives_default` всегда `false` (импл печатается всегда) | К1, К2, проверка `clippy` | контрпримеры не декоративны: «печатать импл всегда» ловится |

Вторая мутация — главный довод существования сверки: эмиссионные тесты и

## Итог (что сделано)

**Умолчание значения строит один носитель, а `derive(Default)` перестал
порождать невалидный вывод.**

- **`default_value` знает три типа:** `duration` → `0` (цель печатает `u32`
  миллисекунд), `q(m, n)` → `0` (хранение `i{W}`), структура → её собственный
  `Default`. Прежде все три давали `RS-014` там, где эталон и семь остальных
  целей запись переводят.
- **`impl Default` печатается по нужде.** `#[derive(Default)]` печатался
  безусловно, а выводится не всегда: у перечисления его нет вовсе, а
  `impl Default for [T; N]` в стандартной библиотеке есть только до `N = 32`.
  Такой файл ложился на диск при **нулевом** коде возврата `taktc` и не
  собирался (`E0277`).
- **Печатать импл всегда нельзя, и это замер:** `clippy::derivable_impls`
  под `-D warnings` — отказ сборки, а проверка цели гоняет ровно эти флаги.
  Признак «derive не выводится» и признак «линт молчит» совпадают по
  построению.
- **Вывод корпуса не изменился:** у структур `examples/` `derive`
  выводится. Класс корпусом не покрыт — контроля фикстурные, с прогоном
  настоящих `rustc`/`clippy`, плюс потактовая сверка с эталоном.
- **Мутация показала, зачем сверка:** неверное умолчание `q` (`16` вместо
  `0`) эмиссионные тесты и `clippy` **пропустили** — упала только сверка
  значений.
- Заведены два кандидата: умолчание `duration` у **эталона** имеет вид целого
  (из-за этого `duration` не вошла в сверку) и второй носитель умолчания в
  `emit_shared_new_block`.

Детали — в [отчёте](0351-rust-default-value-types.md#отчёт-о-тестировании).
