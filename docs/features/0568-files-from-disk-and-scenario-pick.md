### Context

Обмен с диском был неполон и стоял не там: загрузка архива жила полем выбора
файла в панели учётной записи — там, куда ходят за входом, а не за проектом; у
отдельного файла обмена не было вовсе, хотя проект собирают из того, что уже
написано. Сценарий прогона выбирался щелчком по файлу в структуре, то есть
знанием, а не действием: какой из `.json` относится к открытой модели, автор
должен был помнить сам.

### Decision

Действия над проектами стоят в одной полосе: завести, открыть, загрузить архив.
Действия над файлами — в своей: завести, загрузить с диска, выгрузить на диск,
переименовать, удалить.

Сценарий принадлежит модели по имени: файл `.json`, чьё имя начинается с имени
модели, — её сценарий. Кнопка выбора стоит там же, где правят текст модели,
и показывает список только её сценариев.

### Consequences

Правило имени названо словами и действует в обе стороны: `heater.json` и
`heater-cold.json` принадлежат `heater.takt`, `probe.json` — нет. Пустой список
говорит словами: молчащее окно читалось бы как поломка.

Загрузка файла не перезаписывает занятое имя — отказ страницы, а не молчаливая
подмена чужого текста. Выгрузка берёт текст **у сервера**: в области кода лежит
правка автора, а выгружается файл проекта.

## Разработка

### Задача — архив кнопкой

Поле выбора файла переехало из панели учётной записи в полосу структуры и
спряталось: его открывает кнопка-значок, ряд значков не разрывается чужим
контролом. Кнопка видна, пока проект не открыт, — это действие над проектами.

### Задача — файл с диска и на диск

`uploadFile` берёт имя у самого файла (его же видит автор у себя), род решает
расширение; занятое имя — отказ. `downloadFile` читает файл проекта у сервера и
отдаёт его браузеру ссылкой-объектом, как это уже делает выгрузка архива.

### Задача — выбор сценария

Кнопка в полосе действий области кода открывает окно со списком сценариев
открытой модели (`scenariosOf`), выбранный назначается активным той же точкой,
что и щелчок по файлу в структуре (`chooseScenario`). Модель узнаётся по
выбранному файлу: сам `.takt` либо модель, парная открытой раскладке.

### Проверки

`check-web.sh` (105 тестов), `check-design.py` (441 правило), прогон страницы на
сервере с базой: пустой список сценариев говорит словами, заведённый
`heater-cold.json` встаёт в список открытой модели.

## Отчёт о тестировании

### Резюме

Три требования выполнены, проверки зелёные.

### Фактические результаты по проверкам

1. Кнопка загрузки архива стоит рядом с «завести» и «открыть» и уходит, когда
   проект открыт.
2. Файл с диска попадает в проект под своим именем и сразу открывается;
   занятое имя отвергается словами.
3. Выгрузка отдаёт браузеру файл проекта под его именем.
4. Список сценариев показывает `heater-cold.json` у модели `heater.takt` и не
   показывает `run.json`; у модели без сценариев список говорит словами.
