# Фича: Сравнение поля структуры в условии: rust печатает поле булевым

- **Номер:** 0413
- **Статус:** ГОТОВО
- **Зависит от:** нет
- **Tier:** 2 — невалидный вывод при рапорте об успехе
- **Класс:** генерация
- **Связанные issue (анализ):** находка [порт составного типа: нормировать ли в семантике](0390-port-composite-type-policy.md)

## Краткое описание

`ref Run: v.a = 1;` при `struct Pair { a: u8, b: u8 }` цель `rust` печатала
`if self.v.a` — тип поля считался **булевым**. `rustc` отвечал `E0308` при
**нулевом** коде возврата `taktc`.

Тот же класс [вложенная структура — порядок объявления и тип поля](0341-nested-struct-order.md) закрыла у печатника
**выражений**; печатников два, и правка одного оставила второй.

### Decision

`condition_type` различает формы члена: разряд (`Member::Number`) — `bool`,
поле структуры (`Member::Identifier`) — `None`. Тип поля печатнику условий
неизвестен (объявление лежит в модели), и честный `None` означает «приведение
не применяется, печать идёт обычным путём» — ровно то решение, что приняла
0341 для выражений.

## Итог (что сделано)

Печатник условий цели `rust` перестал считать булевым **любой** доступ через
точку: разряд остаётся логическим, поле структуры отвечает `None`.

Класс найден **контрольным входом фичи** и к её предмету отношения не
имеет: составного порта во входе нет.

Это третье повторение одного урока: печатников у выражений и условий
**два**, и правка одного чинит половину входов (0359, 0363, теперь 0413).
