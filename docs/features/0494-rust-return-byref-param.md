## Краткое описание

Массив в параметре цель передаёт **по ссылке** (`a: &[u8; 2]`), а
возврат объявлен по значению. `return a;` печаталось как есть, и `rustc`
отвечал `E0308` при **нулевом** коде возврата `taktc`. Теперь имя, пришедшее по
ссылке, в позиции значения разыменовывается.

**Не требуется.** Язык не меняется; правится форма вывода одной цели.

## Архитектура (ADR)

- **Status:** Accepted
- **Date:** 2026-09-02
- **Authors:** архитектор, аналитик

### Context

Замер-02 (`probe.sh -n 2` на `fn pick(a: [u8; 2]) -> [u8; 2] { return
a; }`):

| Потребитель | Ответ |
|---|---|
| эталон, `st`, `st-at`, `sv`, `sv-mmio`, `plantuml` | исполняют / переводят, инструменты приняли |
| `c`, `c-hal` | `CC-015` — **названная граница** (массив из функции не возвращают, 0431) |
| **`rust`** | `rustc`: `E0308 mismatched types` при нулевом коде возврата |

Класс виден только вместе с параметром-массивом: без него возврат массива у
`rust` работает (0431), а у `c` вход отсекается раньше — его граница и скрывала
предмет в первой пробе фичи.

### Decision

Имя из списка «пришло по ссылке» в позиции **значения** печатается
разыменованным (`*a`). Список кладётся в `Scope::by_ref` тем же признаком
`rust_byref`, которым выбрана форма параметра, — второго знания не заводится.

Разыменование ставится **только на имя целиком**: `a[0]` над ссылкой
работает само, а `(*a)[0]` отвергает `clippy` под `-D warnings`.

Печатников возврата **два** — хвостовое выражение и явный `return`, и правило стоит в обоих. Первая редакция правила правила только явный
`return`, а вывод шёл хвостом — замер не изменился.

### Consequences

- Возврат параметра-массива собирается; прочие позиции не тронуты.
- Массив здесь `Copy`, поэтому `*a` — копия, а не перемещение.

#### Acceptance criteria

1. `rustc` и `clippy` принимают вывод для хвостового и раннего возврата.
2. Индексация параметра разыменования не получает.
3. `./scripts/precheck.sh` зелёный.

### Задача — список «по ссылке» и разыменование

`rust_stmt::deref_if_by_ref` печатает `*a` в обоих путях возврата.

### Примеры и контрпримеры (правило 16)

Язык не меняется. Контроль — индексация параметра: разыменование там не нужно
и запрещено линтом.

### Найденные дефекты

Один — в первой редакции правки: правило стояло только в печатнике явного
`return`, а вывод шёл **хвостовым выражением**, и замер не изменился. Это тот
самый класс («путей печати возврата два»), и он повторился здесь буквально.

### Правило размера модуля

Поле `by_ref` вывело `rust_expr.rs` за лимит (1001 строка). Ужимать
доккомментарий до нечитаемого не стал: по границе ответственности вынесен
`rust_text.rs` — работа с **напечатанной строкой** (снятие внешних скобок),
которая семантических узлов не знает вовсе. Файл стал 995 строк.

### Вердикт

**Готово.** Шесть условий тест-плана выполнены.
