## Краткое описание

Миникарта листа схемы не спрашивается ни о чём: она есть всегда на широком
экране и пропадает на узком правилом вёрстки. Она становится в один ряд с
панелями — строкой во вкладке «Панели» окна настроек со ступенями «всегда»,
«широкий экран», «скрыть».

> Фича зарегистрирована по требованию заказчика 2026-09-09; далее проходит
> жизненный цикл по своду.
