# Фича: Цель sv — формы константы, синтезируемые yosys

- **Номер:** 0491
- **Статус:** ГОТОВО
- **Зависит от:** нет
- **Tier:** 2
- **Класс:** генерация
- **Связанные issue (анализ):** кандидат `FEATURES.md` (заведён при закрытии 0490)

## Стадии жизненного цикла (правило 17)

Все стадии — **разделы этой карточки** (правило 32). Отдельным артефактом
остаются только исправления — [`docs/fixes/`](../fixes/README.md).

## Краткое описание

Константа массива печаталась `localparam logic [7:0] X [0:1] = '{…};`, а
константа перечислимого типа — `localparam mode_e X = MODE_RUN;`.
`verilator --lint-only -Wall` принимал обе формы, а `yosys` отвечал
«syntax error, unexpected '['» и «Non-constant width range on parameter decl»
— при **нулевом** коде возврата `taktc`. Фича переводит обе константы в формы,
которые принимают **оба** инструмента проверки.

## Документирование (правило 24)

**Не требуется.** Язык не меняется — правится форма вывода одной цели,
невидимая автору модели; диагностик фича не заводит.

## Архитектура (ADR)

- **Status:** Accepted
- **Date:** 2026-09-02
- **Authors:** архитектор, аналитик

### Context

Замер-02 (`probe.sh`, проверка цели гоняет **оба** инструмента):

| Вход | verilator | yosys |
|---|---|---|
| `const SETTING: [u8; 2] := {1, 2};` | принял | **«syntax error, unexpected '['»** |
| `const SETTING: Mode := Run;` | принял | **«Non-constant width range on parameter decl»** |
| контроль: `var src: [u8; 2]` (переменная) | принял | синтезировал |

Класс виден только потому, что проверка цели гоняет **два** инструмента: линт
формы не различает. Тот же приём нашёл дефекты и 0369.

### Considered Options

1. **Отказ цели** на константе-массиве. Отвергнуто: контроль показывает, что
   переменная-массив синтезируется — значит выразить значение можно, и отказ
   был бы потерей возможности, а не границей платформы.
2. **Упакованный `localparam`** с индексацией срезом. Отвергнуто: меняет форму
   всех мест индексации, а переменный индекс потребовал бы сдвигов.
3. **Формы, проверенные прогоном обоих инструментов** (принято, ниже).

### Decision

1. **Константа-массив** объявляется сигналом (`logic [7:0] X [0:1];`), а
   значение задаётся в **цепи сброса** (`X <= '{8'd1, 8'd2};`). Значение
   постоянно, и синтезатор сводит регистры к константам сам.
2. **Константа перечислимого типа** объявления не получает вовсе: обращения
   печатаются **именем варианта** (`MODE_RUN`), которое само несёт свой тип.

Форма выбрана **пробой обоих инструментов**, а не чтением стандарта:
промежуточный вариант «нетипизированный `localparam`» yosys принимает, а
verilator отвергает (`ENUMVALUE`: приёмник строго типизирован) — то есть
подходит ровно одна форма из трёх.

### Consequences

- Константы обоих видов синтезируются; вывод корпуса не изменился (снимки
  `examples/generated/` совпали).
- Бит-вектор `[bit;N≤64]` не затронут: он упакованный **скаляр** (0078), и
  `localparam` ему верен.

#### Acceptance criteria

1. Константа-массив и константа перечисления проходят `verilator -Wall` и
   `yosys synth`.
2. В выводе нет `localparam` распакованного массива и типизированного
   `localparam` перечисления.
3. Снимки `examples/generated/` не изменились.
4. `./scripts/precheck.sh` зелёный.

## Разработка

### Задача — константа-массив сигналом

`sv_const::emit_constants` возвращает пары `(имя, значение)` для
констант-массивов; `sv_fsm::emit_ff` печатает их в цепи сброса.

### Задача — константа перечисления именем варианта

`sv_names::enum_constant_literal` находит вариант по значению; `signal_of`
возвращает его имя, а `emit_constants` такую константу пропускает.
