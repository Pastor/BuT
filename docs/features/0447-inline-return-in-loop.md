# Фича: Подстановка тела с возвратом из счётного цикла

- **Номер:** 0447
- **Статус:** ГОТОВО
- **Зависит от:** [подстановка тела с ранним возвратом](0446-inline-early-return.md)
- **Tier:** 4 (форма порождённого кода: подстановка становится доступна ещё
  одному классу тел)
- **Класс:** семантика
- **Связанные issue (анализ):** по запросу заказчика 2026-08-31 («сними границу
  с return внутри цикла»)

## Стадии жизненного цикла

Все стадии — **разделы этой карточки**. Отдельным артефактом
остаются только исправления — [`docs/fixes/`](../fixes/README.md).

## Краткое описание

[подстановка тела с ранним возвратом](0446-inline-early-return.md) научила подстановку раннему выходу, но
оставила названную границу: `return` внутри цикла. Фича снимает её для цикла,
**завершение которого не зависит от тела** — `for` со счётчиком от литерала до
литерала. Тело такого цикла целиком уходит под признак выхода: оставшиеся
итерации прокручиваются вхолостую, а завершает цикл его собственный счётчик.

## Документирование

**Требуется** — меняется наблюдаемая граница языка: раздел
[«Функции»](../../book/src/07-functions/) и приложение
[«Ошибки»](../../book/src/appendix-errors/) (`SE-128`).

## Архитектура (ADR)

- **Status:** Accepted
- **Date:** 2026-08-31
- **Authors:** архитектор

### Context

Подстановка гасит операторы после возможного выхода условием «выхода ещё не
было». Для цикла этого мало: если условие продолжения считает **тело**, а тело
погашено, цикл не завершится никогда.

### Замер форм

Четыре формы прогнаны `probe.sh` по всем девяти потребителям:

| Форма | Итог |
|---|---|
| `break` из цикла | переводят семь целей; **`sv` отказывает** `SV-002` («оператор break (циклов нет)») — цель разворачивает цикл в схему |
| условие цикла усилено признаком (`!done & (i < 4)`) | **`sv`** `SV-002` (цикл перестаёт разворачиваться: границы неизвестны), **`rust`** `RS-011`, **`st`** `ST-011` (смешение битового признака со сравнением) |
| тело цикла под `if !done { … }` | переводят **все восемь**, но `clippy` — `collapsible_if` |
| тело цикла под `if !done && cond { … }` | переводят **все восемь**; приняли `cc`, `iec2c`+`cc`, `rustc`+`clippy`, `verilator`, `yosys` |

### Decision

1. Тело цикла понижается и целиком уходит под признак выхода — **условие цикла
   не трогается**: любая его правка ломает разворот у цели `sv`.
2. Правило применяется, только если цикл завершается **независимо от тела**:
   `for` со статически известным числом итераций. Признак берётся у общего
   носителя `semantic::loop_bounds` — того же, которым цель `sv` разворачивает
   цикл в схему: второй разбор тройки `init`/`cond`/`step`
   разошёлся бы с первым молча.
3. `loop`/`while` и `for` с неизвестной границей остаются `SE-128` — причина
   названа.

### Considered Options

- **A. `break` под признаком** — отвергнут замером: цель `sv` не имеет циклов
  вовсе, она их разворачивает.
- **B. Усиление условия цикла** — отвергнут замером: ломает `sv`, `rust`, `st`.
- **C. Обёртка тела** — принят.
- **D. Оставить границу** — отвергнут заказчиком.

### Consequences

`SE-128` сужается ещё раз: из «возврат внутри цикла» — в «возврат внутри цикла
с заранее неизвестным числом итераций». Признак статических границ переехал из
цели `sv` в семантику, и предел итераций стал **параметром спрашивающего**: у
`sv` это размер схемы (64), у подстановки — защита от долгого счёта (4096).

#### Acceptance criteria

- A1. Возврат из `for` со счётчиком подставляется; трасса совпадает с эталоном.
- A2. Условие цикла в выводе не изменено (иначе `sv` перестанет разворачивать).
- A3. `loop`/`while` — `SE-128` с названной причиной; под эвристикой вызов
  остаётся, и в теле такта нет `return`.
- A4. Вывод принимают все восемь целей и их инструменты.

## Анализ

### Цель и контекст

Предмет — форма порождённого кода и граница правила подстановки. Проверяемое
условие: значения не меняются, вывод валиден у всех потребителей.

### Замер

Таблица форм выше. Дополнительно:

- **дефект, найденный тем же прогоном** — `clippy::collapsible_if` на обёртке
  «выхода ещё не было», то есть на выводе уже закрытой фичи. Исправлен
  исправлением [`clippy` отвергал обёртку «выхода ещё не было»](../fixes/0446-01-inline-early-return.md): обёртка сливается с
  условным оператором. Прогон инструментов получил вторую пробу — с ранним
  возвратом;
- **сторонний класс, вынесенный кандидатом:** `clippy` требует
  `is_multiple_of()` вместо `v % 2 == 0` — это печать `%` у цели `rust`, к
  подстановке отношения не имеющая; в корпусе такой записи нет, поэтому проверка
  цели её не видит.

### Зависимости фичи

[подстановка тела с ранним возвратом](0446-inline-early-return.md) — признак выхода; [цель `sv` разворачивает `for` со статическими границами](0321-sv-for-unroll.md)
— разбор статических границ, ставший общим носителем.

### Требования и проверяемые условия

- R1. A1…A4 выше.
- R2. Признак «границы известны» — **один** на цель `sv` и на подстановку.

### Критерии приёмки и способ проверки

Потактовая сверка на фикстуре, где ранний выход из цикла срабатывает при одних
значениях и не срабатывает при других; эмиссионные тесты формы и границы;
мутации; полный `precheck.sh`.

### Редакторский слой

**Не затронут:** лексика и синтаксис не меняются.

### Особенности по обратной функциональности

Вывод корпуса при умолчании не меняется. Цель `sv` разворачивает циклы тем же
кодом, что и прежде, — он лишь переехал в общий носитель.

### Риски и зависимости

Главный риск — цикл, который перестанет завершаться после гашения тела; он снят
требованием статических границ. Второй — расхождение признака с целью `sv`; снят
общим носителем.

## Разработка

- `semantic/loop_bounds.rs` — общий носитель статических границ (перенос из
  `generator/sv/sv_unroll.rs`, предел итераций стал параметром);
- `generator/sv/sv_unroll.rs` — тонкая обёртка над носителем со своим пределом;
- `semantic/inline/early.rs` — `Obstacle::ReturnInOpenLoop` вместо
  `ReturnInLoop`, понижение `For` с гашением тела, слияние обёртки с условием.

## Итог

Граница «возврат внутри цикла» снята для цикла, завершение которого не зависит
от тела. Остаток границы назван и обоснован замером: у `loop`/`while` гашение
тела остановило бы изменение условия, а `break` цель `sv` не выражает вовсе —
она разворачивает циклы в схему.

Кандидат, вынесенный работой: цель `rust` печатает `v % 2 == 0`, а `clippy`
требует `is_multiple_of()`; в корпусе такой записи нет, поэтому проверка цели класс
не видит.
