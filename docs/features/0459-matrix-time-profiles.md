# Фича: Профили времени и clock в переборе

- **Номер:** 0459
- **Статус:** ГОТОВО
- **Зависит от:** [адресные карты и --address-map в переборе](0458-matrix-address-maps.md)
- **Tier:** 2 (перебор нашёл вход, на котором вывод цели `rust` не собирается:
  `E0308` при нулевом коде возврата `taktc`)
- **Класс:** генерация
- **Связанные issue (анализ):** по запросу заказчика 2026-08-31 («добавь в
  перебор профили времени и `clock`»)

## Стадии жизненного цикла (правило 17)

Все стадии — **разделы этой карточки** (правило 32). Отдельным артефактом
остаются только исправления — [`docs/fixes/`](../fixes/README.md).

## Краткое описание

Матрица знала одну форму времени — `after Nms` в профиле «часы». Фича добавляет
пять: тактовую выдержку `after Nt`, периодический блок `every`, выдержку от
**переменной** `duration`, вычисляемую выдержку выражением и объявление такта
`clock 1kHz;` (с обязательным совпадением ключа `--tick-hz`). Найденный дефект
чинит.

## Документирование (правило 24)

**Не требуется:** язык не меняется, чинится вывод одной цели.

## Архитектура (ADR)

- **Status:** Accepted
- **Date:** 2026-08-31
- **Authors:** архитектор

### Context

Время живёт в двух профилях ([модель времени в языке: литерал длительности и частота такта](0134-language-time-model.md)): «часы» —
метка сравнивается с `now_ms` хоста; «такты» — счётчик внутри модели. Тип
`duration` в целях — целое **32-битное** число миллисекунд (правило
[тип `duration` в целях генерации и вычисляемая выдержка](0183-duration-type-in-targets.md)), а метка времени у цели `rust` —
`u64` (`now_ms` отдаёт его).

### Замер (правило 30, 2026-08-31)

Шесть форм × два профиля × восемь целей — 88 компиляций. Дефект один:

```text
probe.rs:91:69: error[E0308]: mismatched types
   if hal.now_ms().wrapping_sub(self.takt_entry_ms) >= (self.hold) {
      ---------------------------------------------    ^^^^^^^^^^^ expected `u64`, found `u32`
```

Вход: профиль «часы» + выдержка от переменной `duration`. Код возврата `taktc`
**нулевой**. У цели `c` типы приводятся неявно, и класс её не задел.

Законные границы, вошедшие в таблицу: `ST-016` у `st`/`st-at` на вычисляемой
выдержке в профиле «часы» (переменный `PT` таймера требует своей обвязки), и
`SE-069` при несовпадении объявленного такта с ключом — поэтому ключ стал
**частью случая**, как режим `--parameters` (0457).

### Decision

Выражение выдержки **расширяется до `u64`** (`u64::from(…)`), а не метка
усекается до 32 бит: усечение поменяло бы момент переполнения счётчика, то есть
**поведение**.

### Consequences

Перебор — 310 случаев на цель, 37 с. Вывод корпуса не меняется.

#### Acceptance criteria

- A1. Шесть форм × восемь целей: инструменты принимают вывод либо цель
      отказывает ожидаемым кодом.
- A2. Мутация «сравнивать без расширения» роняет перебор.
- A3. Потактовые сверки времени зелены.

## Итог

Ось времени нашла класс, который виден только в **сочетании**: профиль «часы»
плюс выдержка от переменной. Ни профиль сам по себе, ни `duration` сам по себе
дефекта не давали — ровно поэтому перебор и заводился по сочетаниям, а не по
отдельным признакам.
