### Context

Исходники проекта со страницы не находились никак: адрес репозитория читатель
должен был знать заранее.

### Decision

- **Ссылка-значок** в шапке: вид кнопки-значка, суть — ссылка (`<a>`),
  открывается рядом (`target="_blank"`, `rel="noopener"`), не уводя со страницы с
  несохранённой работой. Знак GitHub залит, а не обведён, — так его узнают.
- **Сборка не переписывает адреса со схемой**: правило переноса адресов
  разметки в каталог бандла принимало внешнюю ссылку за относительную (найдено
  проверкой ссылок сборки).

- **Краткая версия**: `{язык}({номер})`; подсказка называет язык, сборку, время,
  коммит и ветку. Без номера сборки — версия и время, как было.

### Consequences

Подпись подсказки не переводится: это имя.
