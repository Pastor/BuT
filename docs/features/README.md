# Реестр фич (карточки)

**Единственный реестр пофичевых артефактов**. Здесь
перечислены **все** карточки фич `XXXX-slug.md` (включая закрытые); каждая
карточка содержит **все стадии** — архитектуру, анализ, разработку, тест-план,
отчёт и итог. Витрина **незакрытых** фич — в корневом
[FEATURES.md](../../FEATURES.md); исправления — в
[`../fixes/README.md`](../fixes/README.md).

Колонка «Вердикт тестирования» перенесена сюда из прежнего реестра отчётов: заготовка у фичи в терминальном статусе роняет предкоммит
(`scripts/check-registry-verdicts.py`).

Заготовка карточки создаётся из шаблона [`../templates/feature.md`](../templates/feature.md)
(вручную или генератором [`scripts/new-feature.sh`](../../scripts/new-feature.sh)).
