## Краткое описание

Состав областей страницы пересматривается. Справа появляется структура проекта —
дерево файлов (`takt`, `takt-ui`, `md`, `json`); выбор файла в дереве открывает
его в той же области, где правится код. Отдельная область симуляции упраздняется:
сценарий входов правится как файл, выбранный в дереве. Отдельная область схемы
упраздняется тоже: схема показывается при выборе файла раскладки. Из полки кнопок
остаётся показ области генерации, и он переезжает вправо; рядом встаёт кнопка
показа и сокрытия панели диагностики.

> Фича зарегистрирована по требованию заказчика 2026-09-09; далее проходит
> жизненный цикл по своду.
