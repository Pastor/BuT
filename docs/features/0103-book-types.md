## Краткое описание

Описывает **систему типов** Takt: `bool`, `bit`, целочисленные типы, упакованный битовый вектор `[bit;N]`, массивы `[T;N]`, перечисления `enum`, структуры `struct`, исправление-точку `q(m, n)`, `float`; псевдонимы типов и вывод типов.

## Итог (что сделано)

Наполнен раздел `book/src/03-types/index.typ` описанием **системы типов** Takt
(правило 24 — язык не меняется, Tier 3; ADR/анализ не требовались):

- **Примитивы** `bit`/`bool` (разведён смысл: разряд данных vs истинность).
- **Целочисленные** `u8`/`i8`…`u64`/`i64` (таблица ширин, диапазоны, арифметика
  по модулю; сверено с `type_node.rs::construct_type`).
- **Битовый вектор `[bit; N]`** (упаковка: `N ≤ 64` — слово 8/16/32/64, `N > 64`
  — слова; бит-доступ `x.k`/`x[k]`; представление `[bit;8] ≡ u8`).
- **Дробные**: `float` (прозрачный, представление выбирают флаги генерации) и
  исправление-точка **`q(m, n)`** (`m` включает знак, `n ≥ 1`, `W = m + n ≤ 64`,
  значение `v · 2⁻ⁿ`).
- **Массивы `[T; N]`** (индексация `a[i]`, инициализатор `{…}`).
- **Перечисления `enum`** (явные/неявные значения `предыдущий+1`, отрицательные;
  знак/ширина по диапазону).
- **Структуры `struct`** (порядок полей значим, позиционный инициализатор `{…}`,
  доступ `.поле`).
- **Псевдонимы `type Name = …`** и **вывод типов** (объявление без аннотации).
- Пример `book/src/03-types/examples/types.takt` — **компилируется** `taktc`
  (цель `c`, EXIT 0): примитивы, `u16`, `enum`, `struct`, `q(4, 4)`, `[u8; 4]`.
  Встроенные сниппеты (бит-запись, псевдонимы на `[bit;N]`/`q`, доступ к полю)
  проверены отдельной компиляцией.
