## Краткое описание

Вывод цели в браузере печатался с именем `playground` независимо от того, какой
файл открыт: `playground.h`, `struct Playground`. Имя корневой модели берётся из
имени файла, поэтому оно есть часть вывода, и у открытого проекта это имя его
файла. Мост принимает имя отдельным полем запроса; безымянный буфер сохраняет
прежнее умолчание.

> жизненный цикл по своду.

## Архитектура (ADR)

- **Status:** Accepted
- **Date:** 2026-09-09
- **Authors:** заказчик (замечание), разработка

### Context

У модуля есть умолчание имени входа — `playground.takt`, и страница им
пользовалась всегда. Пока файла у автора не было, это верно: буфер безымянный.
С появлением проектов файл есть, и его имя видно в шапке — а вывод цели всё
равно назывался `playground`.

Имя корневой модели берётся из имени файла, поэтому оно **часть вывода**: у
`c` это имена файлов, охранная константа и префиксы перечислений, у `rust` —
имя структуры. Печатать чужое имя значит показывать не тот код, который получит
автор, собрав модель у себя.

### Decision

Имя файла едет в мост отдельным полем запроса компиляции. Пусто — прежнее
умолчание; задано — им и печатается вывод. Позиционным аргументом в ключах
сборки имя не передаётся: ключи проверяются разбором, и подмешивать в них имя
значило бы смешать два предмета.

### Consequences

Умолчание сохранено: ссылка-снимок и безымянный буфер печатаются как прежде,
поэтому старые ссылки показывают то же, что показывали.

#### Acceptance criteria

1. Открыт файл проекта → вывод цели носит его имя.
2. Файла нет → вывод носит прежнее умолчание.
3. Вывод модуля равен выводу `taktc` — проверка тождественности зелёная.

## Анализ

### Замер (2026-09-09)

Мост подставлял `playground.takt`, если в ключах сборки нет позиционного
аргумента; страница ключами имя не передавала никогда.

## Разработка

### Задача — имя файла в запросе компиляции

Поле `filename` в запросе моста; подготовка ключей принимает его и подставляет
вместо умолчания. Страница передаёт имя открытого файла.

### Проверки

`check-wasm.sh` (88 компиляций корпуса и 6 трасс байт в байт), тесты крейта
моста, прогон страницы на сервере с базой.

## Тест-план

1. Проект с файлом `model.takt` → вывод цели `c` даёт `model.h` и `model.c`.
2. Безымянный буфер → `playground.h` и `playground.c`.
3. Тождественность модуля → зелёная.

## Отчёт о тестировании

### Резюме

Все три проверки пройдены.

### Фактические результаты

1. Открытый `model.takt` даёт `model.h`, `model.c`, `struct Model`,
   `MODEL_PORT_HEATER`.
2. Без проекта — `playground.h` и `playground.c`, как прежде.
3. `check-wasm.sh`: 88 компиляций корпуса под целями, 6 трасс — расхождений нет.

### Найденные дефекты

Нет.

## Итог (что сделано)

Вывод цели в браузере носит имя открытого файла: имя корневой модели берётся из
имени файла, и у проекта это имя его файла, а не имя безымянного буфера. Мост
принимает имя отдельным полем запроса — ключи сборки остались о ключах.
Умолчание сохранено, поэтому ссылка-снимок печатается как прежде.
