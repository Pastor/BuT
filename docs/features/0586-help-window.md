## Краткое описание

Кнопка «?» перед кнопкой генерации открывает во всю область страницы окно
справки — описание языка из документа `book/`. Слева оглавление с быстрым
переходом, сверху поиск по тексту с переходом по найденному, справа сверху
крестик. Раздел, на котором читатель остановился, запоминается (`localStorage`),
и окно открывается на нём. Оформление — палитра и шкалы страницы.

### Context

Документ языка набран Typst, и выдавался только PDF. Замер 2026-09-10: Typst
0.15.1 выгружает HTML (`--features html --format html`) за 0,6 с, но шаблон
печати превращал заголовки в абзацы с полужирным текстом, а оглавление — в
строки с номерами страниц; оглавление и память раздела строить было не по чему.

### Decision

- **Один документ — два вывода.** Правила вёрстки печати (заголовки, наклон,
  таблицы, оглавление с номерами страниц) действуют только при `target() ==
  "paged"`; HTML получает настоящие `h2`…`h5`. PDF проверен побайтно — прежний.
- **Фрагмент справки готовит сборка** (`scripts/build-web-help.py`): тело
  документа без обвязки, служебные `span` Typst сняты, цвета подсветки печати
  заменены ролями `tok-*` страницы (незнакомый цвет — отказ сборки), у каждого
  заголовка якорь по его словам — вставка главы не сбивает память читателя.
- **Справка входит в отпечаток бандла**: правка документа даёт новый адрес
  `b/<отпечаток>/`, иначе неизменяемый кеш держал бы вчерашнюю справку.
- **Стенд собирает справку обязательно** (`TAKT_HELP_REQUIRED=1`): Typst ставится
  в образ из crates.io с `--locked`. Без Typst локальная сборка справку
  пропускает, и окно говорит, что справка не собрана.
- **Окно читает справку по первому открытию**, а не при загрузке страницы:
  мегабайт текста ради кнопки, которую нажимают не каждый заход. Ссылки
  документа на свои разделы ведут внутри окна — адрес страницы несёт ссылку на
  модель, и якорь перезаписал бы её.

### Consequences

Первая сборка образа стенда дольше: Typst собирается из исходников; слой стоит
до копирования дерева и пересобирается только при смене версии. Справка
русская и в английском интерфейсе — документ существует на одном языке.

## Тест-план

1. PDF документа до и после правки шаблона — побайтно равны.
2. `findRanges`, `sectionAt` — поиск без учёта регистра, без перекрытий, раздел
   читателя по положению заголовков.
3. Сборка: справка в бандле, у глав якоря, код ролями, цветов печати нет.
4. Прогон страницы: открытие, оглавление, память раздела после перезагрузки,
   поиск и переход по найденному, закрытие крестиком и Escape.
