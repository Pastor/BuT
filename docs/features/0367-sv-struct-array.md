## Краткое описание

Замер-21: `pts[0].x := 5;` при `pts: [Cell; 2]` исполняют эталон, `c`,
`st` и `rust`, а цель `sv` печатала вывод, который **verilator принимает, а
yosys отвергает**:

| Форма в выводе | Ответ yosys |
|---|---|
| сброс `pts <= '{{8'd1, 8'd2}, …};` | «Assignment pattern is only supported for whole unpacked array assignments» |
| после починки сброса — умолчание `pts_next = pts;` | «Latch inferred for signal `pts_next[0].x`» |

Всё при **нулевом** коде возврата `taktc`. Класс невидим сверке значений (её
тестбенч собирает verilator) и линту — только синтезу.

## Документирование

**Не требуется** — язык не меняется: запись законна и исполняется эталоном;
правится представление у одной цели.

## Архитектура (ADR)

- **Status:** Accepted
- **Date:** 2026-08-21
- **Authors:** Архитектор + лид разработки
- **Related issues:** [Фича](0367-sv-struct-array.md); связь с

### Context

Массив структур цель печатала: тип — `cell_t pts [0:1]`, сброс — шаблоном
присваивания `'{…}`, умолчание в `always_comb` — целиком (`pts_next = pts;`).
Прогон 2026-08-21 показал: **yosys** не принимает шаблон присваивания нигде,
кроме присваивания массива целиком, а при поэлементном сбросе объявляет
защёлку на `pts_next[0].lo`, потому что тело пишет **поле элемента**, а
умолчание задано массиву целиком.

Verilator обе формы принимает — ровно тот случай, ради которого проверка цели
держит два инструмента.

### Decision Drivers

1. **Вывод обязан синтезироваться**, а не только линтоваться.
2. **Формы выбирает прогон обоих инструментов**, а не стандарт.
3. **Правка не должна затрагивать массив скаляров**: он присваивается целиком
   и синтезируется (0365), а поэлементная печать раздула бы вывод корпуса.

### Considered Options

#### Option A. Печатать сброс и умолчание по полям, когда внутри массива структура

**Pros:**
- Проверено прогоном: `pts[0] <= {8'd1, 8'd2};` yosys **не** принимает, а
  `pts[0].lo <= 8'd1;` и `pts_next[0].lo = pts[0].lo;` — принимает.
- Массив скаляров не затронут: признак — «структура внутри массива».

**Cons:**
- Вывод длиннее: число строк равно числу скалярных полей.

#### Option B. Отказ цели на массиве структур

**Pros:** громче молчания.

**Cons:** запись исполняют четыре других потребителя; отказ сузил бы цель.

#### Option C. Уплощать массив структур в отдельные сигналы

**Pros:** синтезируется наверняка.

**Cons:** имена сигналов перестают соответствовать исходнику; индексация
переменной становится невыразимой.

### Decision

Принимается **Option A**. Носитель — `sv_array::type_leaves(ty, fields_of)`:
отдаёт суффиксы и типы скалярных мест, когда внутри распакованного массива
лежит структура, и `None` — когда регистр присваивается целиком. `Reg`
получает поле `leaves`; ветвь сброса и умолчание печатают по нему.

Значения листьев при сбросе берутся у инициализатора (через
`aggregate::leaves`) либо у умолчания типа.

### Consequences

#### Положительные

- Массив структур переводится и **синтезируется**; отказ, введённый 0366 как
  временная граница, снят.
- Признак «структура внутри массива» назван один раз и переиспользован для
  сброса и умолчания.

#### Отрицательные / Action items

- Вывод длиннее на массивах структур; в корпусе таких нет, снапшоты не
  изменились.

#### Acceptance criteria

1. `verilator --lint-only -Wall` **и** `yosys synth` принимают вывод на входах:
   запись поля элемента, агрегат целиком, массив без инициализатора.
2. Потактовая сверка значений совпадает; наблюдаемые различают поле и элемент,
   а один порт читает нетронутую переменную (проверка сброса).
3. Мутации «умолчание целиком» и «сброс целиком» роняют тест синтеза.
4. Предкоммит зелёный; вывод корпуса не изменился.

## Анализ

### Цель и контекст

Довести массив структур у цели `sv` до синтезируемого вывода и снять
временную границу, введённую фичей (отказ `SV-002` на агрегате с полем
внутри массива).

### Зависимости фичи

- **Зависит от:** нет. 0293 (структуры в целях), 0309 (агрегат массива), 0365
  (распакованный массив), 0366 (носитель раскрытия) закрыты.
- **Влияние на порядок разработки:** снимает кандидата, заведённого 0366.

### Требования и проверяемые условия

- **R1. Сброс — по полям.** Шаблон присваивания yosys принимает только для
  массива целиком.
- **R2. Умолчание — по полям.** Иначе запись поля элемента даёт защёлку.
- **R3. Массив скаляров не затронут.** Признак — «структура внутри массива»;
  иначе вывод корпуса вырос бы без нужды.
- **R4. Значения совпадают с эталоном.** Наблюдаемые различают поле и элемент.
- **R5. Сброс проверяется значением.** Порт читает нетронутую переменную.
- **R6. Синтез — отдельный контроль.** Ни линт, ни сверка значений класс не
  видят: оба идут через verilator.
- **R7. Граница 0366 снимается.** Отказ `SV-002` на агрегате с полем внутри
  массива больше не нужен.

### Критерии приёмки и способ проверки

| # | Критерий | Способ проверки |
|---|---|---|
| A1 | verilator и yosys принимают вывод | `scripts/probe.sh` (раздел инструментов) |
| A2 | Трасса совпадает с эталоном | `struct_array_values_match_generated_sv` |
| A3 | Синтез отдельным тестом | `struct_array_is_synthesizable` |
| A4 | Мутации ловятся | «умолчание целиком», «сброс целиком» |
| A5 | Вывод корпуса не изменился | предкоммит |

### Особенности по обратной функциональности

- **Язык не меняется**; свод: не применимо.
- **Отказ 0366 снят** — вход теперь переводится, и проверка «поле внутри
  массива» в `sv_stmt` удалена вместе с ним.

### Риски и зависимости

- **Длина вывода** растёт пропорционально числу полей; в корпусе массивов
  структур нет.
- **Признак «структура внутри массива»** обязан совпадать у сброса и
  умолчания — он вычисляется одной функцией.

## Разработка

### Задача

#### Что было

Сброс массива структур печатался шаблоном присваивания (`pts <= '{{…}, {…}};`),
умолчание — целиком (`pts_next = pts;`). Verilator обе формы принимает, yosys
— ни одной: первая даёт «Assignment pattern is only supported for whole
unpacked array assignments», вторая (после починки первой) — «Latch inferred».

#### Что сделано

**`takt-lang/src/generator/sv/sv_array.rs`** — `type_leaves(ty, fields_of)`:
суффиксы и типы скалярных мест, когда внутри распакованного массива лежит
структура; `needs_leafwise` — сам признак. Массив скаляров даёт `None` и
печатается целиком, как прежде.

**`takt-lang/src/generator/sv/sv_fsm.rs`** — у `Reg` появилось поле `leaves`;
`leafwise_reset` собирает значения (у инициализатора — через
`aggregate::leaves` фичи, при его отсутствии — умолчания типов). Ветвь
сброса и блок умолчаний печатают по листьям, если они есть.

**`takt-lang/src/generator/sv/sv_stmt.rs`** — снята временная граница 0366
(`refuse_struct_in_array`): вход переводится.

**Сверка**: `takt-sim/tests/data/eval/conformance_sv_struct_array.takt` и два
теста — потактовая сверка значений и **прогон синтеза** `yosys`.

**`takt-lang/src/generator/sv/sv_enums.rs`** (новый модуль) — печать
перечислений состояний и шагов вынесена из `sv_fsm.rs`: тот вышел за предел
размера модуля (1008 строк при лимите 1000). Печать перечислений от сборки
автомата не зависит — границы модуля совпали с границей ответственности.

**Класс невидим двум контролю из трёх.** Сверка значений собирает тестбенч
verilator, линт цели — тоже verilator; yosys видел его один. Отсюда отдельный
тест синтеза.

#### Проверки

```sh
cargo test --test conformance struct_array   # сверка значений + синтез
cargo test --test conformance                # 165
cargo test --test targets                    # 391
for f in examples/*.takt; do scripts/probe.sh -n 1 "$f"; done   # корпус чист
./scripts/precheck.sh
```

Мутации (обе пойманы тестом синтеза): печатать умолчание целиком; печатать
сброс целиком.

### Выводы и дальнейшие шаги

- **Класс видел один инструмент из трёх.** Линт цели и сверка значений идут
  через verilator, который обе неверные формы принимает; вердикт дал только
  `yosys synth` — поэтому у фичи отдельный тест синтеза.
- **Дефект был двухслойным:** починка сброса открыла защёлку на умолчании.
  Замер пришлось снимать дважды.
- **Граница, введённая 0366, снята той же неделей** — она и заводилась как
  временная, чтобы не заменять громкий отказ молчаливым несинтезом.
- Исправлений (`docs/fixes/`) не потребовалось.

## Итог (что сделано)

- Сброс и умолчание регистра, внутри которого лежит структура в массиве,
  печатаются **по полям**; массив скаляров не затронут (признак —
  `sv_array::needs_leafwise`).
- **Дефект двухслойный:** починка сброса открывает защёлку на умолчании —
  замер снимался дважды.
- **Класс видит один инструмент из трёх:** линт цели и потактовая сверка
  идут через verilator, поэтому у фичи отдельный тест синтеза (`yosys`).
- Временная граница фичи (`SV-002` на агрегате с полем внутри массива)
  снята.
- Печать перечислений состояний и шагов вынесена в модуль `sv_enums.rs`:
  `sv_fsm.rs` вышел за предел размера модуля.
- Вывод корпуса не изменился: массивов структур в `examples/` нет.
