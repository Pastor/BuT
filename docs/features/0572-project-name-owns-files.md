## Краткое описание

Имя проекта и имена его файлов связаны: новый проект заводит модель со своим
именем, а переименование проекта переименовывает модель, схему, сценарии и
пояснение. Рядом с загрузкой архива встала выгрузка — то же действие в обе
стороны.

### Context

Проект и его файлы жили порознь: новый проект заводил `model.takt` независимо от
имени, а переименование меняло только подпись в списке. Файл `test1.takt` в
проекте `test2` читается как чужой, а сценарий `test1-cold.json` перестаёт
находиться по имени модели (правило выбора сценария, 0568).

Выгрузка архива при этом была доступна только внутри проекта, хотя стоит рядом с
загрузкой по смыслу — это одно действие в обе стороны.

### Decision

Правило имени одно на страницу и на сервер: файл принадлежит проекту, если его
имя начинается с имени проекта, а дальше идёт точка (расширение) либо
разделитель `-`/`_`. Переименование проекта переименовывает такие файлы; прочие
не трогаются — `probe.json` в проекте `test1` назван автором, а не проектом.

Делает это **сервер, одной транзакцией**: серия рейсов со страницы рвётся
посередине, и проект остался бы наполовину переименованным.

Новый проект заводит модель своим именем. Имя проекта шире имени файла (пробелы,
кириллица) — негодное для файла имя сводится к общему `model.takt`: отказать в
заведении проекта из-за имени файла значило бы подменить предмет.

### Consequences

Занятое новое имя файла пропускается, а не отменяет переименование: имя проекта
уже сменилось, и оставить проект без имени ради одного файла хуже, чем оставить
один файл со старым именем. Активный файл и активный сценарий переставляются
вместе с именами.

## Разработка

### Задача — переименование тянет файлы

`rename_project_files` в транзакции `PATCH`: правило имени — `own_file_tail`,
для каждого файла обновляются запись в базе, файл на диске и ссылки проекта на
активные файл и сценарий.

### Задача — первый файл по имени проекта

`firstFileName` на странице: годное для файла имя проекта даёт `<имя>.takt`,
негодное — общий `model.takt`.

### Задача — выгрузка рядом с загрузкой

Кнопка `exportproject` в полосе списка выгружает **выбранный** проект; открытый
по-прежнему выгружается своей кнопкой. Носитель выгрузки один — он принимает
проект параметром.

### Проверки

`check-web.sh` (106 тестов), `check-design.py` (446 правил), прогон страницы на
сервере с базой.
