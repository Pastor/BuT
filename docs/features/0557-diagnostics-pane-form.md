## Краткое описание

Список диагностик под редактором и журнал прогона под схемой отвечают на один
вопрос — «что случилось» — и выглядят по-разному. Диагностика получает ту же
форму, что журнал: карточка записи, род записи словом, чередование подложки и
пометка выбранной строки. Цветность у неё своя — выбор заказчика по показу.

> жизненный цикл по своду.
