## Краткое описание

Переезд репозитория **состоялся**: `origin` указывает на
`github.com/Pastor/Takt.git`. Но старое имя осталось в **13 живых местах** —

исходников и в манифестах **обоих** плагинов. Сегодня они работают на редиректе
GitHub; фича снимает эту зависимость.

## Направление решения (наметка, не решение)

- Заменить 13 вхождений на `github.com/Pastor/Takt`; три артефакта фичи не
  трогать.
- **Плагины требуют переустановки после правки:** старый URL уже записан в
  установленный плагин RustRover и в `index.json` Zed — правка исходников сама по
  себе их не обновит.
- Открытый вопрос для анализа: **нужен ли проверка** «в дереве нет
  `github.com/Pastor/BuT` вне артефактов 0100». Дёшево (греп по образцу
  `check-language-version.sh`), но защищает от разового события, которое уже
  произошло; альтернатива — обойтись разовой правкой. Решает аналитик.
- Смежно: `extensions/zed-takt/extension.toml` и `install.sh` дублируют
  метаданные (`repository` в двух местах) — при правке проверить, не разъедутся ли.

Окончательный выбор — за стадиями **архитектуры** (ADR) и **анализа**: раздел
выше фиксирует то, что уже проверено, а не предрешает реализацию.

### Context

Репозиторий переехал: `origin` → `https://github.com/Pastor/Takt.git`. Старое
имя осталось **в 16 живых местах** (13 в форме URL + 3 в форме голого `BuT`).

Замер-29 (греп + сетевая проба):

| Категория | Места | Последствие |
|---|---|---|
| Метаданные крейтов | `takt-lang/Cargo.toml:7`, `takt-sim/Cargo.toml:7` | уйдёт в crates.io при публикации |
| Инструкция пользователю | `README.md:2075` (`git clone …/BuT.git`), `README.md:2076` (`cd BuT`) | **вторая строка ломается независимо от редиректа**: клон нового URL создаёт каталог `Takt` |
| Дерево проекта в README | `README.md:2277` (`BuT/`) | читатель видит несуществующее имя корня |
| Doc-ссылки исходников | `lib.rs:431, 501, 502`, `diagnostics/mod.rs:463` | ссылки в `cargo doc` |
| Манифест плагина IntelliJ | `plugin.xml:4` (`<vendor url>`) | попадает в **установленный** плагин |
| Манифест плагина Zed | `extension.toml:7`, `install.sh:93` | `install.sh` пишет URL **в `index.json` Zed** — проверено установкой |

**Ничего не сломано сегодня — работает редирект.** Проба:
`GET https://github.com/Pastor/BuT` → **HTTP 301** на `…/Pastor/Takt`;
`git ls-remote https://github.com/Pastor/BuT.git HEAD` отдаёт коммит. Класс
проблемы — **не отказ, а скрытая зависимость** от чужой инфраструктуры плюс
дезинформация читателя.

**Исключение из «ничего не сломано» — `cd BuT`.** Эта строка от редиректа не
зависит: `git clone https://github.com/Pastor/Takt.git` создаёт каталог `Takt`,
и следующая строка инструкции **уже не работает**. Голое `BuT` в реестре
карточки (13 вхождений URL) учтено не было — вскрыто при проработке.

### Decision Drivers

1. **Молчаливая зависимость.** Редирект GitHub исчезнет, если под `Pastor`
   появится новый репозиторий с именем `BuT`. Событие маловероятное, но
   последствие — отказ клонирования по всем инструкциям сразу.
2. **Дезинформация дороже отказа.** Отказ виден; неверное имя в README читатель
   принимает за истину и повторяет.
3. **Прецедент ADR.** Разовая правка дока без проверки уже приводила к
   рассинхрону (версия языка `0.3.0` против `0.4.0` — дожило незамеченным).
   «Правило, которое нельзя проверить командой, — не правило.»
4. **Артефакты стадий — история.** свод запрещает переписывать задним
   числом принятые решения; упоминания старого адреса в артефактах 0100 —
   свидетельства, а не ошибки.

### Considered Options

#### Option A. Разовая правка, без проверки

**Pros:**
- Минимальный объём; переезд — разовое событие, второй раз может не случиться.

**Cons:**
- Ничем не защищено: скопированный старый сниппет вернёт `Pastor/BuT`, и это
  снова никто не заметит.
- Ровно тот сценарий, из-за которого заведён проверка версии языка.

#### Option B. Правка + проверка «адрес репозитория в дереве один»

Скрипт `scripts/check-repo-url.sh` в `precheck.sh`: все вхождения
`github.com/Pastor/<имя>` вне списка исторических артефактов обязаны называть
**одно и то же** имя.

**Pros:**
- Защищает не от «имени `BuT`», а от **рассогласования вообще** — переживёт
  следующий переезд без правки скрипта.
- Дёшев (POSIX sh, греп), образец рядом — `check-language-version.sh`.
- Ловит и голое `cd BuT`, если добавить второй якорь.

**Cons:**
- Список исторических исключений придётся сопровождать: артефакты новых фич,
  цитирующие старый адрес, будут валить проверка.
- Проверяет согласованность, но не **правильность**: если все места разом
  назвать неверным именем, проверка промолчит.

#### Option C. Единый источник — URL в одном месте, остальные подставляются

**Pros:**
- Рассинхрон невозможен по построению (сильнейшая гарантия).

**Cons:**
- Форматы несводимы: `Cargo.toml`, `plugin.xml`, `extension.toml`, Markdown и
  doc-комментарии Rust не имеют общего механизма подстановки.
- Пришлось бы завести шаг генерации файлов — цена несоизмерима с задачей.

### Decision

Принимается **Option B**.

Драйвер 3 решает спор между A и B: проект уже платил за «разовую правку без
проверки» рассинхроном версии языка. Option C отвергнут как несоизмеримый —
подстановка в пять разных форматов дороже проблемы.

**Нормативные правила решения:**

1. **Адрес репозитория в дереве один.** Все вхождения `github.com/Pastor/<имя>`
   вне явного списка исторических артефактов обязаны называть одно имя. Проверка
   — `scripts/check-repo-url.sh` в `precheck.sh`.
2. **Проверка проверяет согласованность, а не имя.** Имя не зашивается в скрипт: он
   берёт эталон из **манифеста** `takt-lang/Cargo.toml` (поле `repository`) и
   требует, чтобы остальные совпали. Так следующий переезд потребует правки
   файлов, а не проверки.
3. **Исторические артефакты исключаются явным списком путей**, а не «по
   умолчанию». Каждое исключение — решение, а не умолчание (тот же принцип, что
   в своду ADR о явной ветке пунктуации).
4. **Голое имя каталога — отдельная проверка.** `cd BuT` не содержит URL и под
   свод не подпадает; в README оно правится, а проверка получает второй якорь:
   имя каталога в `cd` рядом с `git clone` обязано совпадать с последним
   компонентом URL.

### Consequences

#### Положительные

- Инструкция `git clone` + `cd` снова работает целиком (сегодня вторая строка
  сломана).
- Метаданные крейтов и обоих плагинов называют существующий адрес.
- Следующий переезд ловится машиной на первом же несогласованном файле.

#### Отрицательные / Action items

- **A-1.** Список исторических исключений — точка сопровождения. Артефакт новой
  фичи, цитирующий старый адрес, завалит проверка; лечится добавлением пути в
  список **с обоснованием**. Рост списка — сигнал ревью.
- **A-2.** Проверка проверяет согласованность, но не правильность. Это принято
  сознательно: правильность адреса — знание вне репозитория, и машинно её не
  установить, не ходя в сеть, а предкоммит обязан работать офлайн.
- **A-3.** **Установленные плагины правкой исходников не обновляются:** старый
  URL уже лежит в дистрибутиве RustRover и в `index.json` Zed. После правки
  требуется переустановка — это часть приёмки, а не побочная рекомендация.
- **A-4.** `docs/DIFF.md`, `docs/analyze/0018`, `docs/analyze/0030` упоминают
  `BuT` как **историю языка и путей**, а не как адрес репозитория. Под свод не подпадают (там нет `github.com/Pastor/`) и не трогаются.

#### Acceptance criteria

1. В дереве вне исторических артефактов нет `github.com/Pastor/BuT`.
2. `README.md`: `git clone` и следующий за ним `cd` согласованы; дерево проекта
   называет корень `Takt/`.
3. `scripts/check-repo-url.sh` существует, вызывается из `precheck.sh` и
   **валит** предкоммит при рассогласовании (проверяется мутацией).
4. Проверка **не** зашивает имя `Takt`: подмена имени во **всех** файлах разом
   оставляет его зелёным (проверяется мутацией — это и есть граница A-2).
5. Оба плагина пересобраны и переустановлены; в установленных артефактах старого
   URL нет.
6. Поведение инструментов не изменено: правки — метаданные, тексты и
   doc-комментарии.

## Анализ

### Цель и контекст

Переезд репозитория состоялся; старое имя осталось в дереве. Решение — Option B
[ADR](0179-repo-url-cleanup.md#архитектура-adr): правка + проверка согласованности,
проверяющий **не имя `Takt`**, а единственность адреса, — чтобы следующий
переезд ловился машиной.

### Зависимости фичи

- **Зависит от:** `нет`. Правки — метаданные, тексты и doc-комментарии; ни один
  слой компилятора не затрагивается.
- **Влияние на порядок разработки:** никого не разблокирует и не блокирует.
  Стоит среди процессных: дёшева и снимает дезинформацию в README, который
  читает каждый новый пользователь.

### Требования и проверяемые условия

- **R1. Живых вхождений старого адреса нет** вне исторических артефактов.
- **R2. Инструкция клонирования работает целиком** — `git clone` и `cd`
  согласованы.
- **R3. Проверка заведён** (`scripts/check-repo-url.sh`) и вызывается из `precheck.sh`.
- **R4. Проверка проверяет согласованность, а не имя** — эталон берётся из
  `takt-lang/Cargo.toml`, в скрипте имени `Takt` нет.
- **R5. Исключения явные** — список исторических путей в скрипте, с
  обоснованием.
- **R6. Поведение инструментов не изменено** — правки только в метаданных,
  текстах и doc-комментариях; вывод генераторов байт-в-байт прежний.
- **R7. Плагины переустановлены** — в установленных артефактах старого URL нет.

### Критерии приёмки и способ проверки

| # | Критерий | Способ проверки |
|---|---|---|
| A1 | Старого адреса нет вне истории | греп по дереву |
| A2 | `clone` + `cd` согласованы | чтение README + прогон проверки |
| A3 | Проверка валит рассогласование | **мутация**: вернуть `BuT` в один файл → предкоммит красный |
| A4 | Проверка не зашивает имя | **мутация**: заменить `Takt` на вымышленное имя во **всех** местах → проверка **зелёный** (граница A-2 ADR) |
| A5 | Проверка ловит рассогласованный `cd` | **мутация**: испортить только `cd` → проверка красный |
| A6 | Вывод генераторов не изменён | дифф `examples/generated/` пуст |
| A7 | Предкоммит зелёный | `./scripts/precheck.sh` |
| A8 | Плагины чисты | греп по установленным артефактам RustRover и `index.json` Zed |

**A4 — не формальность.** Он фиксирует **границу** проверки: тот проверяет
согласованность, а не правильность. Без этой проверки легко поверить, что проверка
защищает от неверного адреса, — он защищает лишь от разнобоя.

### Особенности по обратной функциональности

- **Крейты:** меняется поле `repository` — метаданные публикации. Версии крейтов
  **не растут**: изменение не касается ни API, ни поведения.
- **Версия языка не растёт**: язык не затронут.
- **Плагины:** меняются манифесты → требуется пересборка и переустановка (A-3
  ADR), иначе установленные копии сохранят старый URL.

### Риски и зависимости

- **Риск 1: проверка завалит артефакт будущей фичи**, законно цитирующий старый
  адрес (A-1 ADR). Лечится добавлением пути в список исключений с обоснованием;
  рост списка — сигнал ревью.
- **Риск 2: ложное чувство защиты** (A-2 ADR). Снимается проверкой A4, которая

- **10 вхождений в форме URL** заменены на `https://github.com/Pastor/Takt`:
  `takt-lang/Cargo.toml`, `takt-sim/Cargo.toml`, `README.md` (`git clone`),

`docs/adr/0100-*`, `docs/features/0100-*`, `docs/reports/0100-*`, где переезд
описан как вынесенный за объём фичи. Также не тронуты `docs/DIFF.md`,

локальный путь, а не адрес репозитория (A-4 ADR).

изменение касается метаданных публикации, а не API, поведения или языка.

- Греп по дереву: живых вхождений `Pastor/BuT` вне артефактов 0100/0179 и

- Машинная проверка — [дочистка URL репозитория после переезда BuT → Takt](0179-repo-url-cleanup.md#разработка).

### Задача

#### Что было

Разовой правки недостаточно: прецедент ADR — версия языка, поправленная в
README без проверки, разошлась с кодом и прожила так незамеченной. Скопированный
старый сниппет вернул бы `Pastor/BuT` тем же путём.

#### Что сделано

`scripts/check-repo-url.sh` (POSIX sh, образец — `check-language-version.sh`),
вызывается из `precheck.sh` рядом с проверкой версии языка.

- **Эталон берётся из манифеста**, а не зашит: поле `repository` в
  `takt-lang/Cargo.toml`. свод ADR — проверка судит **согласованность**, а
  не имя `Takt`, поэтому следующий переезд потребует правки файлов, а не
  скрипта.
- **Второй якорь — имя каталога:** `cd <имя>` сразу после `git clone` обязано
  совпасть с последним компонентом URL. Именно эта строка была сломана и от
  редиректа не зависела.

**Отклонение от ADR: denylist → allowlist.** свод ADR планировало
исключать исторические артефакты явным списком. Реализация показала, что
старый адрес законно цитируют **все** повествовательные файлы — карточка и ADR
самой фичи, `CHANGES.md`, `FEATURES.md`, — и denylist пришлось бы дополнять при
каждом упоминании. Взят обратный принцип: перечислены файлы, где адрес
**исполняется** (манифесты, README, doc-ссылки исходников, скрипт установки);
`docs/` и журналы не проверяются вовсе — там старый адрес есть свидетельство, а не ошибка. Замысел («каждое исключение — решение»)
сохранён: список проверяемого тоже явный.

**Проверка поймал сам себя на первой же пробе:** первая редакция сравнивала любой
`github.com/*/*` и упала на `lalrpop/lalrpop` — git-зависимости в том же
манифесте. Чужой репозиторий называется как называется; правило «адрес один»
касается **своего**, поэтому владелец теперь берётся из эталона и сверяются
только его адреса.

#### Проверки

**Мутационные (обязательны):**

| Мутация | Ожидание | Результат |
|---|---|---|
| вернуть `BuT` в **один** файл (`extension.toml`) | проверка красный | `rc=1`, файл назван в сообщении ✅ |
| испортить **только** `cd` в README | проверка красный | `rc=1`, «делает `cd BuT`, а клон создаёт `Takt`» ✅ |
| переименовать во **всех** рабочих местах разом на `Nonexistent` | проверка **зелёный** | `rc=0`, «адрес один — Pastor/Nonexistent» ✅ |

Третья мутация — не курьёз, а **проверка границы** (A-2 ADR): проверка
удостоверяет согласованность, а не правильность. Правильность адреса есть знание
вне репозитория; установить её машинно можно только походом в сеть, а предкоммит
обязан работать офлайн. Без этой проверки легко поверить, что проверка защищает от
неверного адреса.

  берётся из поля `repository` манифеста `takt-lang`, поэтому следующий переезд

  исторических артефактов, но старый адрес законно цитируют **все**
