## Краткое описание

Карта адресов портов (внешняя карта `--address-map` компилятора, формат выгрузки
`taktc address-map --emit map`) становится родом файла проекта — расширение
`.takt-map` (решение заказчика) наравне с моделью,
сценарием, пояснением и раскладкой: создаётся, открывается, правится,
переименовывается, удаляется и выгружается архивом так же, как остальные файлы.

> Фича зарегистрирована по запросу заказчика 2026-09-10 («поведение и
> редактирование как у всех остальных»); далее проходит жизненный цикл по своду.

### Context

Замер 2026-09-10: ключ `--address-map` страница принимала, но модуль в браузере
его **не исполнял** — `takt-wasm` строил вход сборки без записей карты, и цель
`c-hal` собиралась по адресам модели молча. Диска у модуля нет, а родов файла
было четыре; карты среди них не было.

### Decision

- **Род `address_map`, расширение `.takt-map`** (решение заказчика): правило рода
  на сервере (`limits::Kind`), ограничение рода в базе — шаг схемы 8 → 9, формат
  архива — версия 5 (прежний сервис отверг бы имя).
- **Карта берётся из состава проекта**, как подключения: `takt-wasm` читает файл
  ключа `--address-map` из присланных файлов, разбирает его
  `parse_address_map` и подставляет записи во вход сборки. Файла нет — отказ
  словами; битая карта — отказ с кодом записи. Имя модели в строке ключей
  узнаётся по расширению `.takt`: значение ключа (`board.takt-map`) принималось
  за входной файл.
- **Цель с адресами собирается картой проекта** (решение заказчика): для
  `c-hal`, `st-at`, `sv-mmio` страница ищет в проекте `<проект>.takt-map` — имя по
  тому же правилу, что у первой модели проекта (`firstFileName`: имя проекта,
  негодное для файла, даёт `model`), — и подставляет `--address-map`. Нет файла
  — сборки нет, отказ называет цель и файл. Карта, названная в ключах явно,
  сильнее.
- **На странице карта — файл наравне с прочими**: раздел структуры, род в окне
  нового файла, правка в области кода, сохранение, переименование, удаление.
  Моделью она не собирается и не судится (своего разбора у страницы нет — судит
  компилятор при сборке), кнопка канона к ней не применяется. Тексты карт
  читаются в состав проекта вместе с моделями.

### Consequences

Правка карты видна сборке после сохранения либо пока карта открыта: состав
проекта читается с сервера. Подсветка карты — лексером языка, отдельного
разбора формата в редакторе нет.

## Разработка

Сервер: `limits.rs`, `db.rs` (шаг 8 → 9), `archive.rs` (формат 5). Модуль:
`takt-wasm/src/compile.rs` (`address_map_of`, разбор имени модели). Страница:
`account.js`, `app.js`, словарь, книга оформления.

## Тест-план

1. Сервер: род выводится из `.takt-map`, причина отказа называет расширение,
   схема перехода равна схеме с нуля, архив — версия 5.
2. Модуль: карта из состава применяется (адрес карты в выводе `c-hal`,
   контроль — без карты его нет); нет файла и битая карта — отказ.
3. Страница: род и раздел, карта читается в состав, открытая карта моделью не
   собирается; прогон страницы — завести, править, сохранить, собрать `c-hal`
   с картой; без файла карты — отказ с именем файла.
