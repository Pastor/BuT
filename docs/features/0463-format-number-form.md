# Фича: Форма записи числа переживает форматирование

- **Номер:** 0463
- **Статус:** ГОТОВО
- **Зависит от:** нет
- **Tier:** 3 (смысл программы не меняется, но исходник автора теряет

- **Класс:** прочее
- **Связанные issue (анализ):** кандидат, заведённый фичей
  [форматтер и fmt в переборе](0462-matrix-formatter.md)

## Краткое описание

`taktc fmt` печатал числа десятичными, теряя запись автора: `0xF0` → `240`,
`at 0x40000100` → `at 1073742080`. Теперь число печатается **как написано**,
если запись означает то же значение.

> Фича заведена из блока кандидатов.

## Документирование

**Не требуется:** канон не меняется — он лишь перестаёт менять то, чего не
обязан касаться. Раздел «Стиль кода» о форме записи чисел не говорит.

## Архитектура (ADR)

- **Status:** Accepted
- **Date:** 2026-08-31
- **Authors:** архитектор

### Context

Проект уже держит правило «АСД хранит выбор автора»: литерал длительности
печатается как написан (`1m30s` не канонизируется в `90s`), синонимы
`while`/`loop` и `: [Guard] x;` / `: x;` не сводятся к одной форме. Число было
исключением — и заметным: для маски и адреса шестнадцатеричная запись показывает
разряды и регистр, а десятичная не показывает ничего.

Замер нашёл след в самом корпусе: в
`book/src/08-ports-addresses/examples/ports.takt` соседние строки записаны и
шестнадцатерично (`0x40000004:5`), и десятично (`1073741832`) — вторые однажды
прошли через `fmt`. Адресный литерал с битом форму сохранял: он отдельный токен
и хранит текст.

### Considered Options

- **A. Хранить основание записи в токене и АСД** (`Token::Number(i128)` →
  плюс признак). Отвергнут по цене: `Expression::Number` — самый частый узел,
  тридцать мест разбора, и признак пришлось бы протаскивать через равенство
  узлов (тот же довод, по которому позиции нет у `ExpressionNode::Model`).
- **B. Печатать по исходнику через позицию узла** — принят: у `ast::Expression`
  позиция **есть**, форматтеру исходник доступен, АСД не трогается.
- **C. Оставить как есть** — отвергнут: правило «форма записи принадлежит
  автору» в проекте уже действует, и число из него выпадало без причины.

### Decision

Число печатается текстом исходника на месте узла, **если** этот текст означает
то же значение. Исходник живёт в потоковом носителе на время форматирования —
как носитель позиции отказа у целей, и по той же причине:
печатники выражений зовутся из двух десятков мест.

**Проверка значения — не перестраховка, а условие безопасности.** Подстрока
берётся по позиции узла; разойдись позиция с текстом — форматтер напечатал бы
чужое число. При несовпадении печатается десятичное, то есть **прежнее**
поведение: молчаливой порчи этот путь не допускает по построению.

**Сброс носителя обязателен**: состояние переживает вызов, и печать вынесена
в замыкание, чтобы сбросить его на всех путях выхода, включая ошибку.

### Consequences

Канон корпуса не меняется (`fmt --check examples/` зелен): в `examples/` числа
уже десятичные. Файлы, где автор писал шестнадцатерично, после `fmt` такими и
остаются.

#### Acceptance criteria

- A1. `0xF0`, `0x40000100`, `0x30` переживают форматирование.
- A2. Десятичная запись остаётся десятичной — канон не переводит её в hex.
- A3. Разделитель разрядов (`1_000_000`) сохраняется.
- A4. `fmt` остаётся идемпотентным, а вывод целей — прежним.
- A5. Мутация «не брать форму из исходника» роняет контроля.

- R1. A1…A5 выше.
- R2. Печать по исходнику **не может** дать чужое число: значение сверяется.

### Критерии приёмки и способ проверки

`format_number_form_tests` (три контроля), модульные тесты носителя, перебор

`precheck.sh`.

### Редакторский слой

**Не затронут:** лексика и синтаксис не меняются.

### Особенности по обратной функциональности

Отформатированные ранее файлы не «возвращают» шестнадцатеричную запись — она
уже потеряна в тексте. Фича лишь перестаёт терять её впредь.

### Риски и зависимости

Риск — потоковый носитель: состояние переживает вызов. Снят сбросом на всех
путях выхода (печать в замыкании) и проверкой значения, которая делает худший
исход равным прежнему поведению.

## Итог

Число встало в один ряд с длительностью и синонимами: форма записи принадлежит
автору. Путь выбран самый дешёвый из безопасных — печать по исходнику с
проверкой значения, — и АСД, самый частый узел языка, остался нетронутым.
