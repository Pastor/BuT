# Спецификация взаимодействий — «жест / клавиша → результат → отклик на экране»

Пункт 8 выходных требований: уточнённые Т1–Т16 для мыши, касания и клавиатуры,
включая курсоры. Сверка с R8–R11 и R13 — в последней колонке.

## Мышь (указатель)

| жест | результат | отклик на экране | курсор | требование |
|---|---|---|---|---|
| тяга по свободному месту холста | панорама вида | лист едет за указателем, сетка вместе с ним | `grab` → `grabbing` | R8 |
| колесо | масштаб шагом `1,1` в пределах `0,25×`…`4×` | точка под курсором остаётся на месте; показатель числом меняется; ниже `0,5×` подписи скрываются | без изменения | R8, Т1 |
| щелчок по узлу | выбор узла + курсор в текст на объявление состояния | узел — пара «выбранное»; строки легенды и навигатора помечены той же парой | `grab` | R10, Т2 |
| тяга узла (порог 4 px) | перенос с привязкой к `--gap` | узел поверх рёбер, рамка `--accent`; рёбра тянутся за ним, сохранённые изломы стоят; снимается метка «не размещён» | `grabbing` | R9, Т6, Т13 |
| двойной щелчок по композиции | вход в лист композиции либо модели | крошки получают уровень, лист вписывается | `grab` | R11, Т3 |
| щелчок по кнопке входа на карточке | то же | то же | `pointer` | Т3 |
| щелчок по ребру | выбор ребра | штрих `--on-surface` толщиной 2, проступают точки изломов | `pointer` | R9, Т4 |
| двойной щелчок по сегменту ребра | новая точка излома в том сегменте, по которому щёлкнули (с привязкой) | точка появляется под курсором, ребро становится выбранным | `crosshair` | R9, Т5 |
| двойной щелчок по точке излома | снятие точки | ребро перестраивается по остатку точек | `crosshair` | R9, Т5 |
| тяга точки излома | перенос точки с привязкой | точка залита акцентом, ломаная следует | `grabbing` | R9, Т5 |
| щелчок по миникарте | перенос вида в точку | рамка видимой области прыгает туда | `crosshair` | R8, Т10 |
| щелчок по крошке | возврат на уровень | лист уровня вписывается, выбор снимается | `pointer` | R11, Т7 |
| щелчок по «вписать» | лист целиком в области | показатель масштаба меняется | `pointer` | R8 |
| щелчок по «отцентрировать» | выбранный узел в центр (без выбора — весь лист) | вид едет, масштаб не меняется | `pointer` | R8 |
| щелчок по «автораскладка» | ярусная раскладка текущего листа заново | узлы встают по ярусам; действие отменяется Ctrl+Z | `pointer` | R9 |
| щелчок по паре «углы» | форма углов рёбер на весь файл | все рёбра перерисованы; `aria-pressed` переносится | `pointer` | R9, Т4 |
| щелчок по «навигатор» | панель слева поверх холста | панель выезжает, `aria-pressed` = true | `pointer` | Т8 |
| наведение на кнопку панели | подсказка `.tip` с подписью словом | панель подсказки под курсором | `pointer` | книга § `.tip` |
| наведение на знак `K` либо на строку условия | подсказка «`K3` · `!Overloaded & NeedUp` · Нужен подъём» | панель `.tip` над знаком | `pointer` | Т4 |
| наведение на узел либо на строку легенды | подсказка «`S2` · `DoorClosing` · Закрытие двери»; без подписи автора — только латиница | та же панель | `grab` | Т2 |
| щелчок по кнопке места легенды | легенда встаёт полкой снизу, колонкой справа либо плавающей панелью поверх холста | лист перекладывается под новое место; `aria-pressed` переносится | `pointer` | требование заказчика |
| тяга знака условия | место знака становится «своим» | знак едет за указателем с привязкой к сетке, чернила плотнее | `grab` → `grabbing` | требование заказчика |
| двойной щелчок по знаку условия | базовое место (центр) | знак прыгает на середину самого длинного сегмента | `grab` | требование заказчика |

| — (без жеста) | пересечение линий рисуется огибанием | мостик на ребре, нарисованном позже; слияние остаётся без мостика | — | требование заказчика |
| тяга плавающей легенды за заголовок | перенос панели с привязкой к `--gap` | панель едет за указателем и не уходит за края холста | `grab` → `grabbing` | требование заказчика |
| наведение на узел «не размещён» | причина словами | та же панель | `grab` | Т13 |

| правка подписи условия в легенде | подсказка знака `K` получает кириллицу | на листе знак не меняется — он и есть постоянная величина | `text` | требование заказчика |

## Касание (`hover: none`)

| жест | результат | отклик на экране | требование |
|---|---|---|---|
| тяга одним пальцем | панорама | лист едет за пальцем | R8, Т16 |
| щипок двумя | масштаб в тех же пределах | показатель числом меняется | R8 |
| касание узла | выбор | пара «выбранное»; цель нажатия — круг `--h-control` (48 px ≥ 44) | R13, Т16 |
| **долгое нажатие** на узле | начало переноса | узел приподнят рамкой акцента, дальше едет за пальцем | Т16 |
| касание кнопки входа на карточке | вход в композицию | двойного щелчка на касании нет — кнопка обязательна | Т3, Т16 |
| касание ребра | выбор ребра | штрих плотнее; **точек изломов нет** — изломы не редактируются | Т5, Т16 |
| касание «вписать» / «навигатор» | те же действия | панель свёрнута до двух кнопок ростом `--h-control` | Т16 |
| — | — | миникарты на узком экране нет | Т10, Т16 |

## Клавиатура

| клавиша | результат | отклик на экране | требование |
|---|---|---|---|
| `Tab` | по узлам в порядке ярусов, затем по рёбрам, затем по строкам легенды | кольцо `--accent` вокруг узла; подсказка знака показывается и по фокусу, а не только по наведению | R13, Т15 |
| стрелки | перенос выбранного узла на шаг сетки | узел прыгает на `--gap`, снимается «не размещён» | R13, Т15 |
| `Shift` + стрелки | перенос на пять шагов | то же шагом `5 × --gap` | Т15 |
| `Enter` | вход в композицию | крошки получают уровень | R11, Т15 |
| `Escape` | назад по крошкам; на корне — снятие выбора; **во время переноса — отмена** | узел возвращается на прежнее место | Т6, Т15 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | отмена и повтор правки раскладки в пределах сессии | вид возвращается к предыдущему состоянию раскладки | R9, Т6 |
| `+` / `−` | масштаб шагом `1,1` от центра области | показатель числом | Т15 |
| `0` | вписать лист | то же | Т15 |
| `F6` (существующий приём страницы) | переход между областями | фокус уходит из холста, панорама не перехватывает клавиши | R7 |
| раскладка клавиш | подсказка на кнопке навигатора | текст `scheme.navigatorHint` | Т15 |

## Что взаимодействия не делают

- **Не редактируют модель.** Добавления состояния, ребра и правки условия
  нет ни жестом, ни клавишей (решение A9 карточки): текст остаётся
  единственным описанием автомата.
- **Не сохраняют молча.** Запись раскладки идёт по общим правилам страницы
  (черновик, сохранение проекта); строка расхождения исчезает **после
  записи**, а не после нажатия.
- **Не отбирают клавиши у текста.** Пока фокус в редакторе, `+`, `−` и `0`
  принадлежат ему; холст слушает их только с фокусом внутри себя.
