# Размерная сетка — все числа через шкалы

Пункт 7 выходных требований. Своих чисел у холста нет: каждое новое —
константа в `app.css` с производной от шкалы книги. Ниже — полный список.

## Новые константы (блок 4 патча `01-app.css.patch.css`)

| токен | значение | при базовом кегле | откуда взято |
|---|---|---|---|
| `--node-d` | `var(--h-control)` | 48 px | диаметр круга узла — ступень контрола: узел и есть цель нажатия, и 48 px перекрывают предел WCAG 2.5.5 (44 px) |
| `--comp-side` | `calc(var(--node-d) * 3)` | 144 px (9rem) | сторона квадрата композиции — задание, пункт 3; три диаметра узла, а не «9rem числом» |
| `--grid-step` | `calc(var(--gap) * 3)` | 24 px | шаг рисованной сетки — три шага привязки; на каждом шаге точка читалась бы как заливка |
| `--pin-d` | `var(--gap)` | 8 px | точка излома — задание, пункт 5 |
| `--map-w` | `calc(var(--node-d) * 8 / 3)` | 128 px (8rem) | ширина миникарты — задание, пункт 10, выражена ступенью |
| `--map-h` | `calc(var(--node-d) * 2)` | 96 px (6rem) | высота миникарты — там же |
| `--node-label-max` | `12ch` | 12 знаков | мера подписи под узлом: шире — подписи соседних узлов сходятся |
| `--edge-label-max` | `24ch` | 24 знака | мера цитаты условия — задание, пункт 4 |
| `--raw-sheet` | `#F7F7F2` / `#20241C` | — | сырьё поля листа, обе темы |
| `--raw-sheet-ink` | `#2E332B` / `#E3E5DC` | — | чернила на поле листа, обе темы |
| `--surface-sheet` | `var(--raw-sheet)` | — | роль: заливка листа |
| `--on-surface-sheet` | `var(--raw-sheet-ink)` | — | роль: чернила листа |

Меры строк заданы **в знаках**, а не в пикселях: текст меряется текстом.
При смене кегля страницы кнопками ±1 предел в пикселях уехал бы, и подпись
рвалась бы там, где раньше умещалась.

Все константы объявлены **прежде употребления** — проверка `D8`. Порядок
вставки в `:root` указан в шапке патча.

## Что взято из существующих шкал без новых чисел

| место | значение | ступень |
|---|---|---|
| высота строки крошек | `--h-compact` | шкала высот |
| высота кнопки панели, строки навигатора, строки легенды, поля подписи | `--h-dense` | шкала высот |
| те же под `hover: none` | `--h-control` | шкала высот |
| скругление листа, панели инструментов | `--radius` | шкала скруглений |
| скругление кнопок панели, миникарты, углов рёбер | `--radius-sm` | шкала скруглений |
| обозначение узла | `--text-md` | шкала кегля |
| номер обозначения, вид состояния, показатель масштаба | `--text-xs` | шкала кегля |
| подпись условия, строка легенды, крошки | `--text-sm` | шкала кегля |
| пустой лист | `--text-lg` | шкала кегля |
| отступ состояния в навигаторе | `--gap-lg` | шкала отступов |
| поля панели, зазоры обойм | `--gap`, `--gap-half`, `--gap-quarter` | шкала отступов |
| переходы фона и рамки | `--motion` (120 мс) | движение книги |
| плотность отклика | `--state-hover`, `--state-press` | § 3 книги |

Шестого кегля, третьей высоты и третьего скругления схема не заводит — как
требует бриф.

## Геометрия рисунка (числа в системе координат листа)

Единица — логический пиксель при масштабе `1,0` (задание, пункт 1, решение вопроса 5
карточки). Эти числа **не CSS-размеры**: они принадлежат `viewBox`, и шкалы
книги к ним не приложимы. Их всё же немного, и каждое названо:

| число | где | откуда |
|---|---|---|
| `24` | радиус круга узла | половина `--node-d` |
| `2` | зазор между границей узла и наконечником | чтобы стрелка не «въезжала» в рамку |
| `1,5` | штрих ребра и рамок | штрих значков книги |
| `2` | штрих выбранного ребра и рамки акцента | вдвое от штриха покоя |
| `5` | радиус скругления углов ломаной | `--radius-sm` |
| `4` | радиус точки излома | половина `--pin-d` |
| `4 3` | шаг штриховой рамки «не размещён» | половина и треть шага привязки |
| `8` | шаг привязки переноса | `--gap` |
| `24` | шаг рисованной сетки | `--grid-step` |
| `0,25`…`4`, шаг `1,1` | пределы и шаг масштаба | задание, пункт 1 |
| `4` | порог начала переноса, px экрана | задание, пункт 6 |
| `4` | радиус мостика-огибания на пересечении линий | половина шага привязки `--gap` |
| `24` | отступ знака условия от узла при базовых местах «начало» и «конец» | три шага привязки (`--grid-step`) |

## Проверка

- `D4` — `font-size` только `var(--text-*)`: в патче все объявления кегля
  ссылаются на шкалу, включая текст внутри SVG.
- `D5` — `height`, `min-height`, `border-radius` только через `var(--h-*)`,
  `var(--radius*)`, `var(--gap*)`.
- `D8` — каждая упомянутая переменная объявлена; новые — в начале файла.
- `D1` — числовой цвет только в блоках сырья (тело правила из одних
  объявлений токенов).
